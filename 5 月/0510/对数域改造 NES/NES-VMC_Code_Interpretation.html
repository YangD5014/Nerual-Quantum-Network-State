For Quantum Many-Body Systems (H₂ Molecule)

1. Research Objectives

Goal

Implement the NES-VMC (Natural Excited State Variational Monte Carlo) algorithm using NetKet framework and Flax.nnx APIs to compute the first K excited state energies of quantum many-body systems.

Requirements

  • Use NetKet's built-in extended Hilbert space hi ** K
  • Diagonalize the averaged local energy matrix to obtain ground and excited state energies
H₂ Molecule: bond_length = 1.4, basis = STO-3G

2.1 Problem Background

In quantum mechanics, we need to solve the eigenvalue problem of Hamiltonian operator Ĥ, finding the lowest K eigenfunctions.

Challenge

For quantum many-body systems, direct diagonalization of the Hamiltonian matrix is usually infeasible because the Hilbert space dimension grows exponentially with particle number.

NES-VMC Solution

NES-VMC equivalently transforms the problem of finding the first K excited states into a ground state problem of an "extended system".

2.2 Extended Hilbert Space

Let X = (x₁, ..., x_N) represent a set of N particles, where xᵢ denotes the state of the i-th particle.

Extended Hilbert Space = K copies of original system via tensor product
Each configuration: x = (x¹, ..., x^K)

H₂ Molecule Configuration

  • Spin order: [α₁, α₂, β₁, β₂]
  • 4 legal configurations under particle/spin conservation
  • Hilbert space dimension: Nₛ = 4

2.3 SingleStateAnsatz Structure

ψ(x) corresponds to the Ansatz in ordinary VMC algorithm, outputting ln(ψ(x)) in complex values.

class SingleStateAnsatz(nnx.Module):
    def __init__(self, n_spin_orbitals: int, hidden_dim: int = 16, *, rngs: nnx.Rngs):
        super().__init__()
        self.n_spin_orbitals = n_spin_orbitals
        self.linear1 = nnx.Linear(n_spin_orbitals, hidden_dim, rngs=rngs, param_dtype=complex)
        self.linear2 = nnx.Linear(hidden_dim, hidden_dim, rngs=rngs, param_dtype=complex)
        self.output = nnx.Linear(hidden_dim, 1, rngs=rngs, param_dtype=complex)

    def __call__(self, x: jax.Array) -> jax.Array:
        h = nnx.tanh(self.linear1(x))
        h = nnx.tanh(self.linear2(h))
        out = self.output(h)
        return jnp.squeeze(out)

Model parameters are complex-valued by default, output is log-domain: ln(ψ(x))

2.4 TotalAnsatz Structure

Let ψᵢ denote the i-th N-particle wave function. The TotalAnsatz is defined as the determinant:

Ψ(x) ≡ det| ψ₁(x¹) ψ₂(x¹) ... ψₖ(x¹) |
| ψ₁(x²) ψ₂(x²) ... ψₖ(x²) |
| ⋮ ⋮ ⋱ ⋮ |
| ψ₁(x^K) ψ₂(x^K) ... ψₖ(x^K) |

Key Property

The determinant structure prevents different Ansatze from collapsing to the same state without explicitly requiring them to be orthogonal.

2.5 Log-Domain Transformation

For stable computation (per paper Section S8):

ln Ψ(X) = ln det(M) = ln det| ψ₁(x¹) ... ψₖ(x¹) |
⋮
| ψ₁(x^K) ... ψₖ(x^K) |

NESTotalAnsatz Implementation

def _forward_single(x_single):
    x_single = x_single.reshape(self.K, self.n_spin)
    L = jnp.zeros((self.K, self.K), dtype=complex)
    for i in range(self.K):
        for j in range(self.K):
            L = L.at[i, j].set(self.single_ansatz_list[j](x_single[i]))
    L_stable = L - L.max()
    sign, log_abs_det = jnp.linalg.slogdet(jnp.exp(L_stable))
    log_Psi_stable = log_abs_det + 1j * jnp.angle(sign)
    return log_Psi_stable, L_stable, L.max()

2.6 Extended Hamiltonian

Define the extended Hamiltonian:

H̃ = Ĥ₁ ⊕ Ĥ₂ ⊕ ... ⊕ Ĥₖ

Where Ĥᵢ acts only on the i-th particle set.

Key Insight

The ground state energy of H̃ equals the sum of the lowest K energies of the original system Ĥ, with ground state wave function Ψ*.

Using trace form equivalence:

Ψ⁻¹(x) H̃ Ψ(x) = Tr[Ψ⁻¹(x) Ĥ Ψ(x)]

2.7 Ham_psi and Ham_Psi Functions

Ham_psi

Computes Ĥψ₁(x¹)

def Ham_psi(ha, single_machine, params, x):
    is_single = (x.ndim == 1)
    if is_single:
        x = x[None, :]

    def _single_hpsi(x_single):
        x_primes, mels = ha.get_conn_padded(x_single)
        log_psi_vals = single_machine(params, x_primes)
        psi_vals = jnp.exp(log_psi_vals)
        return jnp.sum(mels * psi_vals)

    H_psi_batch = jax.vmap(_single_hpsi)(x)
    return H_psi_batch[0] if is_single else H_psi_batch

Ham_Psi

Computes ĤΨ(x)

def Ham_Psi(ha, single_machine_list, total_params, x):
    K = len(single_machine_list)
    if x.ndim == 2:
        def _single_HamPsi(x_single):
            HPsi = jnp.zeros((K, K), dtype=complex)
            for i in range(K):
                for j in range(K):
                    val = Ham_psi(ha, single_machine_list[j],
                                  total_params['single_ansatz_list'][j],
                                  x_single[i])
                    HPsi = HPsi.at[i, j].set(val)
            return HPsi
        return _single_HamPsi(x)

2.9 Core Constraint: No Duplicate Configurations

Key Constraint

Extended states must satisfy x^i ≠ x^j (when i ≠ j). Otherwise, matrix Ψ(x) will have identical rows/columns, leading to zero determinant.

For K=2: Valid configurations = Nₛ² - Nₛ = 4² - 4 = 12
(NOT 4² = 16)

NESFermionHopRule Implementation

def _check_duplicate(self, sigma_ext):
    sub = sigma_ext.reshape((*sigma_ext.shape[:-1], K, SINGLE_SIZE))
    return jnp.any(jnp.all(sub[...,1:,:] == sub[...,0:1,:], axis=-1), axis=-1)

3. Loss Function

Objective Function (Rayleigh Quotient)

L = ⟨Ψ|H̃|Ψ⟩ / ⟨Ψ|Ψ⟩

Using matrix determinant lemma, rewritten in trace form:

L = Tr(S⁻¹Ĥ) = Tr(Ψ⁻¹H̃Ψ)

Local Energy Matrix

E_L(x) ≡ Ψ⁻¹(x) Ĥ Ψ(x)

Via Monte Carlo sampling:

L = E_{x~Ψ²}[Tr(Ψ⁻¹(x)ĤΨ(x))]

4. NES-VMC Gradient Formula

Define log amplitude:

ln|Ψ(x)| = ln det(Ψ(x)) = Tr(log(Ψ(x)))

Gradient Formula

∇_θ L = 2E_{x~Ψ²}[Tr((E_L(x) - Ē_L) ∇_θ ln Ψ(x))]

Where:

  • E_L(x) = Ψ⁻¹(x)ĤΨ(x) — local energy matrix
  • Ē_L = E_{x'~Ψ²}[E_L(x')] — expectation of local energy matrix
  • ∇_θ ln Ψ(x) — log gradient of wave function matrix

When K=1, this reduces to standard VMC gradient formula.

4.2 Gradient Implementation

def nes_vmc_gradient(ha, total_matrix_machine, total_machine,
                     single_machine_list, total_params, x_batch):
    # 1. Batch local energy matrix
    loss_batch, E_L_batch = NES_loss_energy(
        ha, total_matrix_machine, single_machine_list, total_params, x_batch
    )
    E_L_mean = jnp.mean(E_L_batch, axis=0)
    E_L_centered = E_L_batch - E_L_mean
    tr_centered = jnp.trace(E_L_centered, axis1=-2, axis2=-1)

    # 2. Compute gradients
    grad_logPsi = jax.grad(total_machine, argnums=0, holomorphic=True)
    vmap_grad_logPsi = jax.vmap(grad_logPsi, in_axes=(None, 0))
    dlogPsi_batch = vmap_grad_logPsi(total_params, x_batch)

    # 3. Core weighted average
    def weight_and_mean(grad_component):
        weights = tr_centered.reshape((-1,) + (1,)*(grad_component.ndim - 1))
        return jnp.mean(weights * jnp.conj(grad_component), axis=0)

    grad = jax.tree.map(weight_and_mean, dlogPsi_batch)
    loss_mean = loss_batch.mean()
    return grad, loss_mean, E_L_mean

5. Excited State Energy Extraction

After training, accumulate local energy matrices through extensive sampling:

Ē_L = E_{x~Ψ²}[E_L(x)]

Then diagonalize:

Ē_L = UΛU⁻¹

Where Λ = diag(E₁, E₂, ..., Eₖ) contains eigenvalues sorted by energy.

Physical Interpretation

When single-state Ansatz is linear combination of eigenfunctions ψᵢ = Σⱼ aᵢⱼ ψⱼ*:

Ψ⁻¹ĤΨ = A⁻¹ΛA

Diagonalization directly yields excited state energies E₁, E₂, ..., Eₖ.

Summary

Key Components

  • Extended Hilbert Space: K copies via tensor product
  • SingleStateAnsatz: Complex-valued FFNN
  • TotalAnsatz: Determinant structure
  • NESFermionHopRule: No duplicate constraint

Algorithm Flow

  • 1. Sample in extended Hilbert space
  • 2. Compute local energy matrix
  • 3. Calculate gradient via trace formula
  • 4. Diagonalize to extract excited states

Advantage

NES-VMC transforms the excited state problem into a ground state problem, avoiding explicit orthogonalization requirements.
