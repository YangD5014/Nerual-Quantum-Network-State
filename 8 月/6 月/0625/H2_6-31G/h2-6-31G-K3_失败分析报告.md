## 3. 失败原因分析

### 3.1 梯度爆炸问题 (根本原因)

从训练日志可见，在 **Step 80** 附近发生梯度爆炸：

```
[Step  80] logΨ: mean=12.255+0.036j | min=10.059-0.890j | max=12.314+1.676j
梯度监控 | raw=12346.0769 | natural=108535.1652 | clipped=1.5000(上限1.5)
Loss=-1.823740 | E0=-151.56726672 | E1=-0.94711171 | E2=150.69063856 | E3=150.69063856
```

**问题分析**：
1. **raw梯度**突然从 ~1-4 跳到 **12346**，增长约 10000 倍
2. **natural梯度**达到 **108535**，QGT逆矩阵将小噪声放大
3. 裁剪虽然将梯度限制在 1.5，但此时参数已经受到严重破坏
4. **能量E0** 出现 **-151 Ha** 的极端值（正常应为 -1 Ha 左右），相差约 150 倍

### 3.2 梯度归零后训练冻结

Step 90 后：

```
[Step  90] logΨ: mean=7.976+0.760j | min=7.976-1.204j | max=7.976+1.938j
梯度监控 | raw=0.0000 | natural=0.0000 | clipped=0.0000(上限1.5)
Loss=-0.142738 | E0=-60.84706314 | E1=-0.94701440 | E2=61.65133989 | E3=61.65133989
```

**问题分析**：
1. 梯度完全归零 (0.0000)
2. logΨ 值冻结在 `7.976+0.760j`，不再变化
3. 这是典型的 **神经网络"死亡"** 现象 - 参数被破坏到无法恢复的状态
4. softmax输出可能进入饱和区，导致梯度消失

### 3.3 失败链条

```
Step 0-70: 正常训练，Loss从0.69降至-2.4
    ↓
Step 80: 梯度爆炸 (raw=12346, natural=108535)
    ↓
参数被大幅破坏，logΨ值跳到12+
    ↓
Step 90+: 梯度归零，训练冻结
    ↓
无法收敛到正确能量
```

## 4. 技术层面问题

### 4.1 QGT (量子梯度张量) 病态问题

对于 6-31G 基组的较大希尔伯特空间：

| 参数 | 失败案例 | 成功案例 |
|------|---------|---------|
| n_orbitals | 4 | 2 |
| 扩展空间维度 | 4³ = 64 | 4³ = 64 |
| QGT条件数 | **可能极大** | 相对较小 |

`qgt_diag_shift=0.1` 可能不足以正则化病态矩阵，导致求逆时噪声被放大数万倍。

### 4.2 学习率与梯度裁剪

```python
lr = 0.01
clip_norm = 1.5
qgt_diag_shift = 0.1
```

当梯度爆炸到 12346 时，即使裁剪到 1.5，**参数更新幅度仍然巨大**：

```
Δθ = clip(自然梯度) ≈ 1.5
```

这足以将 softmax 激活推入饱和区，导致后续梯度归零。

## 6. 建议修复方案

### 方案 1: 降低学习率 + 增大QGT正则化
```python
lr = 0.001          # 从0.01降至0.001
qgt_diag_shift = 1.0 # 从0.1增至1.0
```

### 方案 2: 学习率预热 (Learning Rate Warmup)
```python
schedule = optax.warmup_cosine_decay_schedule(
    init_value=0.0001,
    peak_value=0.01,
    warmup_steps=50,
    decay_steps=400,
)
optimizer = optax.chain(
    optax.clip_by_global_norm(1.0),
    optax.inject_optimizer_state(optimizer, schedule)
)
```

### 方案 3: 梯度自适应方法
```python
optimizer = optax.adam(learning_rate=0.001)  # 自适应学习率
```

### 方案 4: 减小模型规模
```python
# 降低隐藏层维度
total_ansatz = NESTotalAnsatz(SINGLE_SIZE, K, 8, rngs=nnx.Rngs(11))  # 12→8
```

## 7. 结论

| 失败原因 | 严重程度 | 说明 |
|---------|---------|------|
| **梯度爆炸 (QGT病态)** | ★★★★★ | 6-31G基组导致QGT条件数极大，0.1正则化不足 |
| **学习率过高** | ★★★★☆ | 0.01 + 梯度爆炸 = 参数破坏 |
| **缺乏学习率调度** | ★★★☆☆ | 无warmup/consine schedule |
| **神经网络饱和** | ★★★☆☆ | 梯度冻结后无法恢复 |

**核心问题**：6-31G基组的较大希尔伯特空间使得QGT矩阵病态问题更加严重，0.1的正则化参数不足以抑制求逆时的数值爆炸，最终导致训练失败。
