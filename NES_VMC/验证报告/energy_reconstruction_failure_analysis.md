# 训练后参数复原能级失败的原因分析（`测试复原.ipynb`）

> **背景**：`h2-6-31G-K4.ipynb` 训练完成后，把 `history['params'][-1]` 中的变分参数填入
> `SingleStateAnsatz`，在 `测试复原.ipynb` 中直接计算能量，得到 `-133.30 Ha`（cell 9）或
> `-0.085 Ha`（cell 12），与 FCI 基态 `-1.0668 Ha` 完全对不上。
>
> **核心结论**：
>
> 1. **直接原因**：`SingleStateAnsatz.__call__` 输出的是**对数振幅** `log ψ(x)`，不是振幅 `ψ(x)`。
>    复原时没有取 `exp`，把 `logψ` 当成 `ψ` 代入了 `⟨ψ|H|ψ⟩`。
> 2. **根本原因**：即使正确取 `exp`，**单个列 `ψ_j` 也不是 `H` 的本征函数**。NES 训练的能量级别
>    来自 K×K 局域能量矩阵 `E_L(X) = Ψ(X)^{-1} H Ψ(X)` 的**本征值**（等价于 Rayleigh-Ritz 广义
>    本征问题 `Mv = λSv`），不是单态期望 `⟨ψ_j|H|ψ_j⟩/⟨ψ_j|ψ_j⟩`。
> 3. **正确做法**：构造 `M_ij = ⟨ψ_i|H|ψ_j⟩`、`S_ij = ⟨ψ_i|ψ_j⟩`（在全空间精确求和），解广义
>    本征问题，得到最终参数对应的 4 个能级：`[-1.0210, -0.9191, -0.6474, -0.0983] Ha`。
> 4. **附带发现**：训练日志里记录的 `Energy_levels = [-1.084, -0.941, -0.662, -0.594]` 是训练
>    过程中**有限采样批上的有偏估计**（`E_L` 矩阵非对角元很大，本征值对噪声敏感），不是最终参数
>    的精确能级；事后用最终参数做精确 Rayleigh-Ritz 得到的是第 3 条的值。

---

## 1. 前因：训练时"能级"是怎么定义的

训练对象不是单个 `ψ_j`，而是 **K 个副本的扩展空间**上的行列式波函数：

$$
\Psi(X) = \det[\psi_j(x_i)], \qquad X = (x_1, \dots, x_K), \quad i,j = 1,\dots,K
$$

其中第 `j` 列（列状态）是第 `j` 个单态 ansatz `ψ_j`，第 `i` 行是扩展构型 `X` 的第 `i` 个副本构型 `x_i`。

对每个采样构型 `X`，代码计算 **K×K 局域能量矩阵**（`NES_loss_energy_stable_gauge`）：

$$
E_L(X) = \Psi(X)^{-1}\, H\,\Psi(X), \qquad (H\Psi)_{ij} = \sum_{x'} H[x_i,x']\,\psi_j(x')
$$

- 训练损失：`loss = Re[tr E_L(X)]` 的采样平均（能量之和）。
- 监控能级：`eig(E_L_mean)[:K]`（训练 notebook 第 5 步能量监控），即 **`E_L` 矩阵的本征值**，
  并按实部排序。

关键点：**能级是 `E_L` 矩阵的本征值，不是它的对角元，也不是任何单列的变分期望。**
只有当列 `ψ_j` 恰好是 `H` 的本征函数时，`E_L` 才会对角化、本征值才等于对角元 `⟨ψ_j|H|ψ_j⟩/⟨ψ_j|ψ_j⟩`；
未完全收敛时这两者不相等。

## 2. 后果：`测试复原.ipynb` 为什么算错

### 2.1 直接 bug：`logψ` 被当成 `ψ`

`SingleStateAnsatz.__call__`（[NES_VMC_V1.py](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/NES_VMC_V1.py#L28-L42)）：

```python
def __call__(self, x):
    h = nnx.tanh(self.linear1(x))
    h = nnx.tanh(self.linear2(h))
    out = self.output(h)
    return jnp.squeeze(out)      # ← 这是 log ψ(x)，没有取 exp
```

网络直接输出复数值 `log ψ(x)`。复原时必须先做 `ψ(x) = exp(logψ(x))`。

- **cell 9**：`logψ.conj().T @ H @ logψ`，把量级 ~O(1–10) 的 `logψ` 当振幅 → `-133.2989 Ha`（荒谬值）。
- **cell 11**：`normalization = exp(logψ).conj().T @ exp(logψ) = 1564.86`，这里用了 `exp`。
- **cell 12**：分子仍用 `logψ`（未取 exp），分母却用 exp 后的模方 → `-133.2989/1564.86 = -0.0852 Ha`。
  分子分母自相矛盾，任何量级都被这种混用破坏。

### 2.2 即使取 exp，单列期望也不等于能级

若把 cell 9/12 修正为全程使用 `ψ = exp(logψ)`，得到：

$$
E_0^{(\text{单列})} = \frac{\langle \psi_0|H|\psi_0\rangle}{\langle \psi_0|\psi_0\rangle} = -0.8506\ \text{Ha} \neq E_0^{\text{FCI}} = -1.0668\ \text{Ha}
$$

仍相差 5.9 eV。原因见第 1 节：**训练并没有把每一列独立训练成 H 的本征函数**，
单列的期望值没有物理意义，能级只能从 K 列张成的子空间里提取。

**矩阵层面的直接证据**（`verify_mixing_matrix.py`，用最终参数、全部 16 构型精确求和）：

- 单列期望 = `M_ii/S_ii`（归一化后的对角元）：
  `[-0.8506, -0.9523, -0.7771, -0.7870]` —— cell 9 修正后得到的 -0.8506 就是第一个值。
- 但 `M`、`S` 的**非对角元与对角元同量级**（如 `S[0,3]=2693.1`、`M[0,3]=-1956.4`），
  说明 4 列**严重不正交、相互混合**，不是本征函数。
- 能级 = 广义本征问题 `Mv=λSv` 的本征值（见下），每个能级对应一个**混合线性组合**
  `Σ_j v_j ψ_j`，与任何单个 `ψ_j` 的期望值都没有对应关系。

## 4. 正确复原方法

系统只有 16 个单态构型，可以直接**全空间精确求和**构造 K×K 矩阵：

```python
x = hi.all_states()                  # (16, n_spin)
H = ha.to_dense()                    # (16, 16)
psi_full = np.exp(np.stack([ansatz_j(x) for j in range(K)], axis=1))  # (16, K)

M = psi_full.conj().T @ (H @ psi_full)   # M_ij = <ψ_i|H|ψ_j>
S = psi_full.conj().T @ psi_full         # S_ij = <ψ_i|ψ_j>
lam, _ = scipy.linalg.eigh(M, S)         # 广义本征问题 M v = λ S v
levels = np.sort(lam)                    # ← 最终参数对应的 K 个能级
```

结果：`[-1.0210, -0.9191, -0.6474, -0.0983] Ha`。

**交叉验证**（证明这是"训练同款"定义的精确极限）：

1. 穷举全部 `16^K = 65536` 个扩展构型，按 `|Ψ_total(X)|² = |det Ψ(X)|²` 加权平均
   `E_L(X) = Ψ(X)^{-1}HΨ(X)`，其本征值与上面的 Rayleigh-Ritz 结果**完全一致**
   （且可严格证明 `E_L_mean ≡ S^{-1}M`，本征值相同）。
2. 用训练同款 Metropolis 采样器（`NESFermionHopRule`，`|Ψ_total|²` 稳态分布）对最终参数
   重新采样 5 批独立样本，`eig(E_L_mean)` 均在 `[-1.02, -0.92, -0.65, -0.10]` 附近波动。

两条独立路径互相印证：**最终参数的真实能级约 −1.02, −0.92, −0.65, −0.10 Ha**。

## 5. 训练记录能级为什么"更好看"但不可靠

训练日志记录的 `[-1.084, -0.941, -0.662, -0.594]` 与事后精确复原不一致，原因是：

- 记录值来自**单个有限批次**（16 链 × 200 样本）的 `E_L_mean`，且采样器状态在 gauge reset
  与参数更新后并未重新热化；
- 该 `E_L` 矩阵**非对角元很大**（~1.6，列远非本征函数），本征值对矩阵噪声极其敏感——
  噪声会让极值本征值向外扩散，甚至跌破变分下限（记录 E0 = −1.084 < FCI −1.067 就是这样来的）；
- 所以训练日志的能级**只能当过程监控用**，不能作为训练结束后的精确结果。

## 6. 结论与建议

1. 复原参数的第一个动作永远是 `ψ = exp(ansatz(x))`——模型输出的是 `log ψ`。
2. 求能级不要用单列期望，要对全部 K 列解广义本征问题 `Mv = λSv`（即训练同款的
   `E_L` 本征值在精确极限下的结果）。
3. 当前这组最终参数的**真实能级精度不高**（E0 差 46 mHa ≈ 1.25 eV，E3 差 422 mHa ≈ 11.5 eV），
   训练日志的"高精度"是有限样本偏差的假象；如需化学精度需要继续训练或调参。
4. 建议把"事后精确复原"（全空间求和 + Rayleigh-Ritz）写进训练脚本作为最终评估步骤，
   而不是依赖训练中 `eig(E_L_mean)` 的监控值。
