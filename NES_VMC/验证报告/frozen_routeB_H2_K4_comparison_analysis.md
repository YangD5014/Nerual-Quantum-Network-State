## 1. 结论摘要

在 H₂/6-31G（4 轨道 CAS，16 维物理空间）、K=4、实参数 FFNN Ansatz 上实现了
**Route B 冻结策略**：把收敛的 φ₀ 作为行列式第一列进入新流形
`det[φ₀, ψ₁', ψ₂', ψ₃']`，只训练 3 个 fresh active 列，并与「不冻结继续全训练」的
对照组（Control）在完全相同的 Stage 0 起点上做 200 步平行训练。

**四条核心结论：**

1. **构造性冻结零漂移**：Frozen 阶段 φ₀ 对 FCI 基态保真度全程严格恒定为 **0.996148**
   （同一向量，方差为零）；Control 阶段基态列组合随训练波动漂移（0.9988–0.9996 区间，
   相对 Stage 0 提取的 φ₀）。冻结不需要任何 penalty 项或显式投影算子。
2. **行列式隐式投影有效**：active 列从随机初始化出发，block 精确 E₁ 在 24 步内从
   **-0.120 → -0.951**（FCI E₁ = -0.958），最终提取的 3 个 active 态与 FCI 激发态
   对角重叠 **0.9957 / 0.9883 / 0.9938**，与 φ₀ 的重叠仅 **~10⁻⁴**——正交性由
   「行列式消除线性相关 + NES 广义本征」两步产生，符合方案文档 §16 的逻辑链。
3. **冻结的代价与收益并存**：Frozen 的 E₁ 误差（-4.80 mHa）优于 Control（-7.09 mHa），
   说明冻结基态后剩余自由度专注优化激发态；但 E₀ 被锁定在 Stage 0 水平（-4.95 mHa），
   失去继续下压的空间（Control 可继续优化到 -4.06 mHa）。E₂/E₃ 因 active 列仅 3 个
   且 fresh 初始化，收敛慢于 Control（-14.84 vs -9.78 mHa）。
4. **块结构成立**：冻结流形上完整 4×4 MCMC 广义本征 λ_B = [-1.0476, -0.9532, -0.6578,
   -0.5448]，最低本征值与 φ₀ 的 Rayleigh 商（-1.0494）一致，证明 φ₀ 方向在流形中
   保持为独立块（方案文档 §7 的 `V_B = diag(1, V_active)` 结构在数值上得到确认）。

## 2. 实验设置

| 项 | 配置 |
|---|---|
| 体系 | H₂ (d=1.5 a₀)，6-31G，CAS(2e,4o) → 8 qubit / 16 维物理空间 |
| Ansatz | `SingleStateAnsatz_SharedBackbone`（实参数 FFNN，8→12→12→双头 logA/φ，logψ=logA+iφ），与 `H2_631G_8Qbit_K4_Ansatz_A_RealFFNN.ipynb` 一致 |
| NES | K=4，联合行列式采样 `|det Ψ(x₁..x₄)|²`，NESFermionHopRule，16 链 × 200 样本 × sweep 20 |
| 优化 | 实参数 Wirtinger 力梯度 + Re(S) QGT 自然梯度，lr=0.1，diag_shift=0.1，clip=20，per-param 0.5，gauge reset 周期 10 |
| 流程 | Stage 0：300 步标准 NES-VMC → 提取 φ₀=Σv₀ⱼψⱼ → 分支：Control（4 列续训 200 步）/ Frozen（det[φ₀,ψ₁',ψ₂',ψ₃'] 训 3 列 200 步，fresh 初始化） |
| 诊断 | 每 25 步用 16 维稠密 H 做全空间精确分析（项目惯例的「精确极限」）；Frozen 用 block 分析（φ₀ Rayleigh 商 + 投影基 3×3 本征），避免文档 §5 警告的完整 4×4 对角化重新旋转 φ₀ |

FCI 基准：E = [-1.054347, -0.957906, -0.668952, -0.551402] Ha。

## 3. 冻结前后对比结果

### 3.1 能级（全空间精确，Ha；误差 mHa）

| 阶段 | E₀ | E₁ | E₂ | E₃ |
|---|---|---|---|---|
| FCI | -1.054347 | -0.957906 | -0.668952 | -0.551402 |
| Stage 0 末（冻结点，MCMC λ） | -1.047584 (-6.76) | -0.953824 (-4.08) | -0.661965 (-6.99) | -0.544912 (-6.49) |
| **Control 末（未冻结）** | **-1.050291 (-4.06)** | -0.950814 (-7.09) | -0.659175 (-9.78) | -0.550448 (-0.95) |
| **Frozen 末（Route B block）** | -1.049400 (-4.95) | **-0.953104 (-4.80)** | -0.654110 (-14.84) | -0.545290 (-6.11) |

### 3.2 φ₀ 保真度（对 FCI 基态 / 对初始 φ₀）

| | Stage 0 末 | Control 末 | Frozen 全程 |
|---|---|---|---|
| φ₀ 对 FCI 基态保真度 | 0.996148 | 0.996851（重新提取） | **0.996148（恒定，零漂移）** |
| φ₀ 对初始 φ₀ 保真度 | 1（定义） | 0.999589（波动 0.9988–0.9996） | 1（构造性） |

Control 的漂移虽小（本例 Stage 0 已较收敛），但方向不可控；Frozen 从机制上杜绝漂移——
这正是方案文档 Phase I（State Freezing）的目标。

### 3.3 本征态纯度（与 FCI 各态重叠，全空间精确）

Control（完整 4×4 对角化，态按能量排序）：对角重叠 [0.9969, 0.9950, 0.9903, 0.9988]。
Frozen（block：φ₀ + 投影基 3×3）：

| 态 | 对 FCI E₀ | E₁ | E₂ | E₃ |
|---|---|---|---|---|
| φ₀（冻结） | **0.9961** | 0.0014 | ~0 | ~0 |
| active₀ | 1.4e-4 | **0.9957** | 3e-4 | 1e-4 |
| active₁ | 2.6e-5 | 2e-4 | **0.9883** | 8e-4 |
| active₂ | 1.2e-5 | ~0 | 6e-4 | **0.9938** |

**active 态与 φ₀ 的重叠 ~10⁻⁴**：正交性不是靠 penalty 施加的，而是「行列式消除线性相关
（文档 §14）+ NES 广义本征在正交补内最小化（文档 §16）」的自然结果。

### 3.4 收敛动力学（Frozen，block 精确 E₁ 轨迹）

```
step 0    : -0.1205   （fresh 随机初始化）
step 24   : -0.9514   （24 步内完成主要收敛）
step 99   : -0.9514
step 199  : -0.9531   （FCI: -0.9579）
```

冻结流形的采样分布 `|det[φ₀,ψ']|²` 使 active 列一进入训练就被推向 φ₀ 的「线性余量」，
收敛速度与 Control 中激发态列相当，未因行列式结构改变而受损。

### 3.5 计算成本

| | 可训练列数 | 参数量 | 采样 | 单阶段 200 步耗时 |
|---|---|---|---|---|
| Control | 4 | 100% | 同 | 88 s |
| Frozen | 3 | **75%** | 同（K=4 不变） | 101 s |

Route B 冻结省掉 25% 参数与梯度计算，但**不降阶**（文档 §17-18：K 保持 4，行列式保持 4×4，
采样成本不变）。耗时略高源于每步多算冻结列的 H 作用（Hφ₀ = Σv₀ⱼHψⱼ，K 次 get_conn）。

## 4. 关键发现与讨论

1. **「冻结 ≠ 降阶」得到实证**（文档 §18）。本实验把两者拆开：Phase I 冻结只保证
   已收敛态不漂移并减少 active 参数；若要 4×4→3×3 降阶（进一步省 M/S 与采样维度），
   需要 Phase II（把 active 列数减到 K-1），本实验未做。
2. **必须用 block 分析提取物理态**（文档 §5 的坑）。最初版本对冻结流形直接做完整
   4×4 广义本征，最低本征值被 active 列「拉回」旋转组合（-0.819 ≠ E_φ0），
   误判为冻结失效；改为「φ₀ Rayleigh 商 + 投影基 3×3」后一切自洽。
   **任何按能量排序的完整对角化都会破坏冻结**，root tracking（文档 §21）在
   block 结构下被自然规避。
3. **E₀ 冻结在 -4.95 mHa 不再下降是设计行为**：若 Stage 0 收敛更充分（如 600 步
   或更大采样），φ₀ 起点更高，Frozen 分支的绝对 E₀ 误差随之更小。冻结策略的价值
   在于**保护**而非**改进**已收敛态。
4. **E₂ 劣化（-14.84 mHa）是 fresh 初始化 + 列数减少的联合代价**。文档 §20 的多级
   冻结流程（φ₁ 收敛后再冻结、再 fresh 初始化剩余列）预期可缓解高阶态欠优化。
5. 与 0923 deflation（Q₀HQ₀ 显式投影）相比，Route B 不需要第二个 `|φ₀|²` 采样器、
   不需要估 overlap 标量 c/h/E₀，实现更贴近 NES-VMC 原生结构；代价是行列式只消除
   **线性相关**而非严格归一化正交（文档 §14），正交性最终仍依赖广义本征收敛。

## 5. 局限

- 单例（H₂/6-31G K=4）、单随机种子；Control/Frozen 的对比未做多种子统计显著性。
- 冻结判据用固定步数（300），未实现文档 §2 的自适应化学精度判据。
- `|V_B[0,0]|` 指标因列未归一化而 >1，块结构证据以「λ_B[0] ≈ E_φ0 + active-φ₀ 重叠 ~10⁻⁴」为准。
