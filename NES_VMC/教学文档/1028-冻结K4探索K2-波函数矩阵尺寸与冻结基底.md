## 0. 一句话答案

**冻结 K=4、探索 K=2 时，算法里真正被构造、被求本征的矩阵是 2×2，不是 7×7。**
冻结的 4 列并没有“加进”这个矩阵，而是被**投影减掉**了；因此矩阵尺寸只由 active 的 K 决定，
与冻结了多少列无关。

至于“冻结 K4 再探索 K3”，**新拟设的变分基底仍然只是 3 条新的 ψ（fresh 初始化），
不是 φ₀…φ₃**；φ₀…φ₃ 是“被减掉的子空间”的基，而不是“拿来展开新态的基”。
把两者拼在一起写出的 7×7 只是**全基投影矩阵**，由于块对角，实际只解其中的 3×3。

## 3. 为什么不是 7×7？——两个独立的理由

### 理由一：冻结列是“减掉”，不是“加入”

deflation 的定义就是

```
χ̃_m = ψ̃_m − Φ̃ c[:,m],   c = argmin ‖ψ̃_m − Φ̃ c‖²
```

也就是把新列 ψ̃_m 投影到冻结子空间的正交补上。得到的 χ̃ 是 **K 条**向量，
不是 4+K 条。取行列式自然只有 K×K。

如果冻结列是“加入”，那才需要把新旧列堆成一个大矩阵；但那样做**没有物理意义**，
因为冻结态的贡献已经被精确地扣除了，再加进来等于重复计入。

### 理由二：即使写成全基矩阵，尺寸上限也只是 4+K=6（或 7）

假设你**不**做投影，而是把 `{φ₀…φ₃, ψ̃₀, ψ̃₁}` 六条列一起写成矩阵，
那是一个 n×6 的矩形矩阵；若按“多列行列式/多列 MS 估计”的方阵写法，边长是 **6**，
即 4+2。**7 这个数在 K=2 的情形下没有来源**。

如果题目换成“冻结 4、探索 3”，全基列数是 4+3=**7**，这时才会出现 7 列的矩阵；
但即便在这时，真正求解的方阵仍是 **3×3**，见第 4 节。

> 唯一需要 8 的地方是希尔伯特空间的比特数（8 qubit），那是**组态空间**的维数底数，
> 与“波函数矩阵边长”完全无关。

## 4. 全基 7×7 与 active 3×3 的关系：块对角

设冻结列 φ_i 是旧子空间的近似本征态（由 `v_rot` 旋转得到），
新列为投影后的 χ_m。则在同一组基下

```
        ┌                        ┐
        │  H_FF (4×4) │ H_Fχ     │   H_Fχ ≈ 0
  H  =  │─────────────┼──────────│   因为 ⟨φ_i|H|χ_m⟩ = E_i ⟨φ_i|χ_m⟩ = 0
        │  H_χF       │ H_χχ(K×K)│   H_χF ≈ 0（χ 已对 φ 正交化）
        └                        ┘
```

- 左上 4×4 是冻结子空间自身的 Hamiltonian，其谱就是已经收敛的 φ₀…φ₃；
- 右下 K×K 是剩余子空间（deflated Hamiltonian）的谱，正是我们要求的 φ̂₄…；
- 交叉块在“φ 精确本征 + χ 精确正交”时严格为 0，实际训练中是数值小量。

所以：

```
谱(6×6 或 7×7 全基矩阵) = 谱(4×4 冻结块) ∪ 谱(K×K active 块)
```

求后 K 个能级，只需要解 K×K 那一块。这正是 deflation 省算力的地方：
不必为了拿“第 5、6 个能级”去解一个大矩阵并和已知低能级一起数值相消。

| 场景 | 全基矩阵边长（若硬写） | 实际求解方阵 |
|---|---|---|
| 冻结 4 + 探索 2 | 6×6 | **2×2** |
| 冻结 4 + 探索 3 | 7×7 | **3×3** |
| 冻结 4 + 探索 4 | 8×8 | **4×4** |
| 冻结 6 + 探索 4 | 10×10 | **4×4** |

## 5. 第二问：冻结 K4 再探索 K3，基底是 φ₀…φ₃ 吗？

### 5.1 冻结子空间的基：是 φ₀…φ₃，不是原始 ψ₀…ψ₃

旧 K4 训练得到 4 条网络列 ψ₀^old…ψ₃^old。它们张成的 4 维子空间里，
用样本版 MV=SVA 广义本征求出旋转矩阵 `v_rot`：

```
φ_i = Σ_j ψ_j^old · v_rot[j,i],   i = 0..3      (脚本 L205-214)
```

所以在 **deflation 的“被减掉的那一侧”**，基确实是旋转后的 φ₀…φ₃
（近似本征态），而不是原始的、彼此不正交的 ψ_j^old。

代码里对应 `Phi = exp(Lf) @ V`，`V = v_rot`，所以 `Phi` 的四列就是 φ₀…φ₃（再乘尺度 e^{−f}）。

### 5.2 新拟设的变分基：不是 φ₀…φ₃，而是 K 条 fresh 的新列

新的可训练 ansatz 只含 K 条网络列：

```
total_ansatz = NESTotalAnsatz_stable(n_states=K, ...)   # K=2 或 3
```

它们 **fresh 初始化**（脚本注释明确说不能沿用 Stage0 收敛列，否则行列式奇异），
然后被投影：

```
χ̃_m = ψ̃_m − Φ̃ c[:,m]      m = 0..K-1
```

因此新态的展开基是这 K 条 χ̃（active 列），**不是 φ₀…φ₃**。
φ₀…φ₃ 在这里只承担两个角色：

1. 定义“要投影掉哪个子空间”；
2. 在最终能量里贡献已经知道的那 4 个能级（不再重算）。

### 5.3 三种“基”不要混为一谈

| 说法 | 是什么 | 维数（冻结4+探索3） |
|---|---|---|
| 冻结子空间基 | φ₀…φ₃（v_rot 旋转后的旧列） | 4 |
| 新拟设变分基 | ψ̃₀…ψ̃₂（fresh 新列） | 3 |
| 投影后 active 基 | χ̃₀…χ̃₂ = ψ̃ − Φ̃c | 3 |
| 全基（若硬拼） | φ₀…φ₃ + χ̃₀…χ̃₂ | 4+3=7 |

只有最后一行是 7；“波函数矩阵”指的是第三行，边长为 **3**（K=2 时是 2）。

## 7. 常见误解对照表

| 误解 | 事实 |
|---|---|
| “冻结 4 + 探索 2 ⇒ 矩阵 4+2+1=7×7” | 7 无来源；全基边长是 6，实解 2×2 |
| “冻结列也参与行列式，所以行列式变大” | 冻结列只参与**投影减法**，不进行列式 |
| “K 是总列数” | 脚本里 `K` 只是 active 列数；总列数是 `R+K` |
| “冻结基是原始 ψ₀…ψ₃” | 是 `v_rot` 旋转后的 φ₀…φ₃ |
| “新态用 φ₀…φ₃ 展开” | 新态用 K 条 fresh 新列 χ̃ 展开，φ 只是被 deflate 掉 |
| “7×7 和 2×2 给的本征值不同” | 块对角 ⇒ 后 K 个本征值与 K×K 块完全一致（数值上差小量） |
| “8 qubit ⇒ 8×8” | 8 是组态比特数，不是矩阵边长 |

## 9. 一分钟记忆

- **矩阵边长 = K（本次探索的列数）**，与冻结多少列无关；
- **冻结列走的是矩形系数 c（R×K），不是方阵**；
- **被冻结的基是 φ（v_rot 旋转后）**，但 **新态的基是 fresh 的 χ = ψ − Φc**；
- **4+K 只在“硬写全基矩阵”时出现，且块对角，K×K 就是答案**。
