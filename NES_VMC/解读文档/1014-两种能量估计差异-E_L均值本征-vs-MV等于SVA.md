# 两种能量估计为什么算出来不一样：`eig(E_L_mean)` vs `MV = SVA`

对象：`NES_VMC/experiments/H2分子/H2_631G_8Qbit_K4_Ansatz_A_RealFFNN.py` 训练循环第 5. 节
（[L506-516](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/H2_631G_8Qbit_K4_Ansatz_A_RealFFNN.py#L506-L516)）

## 1. 现象（Step 299 日志）

```
Loss=-3.232606 | E0=-1.05434660+0.00000586j | E1=-0.95790552 | E2=-0.66895207 | E3=-0.55140198-0.00000566j   ← 方法一 eig(E_L_mean)
MV = SVA 本征值｜E0=-1.05663451 | E1=-0.95791371 | E2=-0.66894445 | E3=-0.54911397                          ← 方法二 广义本征
```

差异分布：

| 能级 | 方法一 | 方法二 | 方法一 − 方法二 |
|---|---|---|---|
| E0 | −1.05434660 | −1.05663451 | **+2.29 mHa** |
| E1 | −0.95790552 | −0.95791371 | +0.008 mHa |
| E2 | −0.66895207 | −0.66894445 | −0.008 mHa |
| E3 | −0.55140198 | −0.54911397 | **−2.29 mHa** |
| 求和 | −3.23260617 | −3.23260664 | ≈ 0（差 4.7e-7）|

**一句话结论：两者是"同一批样本、两种不同的估计器"，不是同一个量的两种算法。**
方法一是"逐样本相似变换 → 加权平均 → 普通本征"，方法二是"逐样本 Gram 内积 → 均匀平均 → 广义本征"；
平均时所用的坐标系和样本权重都不同，期望值本来就不相等。总和一致、差异集中在两端（E0/E3 等量反向），
正是"估计器系统性框架差"而非蒙特卡洛噪声的特征（噪声会让四个能级一起抖）。

## 2. 两种方法各自在算什么

记单个 walker 样本 `x_n = (x_{n1},…,x_{nK})`（K=4 个自旋轨道组态），列拟设矩阵
`Ψ_n[i,j] = ψ_j(x_{ni})`，`HP_n[i,j] = (Hψ_j)(x_{ni})`。

### 方法一：`eig(E_L_mean)`（能量监控，与 loss 绑定）

- 逐样本：`E_n = Ψ_n⁻¹ HP_n`（`jnp.linalg.solve`，[NES_VMC_tool.py L223](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/NES_VMC_tool.py#L223)）；
- 跨样本：`E_L_mean = Σ_n w_n E_n`，权重 `w_n ∝ |Ψ_n|`（machine_pow=1 采样 + 重要性加权回 |Ψ|² 测度，py 文件 L185）；
- 能级：`jnp.linalg.eig(E_L_mean)` 的**普通本征值**。
- 恒等式：`Loss = Re tr(E_L_mean) = Σ_k eig_vals_k`（迹 = 本征值之和，与日志完全吻合）。

### 方法二：`MV = SVA`（列子空间 Ritz 投影，给出旋转矩阵 v）

- 逐样本 Gram 乘积：`P_n†(HP)_n`、`P_n†P_n`，先把每个 walker 按 Frobenius 范数归一化；
- 跨样本：**均匀平均**（有效样本计数 N_eff，无 w 加权）得 `M̂、Ŝ`，并强制 Hermitian（[NES_VMC_tool.py L446-484](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/NES_VMC_tool.py#L446-L484)）；
- 解**广义本征** `M̂ v = λ Ŝ v`（`scipy_eigh`，[L528](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/NES_VMC_tool.py#L528)），λ 实、v 可用来旋转出物理态 `φ_k = Σ_j ψ_j v_{jk}`。

## 3. 差异根因（按重要性排序）

### 3.1 平均与"换基"不可交换（主因）

方法一在**逐样本不同的坐标系**里平均：`Σ w_n (Ψ_n⁻¹ HP_n)`——每个样本用自己的 `Ψ_n⁻¹` 做相似变换，
变换矩阵随 n 变，平均后的矩阵不是任何固定基下的投影算符表示。

方法二在**固定的列基 {ψ_j}** 里平均：`Σ (P_n† HP_n)`、`Σ (P_n† P_n)` 都是同一基下的 Gram 矩阵，
平均后才做一次 `Ŝ⁻¹M̂`。

两者一般不相等。只有当各样本 `Ψ_n` 成比例（列拟设在采样点上"形状一致"，即高度收敛、列近似本征态）
时才趋同。未收敛时，差异被重新分配到耦合最强的两端能级——与观测（E0/E3 等量反向、E1/E2 不动）一致。

### 3.2 样本权重（测度）不同

- 方法一：`w_n ∝ |Ψ_n|`，把 |Ψ| 采样重加权回 |Ψ|² 期望；
- 方法二：walker 均匀平均 + 每 walker 除 `‖P_n‖_F²`，等价于按 `1/‖P_n‖_F²` 重加权，**没有使用 w_n**。

因此方法二的 `(M̂, Ŝ)` 并不是 |Ψ|² 测度下真实 Gram 矩阵 `⟨ψ_i|H|ψ_j⟩、⟨ψ_i|ψ_j⟩` 的无偏估计
（对比：`NES_VMC_deflation.py` 里用全空间 16 维稠密振幅算的 `S=A†A、M=A†HA` 才是精确 Gram）。
所以方法二也**不是严格的变分上界**——本例中 E0 = −1.05663451 低于 CAS FCI 基态约 2 mHa 就是证据。

### 3.3 数值病态的放大方式不同

方法一逐样本 `solve(Ψ_n, HP_n)`：条件数差的样本（日志 cond(Ψ)≈8.8 只是第一个样本，尾部样本可大得多）
会把噪声直接写进 `E_n` 再进均值；且 `E_L_mean` 一般**非 Hermite**，普通 eig 产生复本征值
（日志虚部 ±5.9e-6 即非正规矩阵的信号）。

方法二只对**平均后**的 `Ŝ` 求逆（平均改善条件数），且 `M̂、Ŝ` 强制 Hermitian，`eigh` 保证实本征值。

### 3.4 已排除的因素

- **全局列规范 g**：方法一 `E_L` 在列缩放 `D_g` 下是相似变换、方法二 `(M̂,Ŝ)` 是合同变换，
  两者本征值都对 g 不变 → 不是差异来源。
- **shift 数值平移**：`e^{-shift}` 在 `Ψ⁻¹HΨ` 和 `P†HP/‖P‖_F²` 中都完全抵消 → 无关。
- **蒙特卡洛噪声**：若主因是噪声，四个能级应同幅抖动；实际 E1/E2 吻合到 1e-5、
  E0/E3 等量反向且总和不变 → 是估计器定义差异，不是噪声。

## 4. 该看哪个

- **训练优化的是 `tr(E_L) = Loss`**，梯度不约束"能级怎么分配"，所以两法总和一致是必然的。
- **方法一**是与 loss 恒等绑定的监控量（NES 论文的能级监控），其本征值分布无变分保证；
  适合看总能量/收敛趋势，看单能级时受逐样本 solve 噪声影响。
- **方法二**给出旋转矩阵 v、可提取物理态 φ_k（冻结/deflation 方案用的就是它），
  但当前样本版权重不是 |Ψ|² 测度的无偏 Gram，能级可低于精确值。
- **最终裁决建议用全空间精确对照**：H2/6-31G 物理空间仅 16 维，可用
  `FullSumState`/稠密振幅直接算精确 `M=A†HA、S=A†A` 的广义本征（项目里 deflation 脚本已验证），
  用它判断两条监控曲线各自的偏差方向与大小。

## 5. 复现要点

差异的来源全部可由日志验证：
1. `Σ eig_vals ≡ Loss`（恒等式）；`Σ lam` 与 Loss 差 ~5e-7（非恒等，数值巧合级的一致）；
2. E0/E3 偏差符号相反、量级相同（≈2.3 mHa），E1/E2 差 <1e-5；
3. 方法一有虚部（非 Hermite），方法二恒为实（强制 Hermite + eigh）。
