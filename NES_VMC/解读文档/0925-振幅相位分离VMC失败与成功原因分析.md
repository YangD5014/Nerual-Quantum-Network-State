## 一、三个层次的失败原因

原始 notebook 与初版 py 复现的失败不是一个问题，而是**三层叠加**的问题。三层依次剥开后才成功。

### 层次 1：jax.grad 的 dtype 限制（表面报错）

```
TypeError: grad requires real-valued outputs (output dtype that is a sub-dtype of
np.floating), but got complex128. For holomorphic differentiation, pass holomorphic=True.
```

**原因**：logψ = logA + 1j·φ 输出是复数。`jax.grad(f, holomorphic=False)` 要求 f 输出实数；`holomorphic=True` 又要求**参数**是复数。而本网络参数全为实数（`param_dtype=float`），两头都不满足，是 JAX 的"空档"。

**修复**：实参数、复输出函数的 Wirtinger 梯度拆解——

```python
∇logψ(σ) = ∇Re logψ(σ) + i · ∇Im logψ(σ)
# 分别 jax.grad 实部、虚部，再组合 r + 1j*i
```

### 层次 2：实参数 SR 的共轭结构错误（修完 1 仍然冻在 HF）

修完 dtype 后能量滑到 -0.99749 = HF 对角元后**完全冻结**（energy_std → 0.000000）。初期怀疑是复数 QGT 求解方式的问题，实验确认了两个事实：

- 复数 `solve(S_complex, g_complex)` 再丢虚部是**数学错误**：`Re(S⁻¹g) ≠ Re(S)⁻¹Re(g)`，复数耦合把更新方向搅乱；
- 实参数下 ⟨E⟩ 是实值函数，正确公式为：
  - force 梯度：`∇E = 2·Re⟨(E_loc − ⟨E⟩)·(∇logψ)*⟩`
  - 度量矩阵：实参数位移 dθ 是实向量，⟨|dlogψ|²⟩ = dθᵀ·**Re(S)**·dθ，虚部是反对称部分、对实二次型无贡献 → 度量取 `Re(S)`

**验证方法**：用 16 维稠密 H 算精确梯度做对照，采样 force 梯度与精确梯度 cosine ≈ 0.999，纯 SGD 能量正常下降 → 梯度机器本身正确。

### 层次 3：|ψ|² 采样的零方差冻结（真正的元凶）

即使梯度公式完全正确，SR 和 Adam 仍然精确冲进 HF 并冻死。决定性对照实验：

| 动力学 | 结果 |
|---|---|
| **精确 SR**（16 组态加权求和，同样 diag=0.01、lr=0.1） | 平滑越过 HF，200 步到 -1.0476 ✅ |
| 采样 SR（3000 / 15000 样本） | 冻死在 HF，std = 0.000000 ❌ |
| 采样 SGD / Adam / 动量 | 缓慢爬行或冲进 HF 冻结 ❌ |

**冻结机制**（这不是噪声问题，加大样本数无效）：

1. 轨迹下降过程中滑入 HF 本征态附近；
2. ψ 是 H 的本征态 ⇒ 每个被采样组态上 E_loc(σ) − ⟨E⟩ = 0 ⇒ **force 梯度严格为零**；
3. 反方向看更致命：携带梯度信号的激发组态 η 的贡献是 `w_η·E_loc(η)·∇logψη ∝ ψ_η·H·∂ψ`（**线性于 ψ_η**），但按 |ψ|² 采样时 η 的访问率是 ψ_η²（**平方**）。一旦 ψ_η² < 1/N，η 永远采不到，该项在采样估计里恒为 0，而"压缩 ψ_η"的力仍在 → ψ_η 单调衰减到机器零 → 不可逆冻结。

**为什么复参数 notebook 能成功？** 跟踪其 16 个组态的精确权重发现：它**从未进入 HF 盆地**——其随机初始化落在 FCI 一侧（初始 w_HF = 1.3e-4，E = -0.53，权重集中在一个非 HF 组态上），下滑途中 w_激发 一直在 O(1) 量级，采样始终健康。它不是机制更强，而是**初始条件运气好**。实参数版初始化 w_HF = 0.126，下滑必经 HF 盆地 → 触发冻结。

## 二、成功的关键：重要性加权采样

**修复**（通用方法，不针对小体系）：

```python
# 采样：按 |ψ|（machine_pow=1）而非 |ψ|²
sampler = nk.sampler.MetropolisSampler(hi, rule=single_rule,
                                       n_chains=150, sweep_size=32, machine_pow=1)

# 估计器：重要性权重 w(σ) = |ψσ|² / p(σ) ∝ |ψσ|
w_i = exp(Re(logψ(σ_i)))          # 未归一化权重
E  = Σ w_i·E_loc,i / Σ w_i        # 加权期望
g  = Σ w_i·(E_loc,i − E)·(∇logψ)*_i / Σ w_i
S  = Σ w_i·(ΔO*ᵀΔO)_i / Σ w_i     # 加权协方差，再取 Re
```

**原理**：按 |ψ| 采样时，稀有组态的访问率 ∝ ψ_η（比 |ψ|² 采样高数个量级）。被访问时其权重 w ∝ ψ_η，与 E_loc ∝ 1/ψ_η 相乘后**恰好恢复精确公式**的有限贡献（w·E_loc ∝ H·ψ_η 不发散）。采样的分布和估计器的权重组成了无偏估计，梯度信号不再丢失。

**效果**：Step 50 就穿过 HF（-0.9979），Step 100 已在 FCI 一侧（-1.0140），方差全程健康（~0.001–0.003），400 步收敛到 3.5 mHa。

## 三、经验教训

1. **零方差 = 零梯度陷阱**：VMC 中任何 H 的本征态都是采样估计的不动点。波函数塌缩到本征态后，标准采样式 VMC 的梯度严格为零，与 ansatz 表达力无关。做激发态/多态 VMC（deflation）时尤其危险——被冻结的基态 φ₀ 可能正是塌缩态。
2. **复参数 ≠ 更好的机制**：复参数 FFNN 与实参数振幅-相位 FFNN 的成功/失败差异，可能只是初始化轨迹差异。对比两个方案时应控制初始 |ψ|² 分布，否则结论不可靠。
3. **实参数 SR 规范**：∂E 和度量都必须在**取实部之后**求解；不能复数求解后丢虚部。
4. **诊断方法论**：小系统可先用稠密 H 建立三条基线——精确梯度 vs 采样梯度的 cosine、精确动力学 vs 采样动力学——快速区分"梯度机器错"还是"采样分布错"。本次若一开始做此对照，可少走很多弯路。
5. **采样的"平方 vs 线性"缺口**：梯度信号 ∝ ψ_η 而访问率 ∝ ψ_η²，中间差一个 1/ψ_η 的不可采样因子。当波函数在大基组上变尖锐时，此问题必然出现；重要性加权（或 machine_pow<2 的等效方案）是通用解。
