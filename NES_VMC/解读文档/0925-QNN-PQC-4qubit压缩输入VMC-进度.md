## 1. 目标与设计

用参数化量子线路（PQC/QNN）替代 FFNN 作为 VMC 的 Ansatz，核心要求：

1. **组态压缩编码**：8 位占据组态只用 4 个 qubit 承载（用户提出）。
2. PQC 输入是**实数**、最终 logψ 输出是**复数**。
3. 收敛目标接近 FCI 而不是停在 HF。

### 1.1 组态压缩编码（encode_configs）

将 8 位组态 σ = [s0..s7] 按相邻对压缩：

```
x_j = 2·σ[2j] + σ[2j+1] ∈ {0,1,2,3},  j = 0..3
```

例：HF [0 0 0 1 0 0 0 1] → x = [0,1,0,1]，即 "0101"。

**编码层的"放门/留空"直觉与推广**：用户直觉是每个 qubit 空则留空 (I)、占据则放 X 门，HF 编码层即 [I X I X]。但纯 X 门会**碰撞**：对内两个位置都可能被占（α 电子在 site0 → 对 (1,0)；在 site1 → 对 (0,1)，两者都会变成 X），而 H 恰好耦合这些组态且 ψ 值不同。因此实现为**旋转角编码**：

```
编码门 = RY(θ_j)·RZ(θ_j),  θ_j = (π/2)·x_j
  x=0 → I（|0⟩，北极，留空）
  x=2 → -iX（精确 X 门，差全局相位）
  x=1 / x=3 → Bloch 赤道上两个不同点的"广义 X 门"
```

四个取值 → 四个两两不同的量子态，无信息损失，且保留了"占据放门、空处留空"的结构。

### 1.2 PQC 结构（纯 JAX 态矢量模拟，4 qubits）

```
|0000⟩ → 编码层 RY(θ)RZ(θ) ×4 → [变分层 × L] → 测量特征 f
变分层 = RY(a)RZ(b) 单比特旋转 + CNOT 环 (0-1-2-3-0)
测量特征 f = [⟨Z0..Z3⟩, ⟨Z0Z1⟩, ⟨Z1Z2⟩, ⟨Z2Z3⟩, ⟨Z3Z0⟩]  （8 维实数）
```

- 态矢量 16 维，门实现为 `(...,2,2,2,2)` 轴重排 + 切片组合（`apply_1q` / `_apply_cnot`），
  支持任意批维（含 get_conn_padded 的 3D eta）。
- **已验证**：与稠密矩阵逐门模拟对比，特征误差 ~1e-16（CNOT、单比特门均逐一单元测试通过）。

### 1.3 复数输出头（量子-经典混合）

```
f (8维实数) → Linear(8→hidden) + tanh → 两个 Linear(hidden→1)
logψ = logA + i·φ     （全实参数、复输出）
```

### 1.4 VMC 引擎（沿用已验证框架，见 0925 失败成功分析文档）

- 实参数 Wirtinger 梯度：∇logψ = ∇Re + i·∇Im
- `machine_pow=1` 按 |ψ| 采样 + 重要性加权 w ∝ |ψ|（防 |ψ|² 采样的零方差冻结）
- 自然梯度 SR：∇E = 2Re⟨(E_loc−⟨E⟩)(∇logψ)*⟩，度量 Re(S)，diag_shift=0.01
- 150 chains × sweep 32 × chain 20 = 3000 样本/步
- **新增**：`exact_energy()` 全空间 16 组态精确能量，每 50 步打印，消除采样噪声干扰判断

## 2. 开发过程中修过的 bug（对复用 PQC 代码重要）

| Bug | 现象 | 修复 |
|---|---|---|
| `nnx.Rngs` 用法 | `key()` 报错 not callable | 直接 `rngs.params()` 拿 key |
| `ry(批量θ)` 构造 | `jnp.array([[c,-s],[s,c]])` 对批量 θ 生成 (2,2,B) 而非 (B,2,2) | 用 `jnp.stack` 显式构造 (...,2,2) |
| `_bcast` 广播维数 | ones 维数多一层，形状爆炸 (3,1,1,1,1)*(3,2,2,2) | `u.reshape(u.shape + (1,)*(p0.ndim - u.ndim))`，通用适配任意批维 |
| `_apply_cnot` 轴移位 | 移走 axc 后 axt 位置算错（调整方向搞反） | `if axt < axc: axt += 1`（位于其前的轴右移） |
| `exact_energy` 形状 | `logpsi[:,None,None]` 多一维， broadcasting 出荒谬复能量 | 改 `logpsi[:,None]` |
| float() 作用于复数 | jnp 复标量不能直接 float() | 先取 `.real` |

## 3. 当前结果

| 配置 | 步数 | 最终精确误差 | 备注 |
|---|---|---|---|
| L=3, hidden=16, scale=0.5, seed21 | 600 | 13.0 mHa | 首跑，平台期明显 |
| **A**: L=4, hidden=32, scale=0.1, seed21 | 800 | **6.9 mHa** | E = -1.04741 |
| **B**: L=3, hidden=16, scale=0.1, seed7 | 800 | **8.0 mHa** | E = -1.04637 |

（对照：实参数 FFNN 振幅相位分离版 400 步收敛到 3.5 mHa）

观察：
- 两种配置都在 ~7-8 mHa 处进入平台期，能量仍在缓慢下降但速度很慢；
- scale=0.1（PQC 参数小初始化，接近"纯编码层"起点）明显好于 0.5；
- 采样能量与全空间精确能量一致（±2 mHa 内），说明**瓶颈不在采样/梯度，而在优化动力学或 Ansatz 表达效率**；
- 平台能量 -1.046~-1.047 意味着双激发组态的振幅还没调到位（FCI 中 |c_d|≈0.05，贡献 ~7 mHa）。

## 4. 下一步计划（按优先级）

1. **提高采样量或学习率调度**：平台期梯度信噪比低，试 n_chains=300 或 cosine 退火 lr；
2. **减小 diag_shift**（0.01 → 0.001）：平台期自然梯度被正则压制；
3. **特征增强**：PQC 输出加 ⟨X_j⟩ 或 ⟨Z_jZ_{j+2}⟩ 关联特征；
4. **换 Adam/AdamW**：PQC 参数 + 经典头可能受益于自适应步长；
5. 多种子统计，确认平台期是否 seed 相关。
