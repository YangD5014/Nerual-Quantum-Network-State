## 1. 方案总览：要复现什么

NES-VMC（Natural Excited State Variational Monte Carlo）用 **K 个扩展副本**做联合行列式采样

$$
\Psi(X)=\det[\psi_i(x_j)],\qquad X\in\mathcal{H}^{\otimes K}
$$

矩阵局域能量 $E_L=\Psi^{-1}H\,\Psi$ 的特征值给出低能谱。为了**逐层抽取激发态**，文档提出：冻结一个已收敛的物理态 $\varphi_0$，构造投影子

$$
Q_0 = I - |\varphi_0\rangle\langle\varphi_0|
$$

然后**不显式构造** $Q_0HQ_0$（大系统下不可行），而是在每次 local-energy 计算时对 active 列做

$$
\chi_j = Q_0\psi_j,\qquad z_j = Q_0 H Q_0 \psi_j
$$

determinant 保持 K×K：$A^F[i,j]=\chi_j(x_i)$。这就是 **Matrix-Free Deflation**。

**本项目最重要的简化**：H2/6-31G 的物理 Hilbert 空间只有 **16 维**，因此：

- 哈密顿量 $H$ 可以显式取成 16×16 稠密矩阵（$H_{dense}=\mathrm{ha.to\_dense()}$）；
- 内积 $\langle\varphi_0|\psi_j\rangle = \sum_x \varphi_0^*(x)\psi_j(x)$ 可以对全部 16 个构型**精确求和**，不必用文档 §43 指出的大系统下最难的「联合 MCMC 估计 overlap」；
- 冻结态 $\varphi_0^*$ 可以直接存成 16 维复向量（等价于文档里「stop-gradient 冻结的一列 NN」，但省去了每次重求值开销）。

这三点让整个方案在小系统上可以**端到端精确验证**，是文档方案的一个「精确极限」版本。

### 2.1 投影子为什么写成三步而不是矩阵

文档的 matrix-free 核心是把「$QHQ$ 左乘一个向量」拆成三个廉价操作。设 $F$ 是正交归一冻结矩阵（$F^\dagger F=I_r$），则

$$
Q = I - FF^\dagger,\qquad
QHQ\,\psi_j = \underbrace{Q}_{③}\Big(\underbrace{H}_{②}\underbrace{\big(Q\psi_j\big)}_{①}\Big)
$$

对照代码 `_project`：

```python
def _project(A):
    if r == 0:
        return A, H_j @ A
    c   = (jnp.conj(F).T) @ A      # ① ⟨φ_m|ψ_j⟩
    chi = A - F @ c                # ① χ_j = ψ_j − Σ_m φ_m⟨φ_m|ψ_j⟩
    Hchi = H_j @ chi               # ② H χ_j
    c2  = (jnp.conj(F).T) @ Hchi   # ③ ⟨φ_m|Hχ_j⟩
    z   = Hchi - F @ c2            # ③ z_j = Q H Q ψ_j
    return chi, z
```

- `(jnp.conj(F).T) @ A` 即 $F^\dagger A$，第 `(m,j)` 元是 $\langle\varphi_m|\psi_j\rangle$，而 Q 不用显式存储换成了「原向量减去其在冻结子空间上的投影分量」。
- $r=0$（空冻结集）时 `_project` 退化为 `(A, H@A)`，正好回到标准 NES-VMC，从而**一条代码路径同时覆盖 Stage 0 与 Stage 1**。

## 3. `NES_VMC_deflation.py` 逐函数解读

文件只提供「工具箱」，训练循环在 notebook 里（与 `h2-6-31G-K4.ipynb` 结构一致）。

### 3.1 `build_full_stage(ha, hi)`

```python
H_dense = np.asarray(ha.to_dense()).astype(np.complex128)
all_states = np.asarray(hi.all_states())
```

把 NetKet 的哈密顿量算符和 Hilbert 空间「物化」成 numpy 稠密对象，供后面 numpy/scipy 精确求值。**约定**：`H_dense` 与 `all_states` 的行顺序严格一致（都是 `hi.all_states()`），这是 `_idx` 能正确取行的前提。

### 3.2 `states_to_idx_np(all_states, configs)`

把任意一批构型 `configs (..., 8)` 映射成 `all_states` 的行下标，训练循环里偶尔用。逐位比较 → `argmax`（每行必有且仅有一个全等）。

### 3.3 `amplitudes_full(single_machine_list, total_params, all_states_j)`

在全部 16 个构型上对 K 个 gauge-fixed 单列 machine 求值，得到

$$
A[i,j]=\psi_j(x_i)=\exp\big(\log\psi_j(x_i)-\log\psi_j(\text{ref})\big)
$$

注意 `machine_j` 返回的是**已经减掉 ref 的 log**，所以 `jnp.exp` 后直接就是（相对规范的）振幅。全程 `complex128`。

### 3.4 `extract_frozen_state(...)`

从当前 NES 参数里提取「该冻结的物理基态」。在 K 列张成的子空间上构造

$$
S_{ij}=\langle\psi_i|\psi_j\rangle=A^\dagger A,\qquad
M_{ij}=\langle\psi_i|H|\psi_j\rangle=A^\dagger H A
$$

解广义本征问题 $M v=\lambda S v$（`scipy_eigh(M, S)`），按实部升序，取最低本征矢：

$$
\varphi_0=\sum_j\psi_j\,v_{j0},\quad\text{归一化},\quad E_0=\langle\varphi_0|H|\varphi_0\rangle
$$

返回 `(phi0, E0, lam, v, A)`，其中 `A` 一并返回供重建其它物理态。

### 3.5 `orthonormalize_frozen(phi_list)`

把一组（可能近似正交的）冻结态做成正交归一矩阵 $F\in\mathbb{C}^{16\times r}$。用标准 Gram-Schmidt：

```python
p = p - q * (np.conj(q) @ p)   # 减去在 q 上的投影分量
```

空列表返回 `(1, 0)` 形状的空矩阵（作为 r=0 的信号）。$\varphi_0^*$ 用 `stop_gradient` 但本身已是常数，正交化更多是**数值卫生**——把 Monte Carlo/数值漂移引起的微小非正交性消除，保证 $F^\dagger F=I$、$Q$ 是干净的正交投影。

### 3.6 `make_deflation_bundle(...)` — 核心

构造四个 jitted 函数：采样器用的 `machine`、单样本 `machine_single`、局域能量 `el`、前向 `forward`。

关键结构：

```python
F = jax.lax.stop_gradient(F)             # 冻结矩阵是常数，不进梯度
def _amplitudes(total_params): ...       # (16, K)
def _project(A): ...                      # → (chi, z)
def _single(total_params, sigma_single):  # logΨ_F = slogdet(A^F)
def _batch(total_params, sigma_flat):     # (logψ, E_L) = (N,), (N,K,K)
```

- `_single`：把一个 32 维 walker（K×8）reshape 成 (K,8)，取全局 `A`、`chi,z` 的 `idx` 行拼成 $A^F$、(K,K)，用 `slogdet` 得 `logΨ_F`（数值稳定）。
- `_batch`：对 N 个 walker 共享同一份 `A/chi/z`（A 只依赖参数不依赖样本），$E_L^F = \mathrm{solve}(A^F, Z)$（等价于 $(A^F)^{-1}Z$，用 `linalg.solve` 更稳）。
- `machine = jax.vmap(_single, in_axes=(None, 0))`：NetKet 采样器按 `(params, sigma_batch)` 调用。

### 3.7 `make_deflated_grad_fn(forward, min_valid_ratio)` — 梯度

复刻 `NES_VMC_tool` 里的 NES-VMC 梯度公式，仅把 $\Psi\to\Psi^F$、$E_L\to E_L^F$：

$$
\mathrm{loss}_n=\mathrm{Re\,tr}(E_L^F_n),\qquad
\mathrm{grad}=\mathbb{E}_n\Big[\mathrm{tr}\big(E_L^F_n-\bar{E}_L^F\big)\cdot\overline{\nabla_{\text{holo}}\log\Psi^F_n}\Big]
$$

实现细节：

1. **有效性掩码**：剔除 `E_L`/`logψ` 发散的样本（矩阵求逆发散时 `loss` 非有限）。
2. **masked mean**：`E_L_mean = Σ(E_L_safe·valid)/n_valid`。
3. **权重 stop_gradient**：`w = stop_gradient(tr_centered)`，把「能量梯度控制变量」当作常数，只让 `logΨ` 对参数求导——这正是 NES 能量梯度 $\langle E_L\,\partial\log\Psi\rangle - \langle E_L\rangle\langle\partial\log\Psi\rangle$ 的方差缩减形态。
4. **holomorphic 梯度 + conj**：`objective(p)=Σ conj(w)·logΨ·valid`，`jax.grad(objective, holomorphic=True)` 后整体 `conj`，得到 `mean_n[tr_centered_n · conj(∇logΨ_n)]`。
5. 返回 `aux`（valid 比、是否 skip 等），训练循环据此决定是否跳过这一步（与非冻结版对齐）。

### 3.8 为什么 `stop_gradient(F)` 自动给出「投影切空间」

文档 §28 的要点：因为 $\varphi_0$ 被冻结，$\partial Q=0$，故 $\partial(Q\psi)=Q\,\partial\psi$，即 $O_\mu^F=Q\,\partial_\mu\psi/Q\psi$。代码里 `F = stop_gradient(F)` 让 autodiff 把冻结矩阵当常数，$Q$ 不参与求导，于是

$$
\nabla_\mu\chi_j=\nabla_\mu\big(\psi_j - FF^\dagger\psi_j\big)=Q\,\nabla_\mu\psi_j
$$

**自动满足**投影切空间，无需手写任何修正项——这是该实现最巧妙的一处：autodiff 的类型系统（stop_gradient）恰好对应物理上的「冻结 → 投影子不动」。

### 3.9 `make_deflated_qgt_fn(machine_single)` — 自然梯度 QGT

与 `NES_VMC_V1.make_qgt_fn` 同构：对每个样本取 holomorphic 梯度 $O=\nabla\log\Psi^F$，减均值后

$$
S=\frac1N \overline{O}_c^\top O_c,\quad S\leftarrow\frac12(S+\overline{S}^\top),\quad \text{返回 } S+\mathrm{diag\_shift}\,I
$$

训练时用 $\mathrm{solve}(S+\lambda I,\, g)$ 得到自然梯度。因为 `machine_single` 已含投影，$O$ 天然是投影切空间内的向量。

### 3.10 `extract_physical_states(chi_full, H_dense)` — 重建物理态

Stage 1 收敛后，在（已投影的）$\chi$ 列张成子空间上再解一次广义本征问题，得到 deflated 空间里的物理态 $\varphi_1,\varphi_2,\dots$。`M + 1e-14·S` 是为了稳住可能近奇异的 $S$（投影后 $\chi$ 列可能近线性相关）。

## 4. notebook 两阶段流程

### 4.1 `make_ansatz(seed)`

建 K 列总拟设（`NESTotalAnsatz_stable`，`hidden_dim = SINGLE_SIZE + K`）+ 拆分出 K 个 gauge-fixed 单列 machine：

```python
sms = [create_single_machine_gauge_fixed(a, Hatree_Fock)[0]
       for a in total.single_ansatz_list]
```

注意 `create_single_machine_gauge_fixed` 返回三元组 `(machine, graphdef, state)`，这里取 `[0]`。

### 4.2 `run_stage(...)` — 两条路径共用一个函数

```python
machine_single, machine, el, forward = dfl.make_deflation_bundle(sms, all_states, H_dense, frozen_vecs)
```

- `frozen_vecs = np.zeros((16,0))` → Q=I，标准 NES-VMC（Stage 0）；
- `frozen_vecs = F (16×1)` → deflated NES-VMC（Stage 1）。

后面是标准自然梯度循环：`MetropolisSampler` + `NESFermionHopRule` 采样 → `grad_fn` 求梯度 →（可选）`qgt_fn` 自然梯度 → `optax` SGD + `clip_by_global_norm` 更新。

### 4.3 Stage 0 → 冻结 → Stage 1

# Stage 0 收敛 → 提取 φ₀

## 5. 五个关键洞察

### 5.1 秩退化 → Stage 1 必须 fresh re-init

如果沿用 Stage 0 的 converged 列 $\{\psi_0,\dots,\psi_3\}\approx\{\varphi_0,\varphi_1,\varphi_2,\varphi_3\}$，投影后 $Q_0\psi_i$ 全落在 3 维子空间（$\varphi_0\in\mathrm{span}\{\psi_i\}$ 被投影掉），**4 个向量维度 ≤ 3 → $\det A^F\equiv0$，行列式必然奇异**。解决：Stage 1 用新的随机初始化，让 4 个 active 列在 $Q_0H$ 中重新张成不含 $\varphi_0$ 的 4 维空间（K 仍为 4，determinant 仍 4×4）。这是「冻结态」与「删列」的本质区别所在。

### 5.2 硬约束 vs 软约束

项目记忆里强调过：正交性是**变分空间的定义**（硬约束，由 $Q_0$ 强加），而不是损失函数里的一项 $\lambda|\langle\varphi_0|\psi\rangle|^2$（软约束 penalty）。本实现的 `_project` 是硬约束，因此验证时重叠² 可到 $10^{-32}$ 机器精度；软约束只能到 $10^{-6}$ 量级。

### 5.3 冻结向量 vs 冻结 NN 在小系统的等价性

文档在大系统里的做法是「把冻结果列 NN 的权重 stop-gradient」，每次构造 $\varphi_0(x)$ 都要重算。本系统只有 16 维，直接把 $\varphi_0$ 存成 16 维复向量，等价且更快；两者在数学上完全一致——都得到一个**冻结的、不进梯度的波函数快照**。

### 5.4 stop_gradient 即投影切空间

见 §3.8：$F$ 的 `stop_gradient` 让 $\partial(Q\psi)=Q\partial\psi$ 自动成立，autodiff 自动给出正确的投影切空间取梯度，任何手写修正都是画蛇添足。

### 5.5 全空间精确求和回避了最大难点

文档 §43 指出最难的 part 是「用 NES 联合 MCMC 稳定估计 $\langle\varphi_a|\psi_i\rangle$」。本实现用 16 维全空间精确求和绕开了它，属于方案在小系统上的「精确极限」，可用于**交叉验证**大系统近似的正确性——但本身不构成大系统下的性能方案。

## 附：与项目既有结论的一致性

- `hi.all_states()[0]` 非 HF（见 [投影哈密顿量方案1验证](../../文档/投影哈密顿量方案1验证-H2-631G-20260916.md)），本实现的 gauge ref 用的是 `Hatree_Fock`（即 `all_states()[0]`），**规范参考任意非零组态均可数学自洽**，仅物理命名与惯例不符。
- 冻结的是「收敛后的变分态」，是**近似本征态**；因此简化公式 $H-E|\varphi\rangle\langle\varphi|$ 在本实现的 $QHQ$ 一般形式下仍自洽（$QHQ$ 对任意冻结向量都成立，不要求 $\varphi$ 严格本征）。
- 自然梯度 QGT 沿用了项目里「$QGTJacobianDense$ 等价矩阵 + svd solver」绕过 netket 默认 SR 的 jax 版本冲突的思路（详见项目记忆），本实现手写 `make_deflated_qgt_fn` 并 `linalg.solve`，绕开了同一类兼容性问题。
