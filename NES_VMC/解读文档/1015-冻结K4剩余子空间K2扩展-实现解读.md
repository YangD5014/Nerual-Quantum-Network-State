# 冻结 K=4 + 剩余子空间 K=2 扩展：实现解读

> 对应方案文档：`NES-VMC冻结策略/[GPT1014]NES_VMC_Matrix_Free_Subspace_Extension.md`（方案 A）
> 实现日期：2026-10-15　体系：H2/6-31G（物理空间 16 维）　状态：**已验证成功**

## 1. 做了什么

K=4 RealFFNN 训练 300 步后，φ₀..φ₃ 已是哈密顿量的良好近似本征态（Rayleigh 偏差 1e-3–5e-4 Ha、与 FCI 重叠 0.998+）。本实现**冻结这四个态作为投影基**，新建 2 个可训练单态拟设 χ₀,χ₁，在它们的正交补 Q₄ = I − F F†（12 维）内继续运行 NES-VMC，最终提取 φ̂₄,φ̂₅——用「K=4 复用 + K=2 新训」达到 K=6 的效果。

结果（1500 步，172.9s）：

| level | λ（子空间精确） | ν（oracle 下限） | E（FCI） | λ−E | Var[E_loc] | FCI 重叠 | 冻结剩余重叠 |
|---|---|---|---|---|---|---|---|
| 4 | −0.02803225 | −0.02803284 | −0.02803278 | **0.0005 mHa** | 3.7e-7 | 0.99999 | 9e-33 |
| 5 | −0.01448578 | −0.01450344 | −0.01450343 | **0.0177 mHa** | 4.3e-7 | 0.99813 | 9e-33 |

对照 **K=6 全量训练 300 步基线**（`26-10-09-15-11`）：E₄ 误差 59.7 mHa、E₅ 误差 493 mHa。冻结扩展法好 2~3 个数量级——低四态已收敛并被冻结，新优化只需在补空间内拟合两个态，不受 K=6 联合训练里低能态被搅动的拖累。

## 2. 数学设定

- 冻结基 Φ = [φ₀..φ₃]（npz 载入，列归一但 Gram 非对角最大 0.072）→ **升序 Gram-Schmidt** 得正交归一 F (16,4)。投影子只依赖 span{Φ}，GS 与斜投影 Φ(Φ†Φ)⁻¹Φ† 差 5e-16，升序 GS 还保证 φ₀ 不被混合污染。
- 可训练列 A(θ) ∈ ℂ¹⁶ˣ²：两列 gauge-fixed 实参数复输出拟设振幅（ψ_j(HF)=1）。
- **投影态** χ = A − F(F†A)，即文档 §2.1 的 χ̃_a = Q₄χ_a。重叠系数 c = F†A 依赖 θ，但 F 是 stop_gradient 常量，autodiff 对 χ 求导自动得 **∂χ = Q∂A**——正是文档方案 A 要的投影切空间，无需任何手工修正项。
- 联合采样波函数：logΨ_F = log det χ[idx]（2×2 行列式，NES 结构不变，K 从 4 换成 2）。
- 有效算符：z = Q H χ（project→H→project，因冻结态只是近似本征态，[H,P]≠0，不能用简化式 H−ΣE|φ⟩⟨φ|，与项目既有结论一致）。
- E_L^F = χ[idx]⁻¹ z[idx]，loss = Re tr(E_L^F)。

**loss 的收敛目标（关键认知）**：tr(χ⁻¹z) 在列基变换下不变，其期望 = tr(S_χ⁻¹M_χ) ≥ ν₀+ν₁（Fan 极大极小），其中 ν 是 **QHQ 压缩算子**的最低两本征值，不是 H 的 E₄+E₅。由于冻结态非严格本征，ν 与 E 之间存在「冻结偏差下限」——**训练收敛到 ν 即方法饱和**，因此实现前先算 oracle：

```
ν = (−0.02803284, −0.01450344)，与 FCI E₄,E₅ 偏差仅 −5.5e-5 / −1.1e-6 Ha
```

偏差可忽略，且 oracle 本征矢与 FCI 重叠 0.9999999。这一步把「方法误差」与「训练误差」解耦：最终 λ−ν = 6e-7 / 1.8e-5 Ha，说明训练几乎打满方法上限。

## 3. 代码结构

### 3.1 新增 `NES_VMC_deflation_real.py`（实参数 deflated 工具箱）

现有 `NES_VMC_deflation.py` 的 grad/QGT 走 `jax.grad(..., holomorphic=True)`，只适用复参数；RealFFNN 是实参数+复输出，必须重写。本模块是**唯一新写的算法代码**：

| 函数 | 作用 |
|---|---|
| `load_and_orthonormalize_frozen(npz_path, hi, min_residual=0.1)` | 载入 φ_raw → GS 正交归一 F；**双重断言**：npz `all_states` 与 `hi.all_states()` 逐行相等（防基矢序张冠李戴）、每步 GS 残差 >0.1（堵 `orthonormalize_frozen` 近零分支仍 append 未归一向量的坑） |
| `deflation_oracle(F, H_dense, n_keep)` | 对角化 QHQ → ν、oracle 本征矢、全谱（前 r 个 ~0 即冻结方向被压平，实测 4 个零模） |
| `grad_logpsi_real_single` | 单样本 ∇logΨ = ∇Re(logΨ) + i·∇Im(logΨ)（Wirtinger，实参数） |
| `importance_weights_from_logpsi` | w_i ∝ \|Ψ_F(σ_i)\|（valid 上 softmax 归一） |
| `make_deflated_grad_fn_real(machine_single, forward)` | 力梯度 grad = 2·Re Σ_n w_n·tr(E_L,n − Ē_L)·conj(∇logΨ_n)，float 叶子；aux 含 valid_ratio/ESS/should_skip |
| `make_deflated_qgt_fn_real(machine_single, machine_batch)` | O=∇logΨ（Wirtinger），w 加权中心化，S = Re(O†WO) + diag_shift·I |

公式与已验证的 `nes_vmc_gradient_stable_gauge_real`（K4 RealFFNN 脚本）逐项同构，仅把 (machine, E_L) 换成 deflation bundle 的 (machine_single, forward)，并去掉 g（列规范）路径。

### 3.2 新增 `H2_631G_8Qbit_K2_frozen4_deflation_RealFFNN.py`（训练脚本）

直接复用既有组件：`NES_VMC_deflation.py` 的 `make_deflation_bundle`（χ、z、machine、forward、E_L 全套）与 `extract_physical_states`（M=χ†Hχ, S=χ†χ 广义本征）；`NES_VMC_V1.py` 的 `create_single_machine_gauge_fixed`、`NESFermionHopRule`；`H2_6_31G_8Qbit_K2.py` 的 K=2 扩展空间 `hi_ext/ext_edges`（hi 与 K4 模块相同，基矢序一致）。

流程：
1. 载入 npz → GS → oracle 预检（不通过则停）；
2. **fresh 随机初始化** K=2 拟设（工程惯例：Stage1 必须新 init；沿用旧列会使投影后向量落在低维子空间致行列式奇异），循环换 seed 直到 cond(χ_full)<1e6；
3. `make_deflation_bundle` 出 machine/forward → `NESFermionHopRule(K=2)` + `MetropolisSampler(machine_pow=1, n_chains=16, sweep=20, chain_length=200)`；
4. 每步：采样 → 实参数 deflated 梯度 → per-param 裁剪(0.5) → 自然梯度 `solve(Re(S)+0.1I, g)` → optax(clip 20 + sgd 0.1) 更新；
5. **监控用全空间精确量**（16 维下开销可忽略）：每步算 χ → 2×2 广义本征 λ、cond(S_χ)、max|A|、‖F†A‖——无 MC 噪声，比样本估计器干净；
6. 结束：`extract_physical_states` 出 φ̂₄,φ₅ → 验收表 → 存 npz/pkl/log + 5 联图（λ 收敛/Loss/能量误差-化学精度带/采样健康度/梯度-漂移）。

采样配方沿用 1006 修复结论：machine_pow=1 按 |Ψ_F| 采样 + w∝|Ψ_F| 重要性加权，防止投影态节点附近稀有组态梯度信号被 |Ψ|² 测度淹没。

## 4. 实测发现与坑

1. **冻结分量漂移（新平坦方向）**：ψ_j → ψ_j + Σα_mφ_m 对 Ψ_F 完全不可见（Qφ=0），该方向梯度恒零、QGT 零行。实测 max|A| 无界漂到 ~1.15e3 触发 512 次告警，但 float64 下 χ 有效位充足、结果无损（Var~4e-7）。**不要**加 |⟨φ|ψ⟩|² 惩罚——gauge-fixed 列不可能严格落在 Q 空间，惩罚有偏。更大体系需考虑定期重投影或弱拉回。
2. **不需要 gauge reset**：deflated bundle 直接 slogdet(χ[idx])，列已由 ψ_j(HF)=1 钉死，K4 的列均值漂移问题不存在。
3. **loss 尺度与 K4 完全不同**：目标是 Σν≈−0.0425 Ha（K4 是 −2.0 量级），日志/看图时别按 K4 经验判断。
4. **E₄/E₅ 间隔仅 0.0135 Ha**：300 步时 φ̂₅ 与 FCI 重叠只有 0.89（列混合未解耦），1500 步升到 0.998。子空间两态近邻时收敛比基态慢，验收要看到重叠稳定。
5. 全程 valid_ratio=1.0、cond(S_χ)≤123、ESS 占比 ~0.65——16 维 + 2 态行列式没有采样饥饿。
6. 训练极快：0.12s/步（bundle 每 walker 重算 16×2 网络前向，tiny FFNN 下可忽略）。

## 6. 与文档 §9「最核心待解决问题」的对应

> 如何在不显式构造大规模哈密顿量的前提下，将四个已收敛 NES-VMC 态作为冻结的投影基，并构造与投影后波函数一致的两态联合采样、矩阵元估计和梯度更新？

本实现给出的肯定答案（16 维精确极限版）：联合采样直接用 log det(Qχ)[idx] 的 2×2 NES 行列式；梯度用实参数 Wirtinger + |Ψ_F| 重要性加权，∂χ=Q∂A 由 autodiff 免费给出；矩阵元/提取用全空间精确和。**尚未做的**：文档 §3.3 的 MC 重叠估计与 §5 的大体系联合采样推导（本实现 c=F†A 用精确求和，扩展到不可枚举空间时需换成交叉/重要性采样估计 c，漂移监控与重投影策略也要补上）；方案 B（H+μP₄）未测试。
