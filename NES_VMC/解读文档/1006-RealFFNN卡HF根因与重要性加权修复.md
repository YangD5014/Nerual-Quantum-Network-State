# NES-VMC K=2 实参数 FFNN 卡 HF 问题：背景、根因与重要性加权修复

## 1. 问题背景

H2/6-31G（8 自旋轨道、物理空间 16 维）上做 NES-VMC 多能态训练（K=2，两列基矢 + 2×2 E_L 矩阵 + 广义本征求 {E₀, E₁}）。两个 notebook 唯一实质差异是 ansatz 参数化：

| | Complex FFNN（成功） | RealFFNN（失败） |
|---|---|---|
| 参数 | 复数权重 | 实数权重，logΨ = logA + iφ（振幅-相位分离共享骨干） |
| 末步 E₀ | −1.04571 Ha（误差 8.6 mHa） | **−0.99746 Ha = E_HF（−0.9975）** |
| 末步 E₁ | −0.94977 | −0.95726（= 真实第一激发态，误差 0.6 mHa） |
| Loss 平台 | −1.9955 | **−1.9547 = E_HF + E₁** |

RealFFNN 的 E₀ 在前 ~40 步到达 HF 能量后，此后 260 步锁死不动（±0.003 Ha 振荡），末段 raw 梯度范数从 1.5 衰减到 ~0.006；复参数版全程梯度 0.6–0.8 不断流。

## 2. 根因：|Ψ|² 采样的双激发饥饿 → 零方差冻结

### 2.1 塌缩目标不是"没收敛"，而是收敛到错误本征态对

末步采样分布（3200 样本，按相对真 HF=[1,0,0,0,1,0,0,0] 的翻转数分类）：

| 组态 | RealFFNN | Complex FFNN |
|---|---|---|
| HF（0 翻转） | 50.0% | 45.0% |
| 单激发（2 翻转） | 49.9% | 49.9% |
| 双激发（≥4 翻转） | **0.1%** | **5.1%** |

两列基矢张成 {HF, 单激发} 支撑集，而该支撑集上 H 的最低两个本征态恰好是 HF 与第一激发态——2×2 E_L 矩阵已严格对角化、Loss 无下降空间，E₁ 收敛到精确值 0.6 mHa 正是"本征态对已到位"的旁证。FCI 基态比 HF 低的 56.9 mHa 关联能**全部来自双激发组态**，支撑集里没有它们，E₀ 就永远到不了 −1.054。

### 2.2 饥饿的正反馈机制

netket `MetropolisSampler` 默认 `machine_pow=2`，按 q(x) ∝ |det Ψ(x)|² 采样（本 notebook 中 total_machine 的 logΨ = log det[L(x)]，machine_pow 即行列式的指数）。力梯度中连接组态 η 的贡献 ∝ **ψ_η**（一次方），而它被采到的频率 ∝ **|ψ_η|²**（平方）：

```
双激发振幅略降 → 采样频率按平方降得更快 → 梯度信号更弱 → 振幅再降 → …… → 严格 0
```

一旦样本全部落在 {HF, 单激发}，HF 是 H 的本征态使 E_loc 方差为 0，梯度**数学上恒等于 0**（不是"小"）。SR、diag_shift、梯度裁剪、gauge reset 都无法为从未出现的组态生成信号。

### 2.3 为什么只有实参数版掉进去

logΨ = logA + iφ 结构下相位头不改变 |Ψ|² 分布，实数振幅头平滑，随机初始化后梯度第一步就把列 1 拉向可见最低组态 HF，触发 2.2 的锁死。复参数版随机初始化使 HF 初始权重 ~1e-4，全程覆盖宽支撑集，从未进入 HF 盆地——**是盆地归属差异，不是表达力差异**。

## 3. 解决方案：machine_pow=1 采样 + 重要性加权（IPW）

### 3.1 原理

采样与期望定义测度解耦：

- 目标测度（不变）：π(x) ∝ |Ψ(x)|² —— Loss、力梯度、QGT 的期望都定义在 π 下；
- 提议分布（改）：q(x) ∝ |Ψ(x)|（`machine_pow=1`）；
- 权重（补）：w(x) = π(x)/q(x) ∝ |Ψ(x)|，所有 ⟨·⟩ 改为加权平均 ⟨O⟩_π = Σ wᵢO(σᵢ)/Σwᵢ。

被积函数 w·E_loc·∇logΨ ∝ |Ψ|²·(...) 逐项恢复 π 下的精确公式，**无偏性由权重保证**；同时稀有组态访问率从平方律（ψ_d~1e-3 → 1e-6）提升到线性律（→ 1e-3），**梯度信号不再断流**。二者是组合拳：只改 machine_pow 不加权 → 收敛到错误测度；只加权不改采样器 → 权重恒 1 等于没改。代价是权重方差（ESS 下降），实测收益远大于该代价。

实现细节：logΨ 含逐样本 shift 与列规范 g（常数平移），在归一化权重中严格抵消，故直接取 `exp(Re logΨ)` 并在 valid 样本上先减 max 防溢出、再归一化（Σw=1）。

### 3.2 代码修改（notebook 内）

**Cell 6（采样器）**：`MetropolisSampler(..., machine_pow=1)`，超参回显同步标注。

**Cell 5（梯度/QGT 兼容层）**，对齐姊妹脚本 `FFNN振幅相位分离版-VMC-1.py`：
- 新增 `_importance_weights(machine, params, x, g, valid)` → 归一化 w∝|Ψ|；
- `nes_vmc_gradient_stable_gauge_real`：`E_L_mean`、loss、力梯度 `2Re⟨(trE_L−⟨trE_L⟩)(∇logΨ)*⟩` 全部由均匀 masked 均值改为 w 加权（wv 已归一化，直接 Σwv·(...)）；
- `make_qgt_fn_gauge_real`：`O_mean` 与度量 S 改为加权协方差，取 Re(S)（实参数度量，虚部反对称无贡献）；
- ∇logΨ 仍用 Wirtinger 拆分（∇Re + i·∇Im），接口不变，Cell 7 训练循环零改动。

## 4. 验证结果（2026-10-04，300 步完整运行）

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 末步 E₀ | −0.99746（=HF 锁死） | **−1.00082（越过 HF）** |
| E₀ 误差轨迹 | 56.9 mHa 平台 | 57.5 → 56.5 → **53.5 mHa，持续下降** |
| 末步双激发频率 | 0.1% | **5.7%**（step150 时 4.5%，稳定非零） |
| 末段 raw 梯度 | ~0.006（饿死） | ~0.019（不断流） |
| 末步采样 | HF 50% / 单 50% / 双 0.1% | HF 45.6% / 单 48.7% / 双 5.7% |

**机制层面锁被部分打破**：E₀ 不再钉在 E_HF，双激发恢复有限访问率，梯度持续非零。但**仅靠 IPW 不足以收敛到化学精度**——见第 6 节更正。

## 6. 重要更正（2026-10-06 → 10-07）：IPW 必要但不充分，真正修复是「每步重置采样链」

### 6.1 证伪：单独 IPW + 调 diag_shift 仍卡 HF

新 notebook `H2_631G_8Qbit_K2_Ansatz_A_RealFFNN_IPW.ipynb` 首版（machine_pow=1 + IPW，`qgt_diag_shift=0.01`、`N_ITER=600`）完整 600 步实测：

| 指标 | 10-04 (shift=0.1, 300步) | 10-06 (shift=0.01, 600步) |
|---|---|---|
| E₀ 末步 | −0.99845（缓慢下探） | **−0.99751 = 精确钉死 HF** |
| E₀ 误差 | 53.5 mHa（在降） | **56.9 mHa（step100 后完全平坦）** |
| E₁ 误差 | 0.6 mHa | 0.09 mHa（极准） |
| Loss 末步 | −1.956 | **−1.9553 = E_HF + E₁_true 精确吻合** |

且 `diag_shift=0.01` 比 `0.1` **更糟**（0.1 时 E₀ 还在下爬，0.01 直接钉死），第 4 节"下一步建议 shift→0.01"方向反了。

### 6.2 根因升级：K=2 的「二维本征子空间」塌缩

E₁ 收敛到精确第一激发态（0.09 mHa）是决定性线索：K=2 两列基矢张成了 **{HF, 第一激发态} 二维本征子空间**，两列都是 H 的严格本征态 → E_L 矩阵对角、梯度恒零 → 整个子空间被锁死。这比单态 VMC 的「HF 零方差冻结」更顽固：IPW 把双激发覆盖率从 0.1% 提到 3–5%，但两列已同时是本征态，那点梯度信号不足以把子空间旋到含双激发成分的 FCI 基态方向。

### 6.3 真正修复：对齐参考实现的「每步 reset + 短链」采样策略

精读收敛成功的参考 notebook `量子-经典混合式 Ansatz/FFNN振幅相位分离版-VMC-1.ipynb`，逐项对比找出当前 notebook 遗漏的实质差异（权重公式、diag_shift、lr 本就相同）：

| 项 | 参考（成功） | 当前首版（卡 HF） |
|---|---|---|
| **采样链** | **每步 `sampler.reset()` + `chain_length=20`** | 链跨步延续，`chain_length=200` |
| hidden_dim | `SINGLE_SIZE*2+4 = 20` | `SINGLE_SIZE+K = 10` |
| 链数 | 150 | 16 |

**决定性差异 = 每步 reset**：参考实现每步把 MCMC 链重新随机初始化到 Hilbert 全空间，双激发组态每步都有全新访问机会，支撑集根本无法塌缩进 {HF,单激发} 盆地；而链跨步延续时，一旦分布滑向盆地，链就在其中随机游走，IPW 权重救不回从未到访的组态。

**修改**：cell 7 采样前加 `sampler_state = nes_sampler.reset(...)`；cell 6 `N_CHAINS 16→150`、`N_SAMPLES_PER_CHAIN 200→20`、`hidden_dim 10→20`。

### 6.4 修复后验证（2026-10-07，600 步完整运行）

| 指标 | 首版(仅IPW) | 加每步reset后 |
|---|---|---|
| 末步 E₀ | −0.99751（=HF） | **−1.05377** |
| **E₀ 误差** | 56.9 mHa | **0.576 mHa（化学精度内）** |
| E₁ 误差 | 0.09 mHa | 0.002 mHa |
| Loss 末步 | −1.9553 | **−2.0117（理论 −2.0123）** |
| 末步双激发频率 | 3.3% | **20.3%** |

E₀ 误差轨迹：1390 → 3.0 → 0.75 → 0.63 → 0.59 → **0.58 mHa**，前 100 步即进入化学精度并保持。**基态成功收敛到 FCI，不再卡 HF。**

## 7. 可迁移结论（修订）

1. **NES-VMC K=2 卡 HF 的根因是二维本征子空间塌缩**（两列同时成为 H 的本征态 → E_L 对角 → 梯度恒零），比单态的 HF 零方差冻结更顽固。
2. **machine_pow=1 + IPW 必要但不充分**：它把双激发访问率从平方律提到线性律，但救不回「链从未到访的盆地」。
3. **通用修复 = 每步 reset 采样链 + 短链**：让 MCMC 每步从全空间随机态重新出发，从机制上阻止支撑集塌缩；配合足够容量（hidden_dim≥20）与样本量（≥3000）。这是参考单态实现收敛的真正关键，而非权重公式本身。
4. **诊断三件套**：末步采样按翻转数分组、Loss 平台值与 E_HF+E₁ 对账、E₁ 是否收敛到精确本征值（本征子空间塌缩的旁证）。
5. **调参教训**：`diag_shift` 不是越小越好——0.01 比 0.1 更容易钉死 HF；软方向放大让塌缩更快锁死。
