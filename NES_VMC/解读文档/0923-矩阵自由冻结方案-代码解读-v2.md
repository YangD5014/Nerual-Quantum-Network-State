## 1. 为什么需要 v2（与 v1 的本质区别）

v1（`NES_VMC_deflation.py`）是**最小验证方案**：它直接调用 `ha.to_dense()` 拿到 16×16 哈密顿矩阵、
枚举全部 16 个 Hilbert 空间态求 overlap、用 `scipy_eigh` 做全空间广义本征分解。它在 H2/6-31G
（物理空间仅 16 维）上成立，但**无法推广到大系统**——希尔伯特空间指数爆炸，`to_dense()` 和全空间
枚举都不再可行。

v2 是**完整可用方案**，三条硬约束全部满足：

| 约束 | v1 | v2 |
|---|---|---|
| 哈密顿量 | `ha.to_dense()` 显式 16×16 矩阵 | 只用 `ha.get_conn_padded(x)` 局部连接作用 |
| 采样 | 无采样，直接枚举全空间 | 两个 Metropolis 采样器（MCMC） |
| 冻结态表示 | 稠密 16 维复向量 | Stage-0 收敛列 NN 的 stop-gradient 线性组合 |

v2 的底层计算只在**连通组态**之间跳转，代价正比于哈密顿量的局部连接数（多体系统下为多项式），不随希尔伯特空间维度爆炸。

## 2. 核心数学：矩阵自由 deflation

### 2.1 哈密顿量只经 `get_conn` 作用

不构造 `H` 矩阵，而是对一个态 `ψ` 逐点计算其「H 作用」：

```
(Hψ)(x) = Σ_{x'∈conn(x)} H[x,x'] ψ(x')
```

NetKet 的 `ha.get_conn_padded(x)` 返回 `(x_primes, mels)`，分别是被 `x` 连通的组态列表与对应的
非零矩阵元。v2 中所有对 `H` 的调用都收敛到这一个函数（`Ham_psi_scaled` / `Ham_Psi_scaled`，来自 `NES_VMC_V1`），
其中 `Ham_Psi_scaled` 进一步封装成对「所有 walker × 所有列」的批处理作用：

```
HPsi[i,j] = (Hψ_j)(x_i)
```

### 2.2 冻结态 = 冻结列 NN 的线性组合（不是稠密向量）

Stage-0 收敛后得到 K 个「列」波函数 `ψ_k`（gauge-fixed 单列 machine）。基态旋转系数 `v0`
由 K×K 广义本征问题 `M v = λ S v` 给出（`compute_lam_v_from_samples` 在 MCMC 样本上估计 M、S，
`solve` 出的 K×K 复 Hermitian 问题，**不枚举全空间**）。

冻结态定义为：

```
φ_0(x) = Σ_k v0[k] · ψ_k(x)
```

其中 `v0` 与 `ψ_k` 的参数都被 `jax.lax.stop_gradient` 冻结。`make_frozen_bundle` 把 `φ_0` 做成一个
「波函数快照」，对外只暴露三个可调用的矩阵自由接口：`logphi_walker(x)`（log φ₀）、`hphi(x)`（H φ₀）、
`machine(params, sigma)`（log φ₀，供采样器）。

> 关键点：`φ_0` 是**函数**（列 NN 组合），不是向量。这是能在大系统上做 deflation 的前提。

### 2.3 overlap 标量用「ratio estimator」估计（文档 §43 最难的部分）

deflation 需要三个全局标量（对 `active` 列 `ψ_j` 而言）：

```
c_j = ⟨φ_0|ψ_j⟩ / ⟨φ_0|φ_0⟩
h_j = ⟨φ_0|H|ψ_j⟩ / ⟨φ_0|φ_0⟩
E_0 = ⟨φ_0|H|φ_0⟩ / ⟨φ_0|φ_0⟩
```

`estimate_overlaps` 用一个**独立的 `|φ_0|²` 采样器**做重要性采样。因为

```
E_{|φ_0|²}[ ψ_j / φ_0 ] = Σ |φ_0(x)|²/⟨φ_0|φ_0⟩ · ψ_j(x)/φ_0(x)
                        = Σ φ_0*(x) ψ_j(x) / ⟨φ_0|φ_0⟩ = ⟨φ_0|ψ_j⟩/⟨φ_0|φ_0⟩ = c_j
```

（利用了 `|φ₀|²/φ₀ = φ₀*`），所以 `c_j = E_{|φ₀|²}[ψ_j/φ₀]` 在统计意义下严格成立。同理 `h_j = E[(Hψ_j)/φ₀]`、
`E_0 = E[(Hφ₀)/φ₀]`。数值上用统一的 per-sample shift 稳定 `ψ_j/φ₀`、`(Hψ_j)/φ₀`、`(Hφ₀)/φ₀`
（shift 在比值中约分），并掩码剔除 `|φ₀(x)|` 过小的样本。

### 2.4 deflated 局域能量 = Q H Q（不是裸 H Q）

投影算子 `Q₀ = I − |φ₀⟩⟨φ₀|/⟨φ₀|φ₀⟩`。déflated 列 `ψ_j^F = Q₀ ψ_j = ψ_j − c_j φ₀`。
局域能量的列矩阵 `E_L^F = (A^F)^{-1} Z`，其中 `A^F` 是 déflated 振幅矩阵、`Z` 是 **Q₀HQ₀** 作用：

```
A^F[i,j] = ψ_j(x_i) − c_j φ₀(x_i)
Z[i,j]   = (Hψ_j)(x_i) − c_j (Hφ₀)(x_i) − φ₀(x_i)·(h_j − E₀ c_j)
```

第二条线的推导：`Q₀HQ₀ψ_j = Hψ_j − c_j Hφ₀ − φ₀ ⟨φ₀|(Hψ_j − c_j Hφ₀)⟩/⟨φ₀|φ₀⟩`，
而 `⟨φ₀|Hψ_j⟩/⟨φ₀|φ₀⟩ = h_j`、`⟨φ₀|Hφ₀⟩/⟨φ₀|φ₀⟩ = E₀`，故 `= Hψ_j − c_j Hφ₀ − φ₀(h_j − E₀ c_j)`。✓

> 用 QHQ 而非裸 HQ 是 v1 已验证实现与数值顾问双重确认的结论——裸 HQ 会漏掉投影后的 `φ₀` 反投影项。

### 2.5 梯度与投影切空间

`make_deflated_grad_fn_v2` 复刻标准 NES-VMC 梯度公式，只是把 `Ψ → Ψ^F`、`E_L → E_L^F`：

```
loss_n = Re tr(E_L^F_n)
grad   = mean_n [ tr(E_L^F_n − mean) · conj(∇_holo log Ψ^F_n) ]
```

因为 `φ_0`（及 `c/h/E₀`）对 active 参数都是 `stop_gradient` 常量，`∂(Q₀ψ)=Q₀∂ψ` 自动成立——梯度天然躺在投影后的切空间，无需显式地投影梯度。

## 3. 逐函数解读（代码 ↔ 数学映射）

### 3.1 `make_frozen_bundle(frozen_sms, frozen_params, v0, ha)`

把 Stage-0 的 K 列 gauge-fixed machine（`frozen_sms`）+ 收敛参数（`frozen_params`）+ 基态旋转系数（`v0`）
打包成冻结态快照。

- `v0`、`frozen_params` 先 `jax.lax.stop_gradient`，切断一切反传。
- `_col_logs(xw)`：对**单个 NES walker** `xw (K,n_spin)` 算 `[i,k]=logψ_k(x_{w,i})`，返回 `(K,K)`。
- `_logsumexp_combo(logs)`：稳定 log-sum-exp 组合 `logφ₀ = log Σ_k v0[k]ψ_k`。
- 对外接口：
  - `frozen_logs(x)`：config 批 `(N,n_spin)` → `(N,K)`（供 `estimate_overlaps`）。
  - `logphi(x)`：单个 config `(n_spin,)` → 标量 logφ₀（供采样 machine）。
  - `logphi_walker(x)`：NES walker 批 `(N,K,n_spin)` → `(N,K)`（供 `_core` 的 shift 对齐）。
  - `hphi(x)`：NES walker 批 → `(N,K)` 的 `(Hφ₀)(x_i)`，`H` 只经 `get_conn` 作用。
  - `machine(params, sigma)`：`(params, sigma) -> logφ₀(sigma)`，供 NetKet 采样器（`2·Re` 得 `|φ₀|²`）。

> **为什么逐行 vmap？** `SingleStateAnsatz.__call__` 内部用 `jnp.squeeze`，当批维为 1 时会把批维压掉，
> 导致 `N=1`（如 QGT 里的 `machine_single`）时形状坍缩。这里对「单个 walker」显式计算后 `vmap`，从根上规避。

### 3.2 `estimate_overlaps(frozen_bundle, active_sms, active_params, x_frozen)`

在 `|φ₀|²` 采样样本 `x_frozen (N,n_spin)` 上估计 `c/h/E₀`，返回 host 侧 numpy（stop_gradient 常量）。

- 统一 shift `s = max(Re[logψ 冻结∪active])`（per-sample），比值中约分。
- `phi = Σ v0·exp(logs_F − s)`（≡ φ₀·e^{-s}），`psi = exp(logs_A − s)`，`Hψ`/`Hφ₀` 同理经 `Ham_psi_scaled(... shift=s)`。
- `_ratio_mean_2d` / `_ratio_mean_1d`：对 `num/φ₀` 做 `|φ₀|>1e-8` 掩码平均，分别得到 `(K,)` 与标量。
- 注意结果又被 `stop_gradient`，它们只是「全局常量」，不进 active 梯度。

### 3.3 `make_deflation_bundle_v2(active_sms, frozen_bundle, ha, K, n_spin)`

核心工厂，产出四个 jitted 函数：`machine_single`、`machine`、`el`、`forward`。真正干活的是 `_core`：

```
x = sigma_flat.reshape(N,K,n_spin)                     # 还原成 (N,K,n_spin) walker
logP = [ vmap(active_sms[j])(x) for j ]  → (N,K,K)     # logψ_j(x_i)
s    = stop_gradient( max Re( logP ∪ logφ₀ ) )         # per-walker 安全 shift
M    = exp(logP − s)                                    # 稳定振幅矩阵
HM   = Ham_Psi_scaled(ha, active_sms, params, x, s)    # e^{-s}·(Hψ_j)(x_i)
```

- 无冻结（`frozen_bundle=None`，Stage 0）：`A^F=M`、`Z=HM`，退化为标准 NES-VMC。
- 有冻结（Stage 1）：`A^F = M − c·φ₀·e^{-s}`、`Z = HM − c·Hφ₀·e^{-s} − φ₀·e^{-s}·(h−E₀c)`。
- 行列式回到对数域：`log|det(e^{s}·A^F)| = K·s + slogdet(A^F)`，即 `log_psi = K·s + log_abs + i·arg(sign)`。
- 局域能量 `E_L = solve(A^F, Z)`，因 `A^F` 与 `Z` 同乘 `e^{s}`，`E_L` 是 shift 不变的。

> **shift 稳定化的意义**：`exp(logP)` 在 `Re(logP)≳88`（complex64）会溢出。参考实现 `NESTotalAnsatz_stable`
> 正是靠 `shift=max Re(L)` 防溢出的。v2 把同一技巧推广到 deflation 情形：`s` 取主动列与冻结态 log 的联合最大实部，
> 保证 `exp(logP−s)`、`exp(logφ₀−s)` 都不溢出，且 `s` stop_gradient，梯度仍然正确（`∂log|det| = tr(A^−1 ∂A)` 与 shift 无关）。

### 3.4 `make_deflated_grad_fn_v2(forward, min_valid_ratio)`

- 由 `forward` 得到 `(logΨ^F, E_L^F)`；`loss = Re tr(E_L)`，有效样本掩码去除 NaN/Inf。
- 通过 `jax.grad(..., holomorphic=True)` 对 `objective(p) = Σ conj(w)·logΨ^F(p)`, `w=stop_gradient(tr(E_L−mean))`
  求梯度，再取共轭、除有效样本数——这是 NES-VMC 能量梯度的标准形式。

### 3.5 `make_deflated_qgt_fn_v2(machine_single)`

- `grad_logpsi = jax.grad(machine_single, argnums=0, holomorphic=True)`，再 `vmap` 到整批样本。
- `flatten_batched_pytree` 压平每个样本的梯度 pytree → `O (n,P)`。
- QGT 切片为 `S = O^H_c O_c / n`（Hermitian 对称化），返回 `S + diag_shift·I` 供自然梯度 `solve`。

## 4. 关键工程决策（为什么这么设计）

1. **两个采样器**：
   - 冻结态采样器（单空间 `hi`，`single_rule` FermionHopRule）在 `|φ₀|²` 上采样 → 估计 overlap 标量；
   - NES 联合行列式采样器（`hi^K`，`NESFermionHopRule`）在 `|det A^F|²` 上采样 → 求梯度。
   两者物理角色不同、分布不同，必须分离。

2. **`c/h/E₀` 是动态量，打包进 `parameters` pytree 而非闭包**：
   `c/h/E₀` 在 Stage-1 每步都被重估，且它们影响 `|Ψ^F|²`（不似 gauge 常数平移无害）。NetKet 采样 machine
   只有 `(parameters, sigma)` 两个签名位置且被 jit 缓存，若用闭包捕获会在首次编译时固化常量。
   解法：`pack_sp(params, c, h, E0)` 把 `c/h/E₀` 塞进 `{"real","c","h","E0"}` 的整体 pytree，
   随 NetKet `parameters` 作为动态参数逐步流入（notebook 里的 `build_sampler_mac` 负责解包）。

3. **Stage-1 必须 fresh re-init**：
   若沿用 Stage-0 收敛列 `{ψ₀..ψ₃}≈{φ₀,φ₁,φ₂,φ₃}`，投影 `Q₀` 之后 4 个 active 列全落在 3 维子空间，
   `det A^F` 必然奇异。fresh 随机初始化让 active 列在 Q₀H 里重新张成不含 φ₀ 的 4 维空间（K 保持 4，行列式仍 4×4）。

4. **gauge-fixing 是 overlap ratio 有意义的前提**：
   `create_single_machine_gauge_fixed(ansatz, ref)` 让每列满足 `ψ_j(ref)=1`，使 φ₀ 与 active ψ_j 处于同一规范，
   `⟨φ₀|ψ_j⟩/⟨φ₀|φ₀⟩` 与 `ψ_j/φ₀` 的 ratio 才有确定含义。

5. **vmap 规避 `squeeze` 形状坍缩**：见 §3.1 注释，这是 `machine_single`（QGT）在 `N=1` 时能正确 trace 的关键。

## 5. 验证结果（矩阵自由 + MCMC，无 to_dense / 无全空间）

冒烟验证（Stage-0/Stage-1 各 40 步、每步 3200 个 NES walker + 2560 个冻结态样本）已确认：

- **Stage 0（Q=I，标准 NES-VMC）**：`E0` 从 `-0.32` 单调收敛到 `-1.045`（趋向基态 `-1.0543`）；
  子空间广义本征 `λ = [-1.048, -0.954, -0.619, -0.454]` 对齐 FCI `[-1.054, -0.958, -0.669, -0.551]`。
- **冻结态自检**：在 `|φ₀|²` 采样上估计 `E₀ = ⟨φ₀|H|φ₀⟩/⟨φ₀|φ₀⟩ = -1.032`（对照基态 `-1.054`），
  **端到端验证了「矩阵自由 H 作用 + ratio overlap 估计」的正确性**。
- **Stage 1（Q₀H，deflated）**：déflated 最低能级从 `-0.21` 收敛到 `-0.950`（趋向第一激发态 `-0.958`），
  逐级能量整体向 `[E1,E2,E3,…]` 上移——正是「投影掉基态后重排能谱」的预期行为。

（完整 notebook 用 `N_ITER0 = N_ITER1 = 300`、`N_SAMPLES_PER_CHAIN = 400`，收敛余量更大。）
