## 3. 根因：`eig(sym⟨E_L⟩)` 为什么不是本征值

`E_L(x) = A(x)⁻¹Z(x)` 是**单一组态**上的矩阵逆，样本平均

```
⟨E_L⟩ = Σ_x w(x) A(x)⁻¹ Z(x),   w ∝ |det A|²
```

而正确的子空间本征问题需要的是**Gram 型**量（不含逆）：

```
M = Σ_x w(x) A†Z,   S = Σ_x w(x) A†A,   M v = λ S v
```

两者只在 K=1 时严格相等（`χ*·Hχ/χ` → `⟨χ|H|χ⟩`）。K≥2 时：

1. **逆的比值估计有偏**：`E[1/x] ≠ 1/E[x]`。`A⁻¹` 对行列式接近奇异的组态极其敏感。
2. **迹仍然正确**：`tr(A⁻¹Z) = Σ_i (Hχ)_i(x_i)/χ_i(x_i)`，单组态意义上就是"各列局域能量之和"，加权平均恰好复原 Σλ。这解释了"迹对、谱错"。
3. **偏差随 K 和列间动态范围放大**：K=2（φ₄/φ₅ 量级相近）时逆的噪声有限，偏差只有 ~0.01 mHa（K2 运行日志实测 λ₀/λ₁ 与 FCI 差 0.01/0.02 mHa）；K=4 时 E₇=+0.024 Ha 比 E₄ 高出 0.052 Ha，高能列在 |det A|² 测度下的有效权重极小，`A⁻¹` 的放大把谱"向外推"——全枚举给出的谱正是典型的**谱扩散**形态（两端外推、中间压缩、总和不变）。
4. **对 c 还极其敏感**：精确 c → (−0.172, …, +0.161)；有噪 c → (−0.058, …, +0.066)。同一个"监控量"换一批 aux 样本就能跳 100 mHa，作为收敛判据毫无意义。

补充：有效测度本身极度集中——全枚举下权重 ESS 仅 **134 / 43680** 个有效元组，与主采样 ESS≈1300/3200、aux ESS≈50/1024 一致。低 ESS 让比值型估计的偏差进一步显性化。

## 4. 辅助函数系数（EPS_MIX / AUX_M / SCALE_BETA）是不是原因？

**不是误判的原因**，但有真实的精度代价：

- §2.3(a) 用的是**精确**的 c、c2，`eig⟨E_L⟩` 仍然偏 130+ mHa ⇒ 偏差与 aux 系数无关，属于估计器定义问题。
- 真正受 aux 影响的是 **c 的噪声**：两次独立 M=1024 的估计

  ```
  max|c_new − c_saved| = 0.138,  而 |c|max ≈ 0.18
  ```

  相对噪声达 ~75%，有效样本只有 `aux_ess ≈ 49/1024`（`aux_maxw ≈ 85–92`，重尾）。后果是 Gram 提取的边缘能级从 0.000 mHa 退化到 −3.8 mHa（§2.3b，且那里还令 c2=0），实际运行（带 c2）为 0.003–0.010 mHa。
- 量纲/尺度设定（f=5.016、g≈[4.65, 2.76, 2.89, 3.41]）在 50 步后即稳定，无漂移，不是问题。

**调优建议（非必需，属精度打磨）**：

| 项 | 现状 | 建议 | 理由 |
|---|---|---|---|
| `NES_AUX_M` | 1024（ESS≈50） | 4096 或 8192 | c 噪声 ∝ 1/√ESS，提取误差随之下降（§2.2 已实测 0.153→0.045 mHa） |
| `EPS_MIX` | 0.25 | 扫 0.05 / 0.25 / 1.0 | q 中 active 项占比过小会压低 active 列的覆盖；注意同时监测 `aux_maxw` |

## 6. 修复方案

### 方案 1（推荐）：把每步监控换成 Gram 形式，几乎零额外成本

主采样批的每条 walker 本来就要求值 `A`（K×K）与 `Z`（K×K），只是当前 `bundle["grad_fn"]` 内部用完即弃。把二者返回出来，然后在同一批样本上做

```python
S = einsum('nmi,nmj->ij', conj(A), A) / N
M = einsum('nmi,nmj->ij', conj(A), Z) / N
lam = sort(eigvalsh(solve(S + ηI, M)))       # η ~ 1e-12
```

优点：无需额外采样；与收尾提取同构（§2.3 证明其极限精确）；对 c 的敏感度远低于 `A⁻¹` 形式。

### 方案 2（最小改动）：图只画"迹"，本征值改为周期性提取

- 子图 1 的 `λ̂` 曲线删掉，改画 `Loss = Re tr⟨E_L⟩`（它是对的，且与 ΣE 吻合）；
- 每 25 步做一次 aux 提取（M=4096），把 `λ_mc` 记入 history，用它画能级曲线与误差子图。

### 方案 3：不动监控，只改判据

在报告/脚本验收段明确：**收敛判据只看收尾 Gram 提取 + 正交性/冻结剩余重叠，不看 `eig⟨E_L⟩`**；并把该曲线改名为 `trace-split (biased, not eigenvalues)` 以免误读。

> 注意：`λ̂ = eig(sym⟨E_L⟩)` 在 K=2 的运行里恰好接近真值（误差 0.01 mHa），这是 **K=2 的偶然**，不能推广为"该监控量可用"。
