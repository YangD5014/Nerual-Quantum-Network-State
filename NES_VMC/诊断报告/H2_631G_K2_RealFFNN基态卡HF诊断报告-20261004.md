## 1. 结论摘要

实参数版基态收敛到 **E₀ = −0.99746 Ha ≈ HF 能量（−0.9975 Ha）**，相对 FCI 基态（−1.054347 Ha）误差 **56.9 mHa**，恰好等于 H2/6-31G 的 HF 关联能（56.8 mHa）。这不是"收敛慢"，而是训练塌缩进了一个**采样自锁的局部极小**：

> 两列基矢张成 {HF, 第一激发态} 子空间 —— 这是哈密顿量在"被采样到的组态支撑集"上的**精确本征态对**，Loss 在该支撑集上已无下降空间，梯度饥饿（sampling starvation / 零方差冻结）把优化彻底锁死。

根因链条：**默认 `machine_pow=2`（按 |Ψ|² 采样）→ 双激发组态采样频率塌到 0.1% → 基态关联能（全部来自双激发）的梯度信号消失 → 列 1 停在 HF、列 2 停在单激发构成的第一激发态**。

复参数版能越过 HF 并非机制更强，而是随机初始化恰好落在 FCI 一侧（HF 权重 ~1e-4），全程保持 ~5% 的双激发采样频率，梯度信号从未断流。

## 3. 根因分析

### 3.1 主因：|Ψ|² 采样的双激发饥饿 → 零方差冻结（自锁正反馈）

两个 notebook 均使用

```python
nes_sampler = nk.sampler.MetropolisSampler(hilbert=hi_ext, rule=nes_rule,
                                           n_chains=N_CHAINS, sweep_size=SWEEP_SIZE)
```

未显式设置 `machine_pow`，即默认 **`machine_pow=2`，按 p ∝ |Ψ|² 采样**。VMC 力梯度中每个组态的贡献正比于其采样概率：

∇E ∝ Σ_σ p(σ) · 2Re[(E_L(σ)−⟨E⟩)∇logΨ(σ)*]，p(σ) ∝ |Ψ(σ)|²

FCI 基态 |Ψ₀⟩ ≈ w_HF|HF⟩ + w₁Σ|单激发⟩ + w₂Σ|双激发⟩，其中**基态关联能（HF 与 E₀ 之间 56.9 mHa 的差）完全由双激发项提供**。一旦采样分布向 {HF, 单激发} 倾斜：

1. 双激发样本频率 → 0.1%，其梯度贡献按 |Ψ|² 再平方压低（信号 ∝ w_doubles²，而目标波函数里是 w_doubles），等效于被抑制约 500×；
2. 列 1 缺少把振幅推向双激发的动力，反而继续被"采样到的支撑集上的最低本征态"吸引 —— 即 HF；
3. {HF, E₁} 恰是该支撑集上 2×2 E_L 矩阵的**精确本征态对**，tr(E_L) 在此已无可下降方向，梯度范数塌到 0.01 量级；
4. 分布被进一步锁死（频率自锁）。这与 2026-09-25 在 `FFNN振幅相位分离版-VMC-1.py` 上诊断过的"HF 零方差冻结"是同一机制，2026-10-02 对该 notebook 的初步分析（HF 62% / 单激发 38% / 双激发 0.16%）也与此一致。

### 3.2 为什么偏偏是实参数版掉进 HF 盆地？

- **复参数 FFNN 的初始化落点在 FCI 一侧**：复数权重使随机初态的 |det| 存在强烈相消干涉，HF 组态初始权重仅 ~1e-4（见 2026-09-25 诊断记录），采样从一开始就覆盖含双激发的宽支撑集，梯度信号完整，两列直接收敛到 {E₀, E₁}，**从未进入 HF 盆地**。
- **实参数振幅-相位分离结构使 |Ψ| 更"顺从"**：logΨ = logA + iφ，振幅由共享骨干的实值头 `logA` 平滑决定，相位头只旋转相位、不改变 |Ψ|² 的组态分布。随机初始化下 |Ψ|² 接近均匀，梯度下降第一步就把列 1 拉向"当前可见的最低能量组态"= HF（它是真实基态中权重最大的单组态），随后触发 3.1 的正反馈锁死。
- 因此差异**不是表达力**（实参数+相位头同样能表示复波函数、原则上可表达 E₀），而是**优化盆地归属**：实参数结构 + |Ψ|² 采样天然把 HF 作为吸引子；复参数版只是运气好绕开了它。

### 3.3 SR / 裁剪 / gauge reset 为什么救不了

- **自然梯度（Re(S) + diag_shift=0.1）** 只是在已采样支撑集内重新塑形梯度，无法为**从未出现的组态**生成信号；diag_shift 反而进一步压死残余的小信号方向。
- **per-param clip（0.5）与 clip_by_global_norm（20）** 针对的是梯度爆炸，本例末段梯度是 0.006 量级的"饿死"，裁剪从未触发、也无从触发。
- **周期性 gauge reset** 只吸收列均值规范漂移，属规范坐标化妆，与采样饥饿无关。

## 4. 修复方案（按验证程度排序）

1. **`machine_pow=1` 按 |Ψ| 采样 + 重要性加权 w ∝ |Ψ|（首选，已验证）**
   稀有组态的梯度信号由 ∝ w² 提升为 ∝ w，加权估计器恢复精确梯度公式。姊妹脚本 `量子-经典混合式 Ansatz/FFNN振幅相位分离版-VMC-1.py`（同一实参数+复输出 ansatz）用此方案 400 步收敛到 −1.0509 Ha（误差 3.5 mHa），显著优于本 notebook 的 56.9 mHa。改动点：采样器加 `machine_pow=1`，梯度/QGT 的样本均值乘权重 w_i ∝ |Ψ(σ_i)| 并归一。
2. **初始化显式混入双激发权重**：在 `logA` 初始化时对双激发组态注入正偏置，避免开局滑入 HF 盆地（治标，与方案 1 叠加更稳）。
3. **Stage0 预训练 + 冻结路线**：若走 Route B 冻结方案，须先把 Stage0 训练至误差进入化学精度（≈1.6 mHa）再冻结，否则冻结只保证"锁死在 −0.9975"不再变差（见 2026-10-02 结论）。
4. 辅助：适当调小 `qgt_diag_shift`（0.1 → ~0.01 量级）可减弱对残余信号方向的阻尼，但单独使用不足以脱离锁死。
