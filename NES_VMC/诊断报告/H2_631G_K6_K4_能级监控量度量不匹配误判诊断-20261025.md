## 2. 根因：监控量的度量与“物理能级”不匹配

### 2.1 物理能级是什么

对 K 个单副本波函数 `ψ_j(σ)`（`σ` 为固定粒子数/自旋扇区的基态），能级是

```
S_ij = Σ_σ ψ_i(σ)* ψ_j(σ)
M_ij = Σ_σ ψ_i(σ)* (Hψ_j)(σ)
M v = λ S v
```

中的广义本征值。注意 `Σ_σ` 是**单副本希尔伯特空间上的均匀（计数）求和**。

### 2.2 扩展空间 `|Ψ|²` 测度为什么不等价

训练/旧监控的样本来自扩展空间，`p∝|Ψ|`、权重 `w∝|Ψ|`，合起来是 `|Ψ|²` 测度。
对行列式型 NES 态，单副本边缘分布

```
p_1(σ_1) = Σ_{σ_2..σ_K} |det[ψ_j(σ_i)]|²
```

既不是均匀分布，一般也不因子化。因此在这个测度下估出的 `S、M` 是**另一个内积**
下的 Gram 矩阵，`λ` 自然不等于物理能级。

### 2.3 为什么表现为“保迹重排”

指标 `tr(S⁻¹M)=Σλ` 只约束总和。`|Ψ|²` 度量给 `S` 带来的畸变，会**保持迹不变**
地把本征值在能级之间重排：

- 加权 `S` 与精确均匀 `S` 差别极大：
  - 精确（K6 保存参数，离线标定）：`diag(S)=[1.24,0.44,1.57,1.04,0.25,2.20]`，
    `cond(S)≈317`；
  - `|Ψ|²` 加权估计：`diag(S)=[0.107,0.027,0.183,0.020,0.229,2.41]`，
    `cond(S)≈1480`（有列范数仅 `0.02`）。
- 于是出现 `λ1` 偏负、`λ4` 偏正、总和仍精确的“重排”。
- **非变分判据**：加权估计给出 `λ1 = -0.96172 < E1 = -0.95791`。任何合法
  Rayleigh–Ritz 值都不可能低于精确本征值，这直接说明**估计量本身有偏**，
  而不是子空间没收敛。

### 2.4 为什么 notebook 的 `eig(⟨E_L⟩)` 反而“看起来对”

`⟨E_L⟩` 与训练 loss 同源，量级和能级一致；用保存参数离线标定，它给出的 6 个值
与 FCI 的偏差最大 `0.14 mHa`（`E5` 的采样噪声），与精确枚举一致。它的问题是
**谱扩散/方差**（K4 冻结扩展曾偏 `±137 mHa`），而不是这次 K6 收敛末态的系统偏差。
换句话说：这次换量换来了“低噪声”，却引入了“度量偏差”。

## 3. 正确监控量：单副本均匀测度 Ritz 值（可推广，不枚举全空间）

### 3.1 估计器

新增于 `NES_VMC_tool.py`：

- `make_uniform_level_estimator_fn(ha, single_machine_list, total_graphdef)`
- `compute_lam_v_from_samples_uniform(estimator, total_params, x_batch, return_MS=False)`

流程：

1. 在**单副本**参考分布 `q(σ) ∝ Σ_j |ψ_j(σ)|²` 上采样（`machine_pow=1` 时
   NetKet 采样分布就是 `exp(log q)=q`）；
2. 自归一化重要性权重 `w_n ∝ 1/q(σ_n)`，把 `q` 样本还原为均匀测度；
   `q` 的归一化常数被自归一化消掉，无需配分函数；
3. 逐样本计算 `P[n,j]=ψ_j(σ_n)` 与
   `E_L[n,j]=(Hψ_j)(σ_n)/ψ_j(σ_n)`，其中 `Hψ_j` 用
   `ha.get_conn_padded` + 逐列 `logψ` 差分稳定计算；
4. `S=Σw P†P/Σw`、`M=Σw P†(P·E_L)/Σw`，再解 `M v=λ S v`。

复杂度 `O(N·K·C)`，K×K 本征问题，内存只有 `(N,K)` 与 `(N,C)`，**不做全空间数组**。

### 3.2 脚本接入

两个脚本均新增：

- 超参：`MONITOR_CHAINS=32`、`MONITOR_SAMPLES_PER_CHAIN=64`（共 2048 样本）、
  `MONITOR_SWEEP_SIZE=10`；
- 独立的单副本采样器 `monitor_sampler`（与训练采样完全解耦）；
- 监控块改为采样 `monitor_samples` 并调用
  `compute_lam_v_from_samples_uniform`；
- 日志标签改为 `均匀测度 Ritz λ(升序)`，并同时打印
  `n_valid_monitor / n_valid_train`、`cond(S)`；
- 图标题/坐标轴改为 `uniform-measure Ritz values`；
- `history` 键保持不变（`Energy_levels / lam_real / M_matrix / S_matrix / V_matrix`），
  已有画图/分析代码无需改动。

## 4. 判断流程（以后遇到类似问题可直接复用）

1. **先确认训练是否一样**：逐位比较两次运行的 `Loss` 与梯度范数。若一致，
   问题一定在监控/画图，不在优化。
2. **检查监控量是否符合“非变分”判据**：任何能级低于精确本征值（或高于上一个
   精确本征值而总和又对得上）都说明估计量有偏。
3. **比较 `S` 的结构**：`cond(S)`、`diag(S)` 是否与理论/离线小体系标定一致。
   若某列范数小两个量级，广义本征会放大其误差。
4. **任何监控量都要做一次离线标定**（小体系可精确枚举，大体系可用大样本极限），
   确认它的“无限样本极限”就是物理量，再相信在线读数。

## 5. 注意事项与后续建议

1. **监控必须与训练分离**：`|Ψ|²` 测度是训练/梯度需要的；能级读数需要单副本
   均匀测度。两者不要混用同一个 `S、M`。
2. **样本数与尾部**：当前 2048 样本对 K6/K4 已足够（最大 0.06~0.15 mHa）。
   体系变大或 `q` 更尖时，建议提高 `MONITOR_CHAINS`，或监控有效样本数
   `ESS=(Σw)²/Σw²`（可后续加进估计器返回值）。
3. **`q` 的支撑**：`q(σ)=Σ_j|ψ_j(σ)|²` 覆盖全空间，但极低概率组态可能采不到；
   自归一化权重下它们对 `S、M` 的贡献有界，本次标定未出现明显漏采问题。
   若出现 `n_valid_monitor` 明显偏小，应增加样本或换更均匀的参考分布。
4. **不要回退到扩展空间 Gram**：它保迹但会重排 `λ`，对“逐能级化学精度”是
   不可用的读数。
5. 旧的 `make_MS_unbiased_estimator_fn / compute_lam_v_from_samples_unbiased`
   仍保留在公共模块中（其他实验可能引用），但本 K6/K4 脚本已不再使用。

## 6. 附：离线标定方法（仅用于验证，生产流程不依赖）

对 8 qubit / 2 电子体系，单副本希尔伯特空间只有 16 个基态，可离线构造
`S、M` 并解广义本征，作为“金标准”核对在线监控量：

```
states = hi.all_states()                 # (16, 8)
P = [ψ_j(states) for j in range(K)]      # (16, K)
S = P† P ; M = P† H P
λ = eig(M, S)
```

该步骤只用于本报告的判定与参数标定；正式脚本中的监控量完全基于单副本采样 +
重要性加权，可推广到无法枚举的体系。

### 问题定位

- 旧每步监控 `aux["lam_gram"]` 来自 `NES_VMC_deflation_mf.py: _gram_eig`，用主联合
  walker 样本 + `w∝|Ψ_F|` 组装 `S=ΣwA†A`、`M=ΣwA†Z`，即扩展空间 `|Ψ_F|²` 测度；
  与 K6/K4 主脚本同一缺陷：迹守恒但单能级会被重排。
- 实测（`冻结K4_探索K2/日志/26-10-23-07-25` 末步）：旧 `λ̂=[-0.02797935, -0.01384638]`，
  而收尾提取（正确口径）`λ_extract=[-0.02798761, -0.01368918]`，E5 差约 `0.16 mHa`。
- 收尾提取 `λ_extract`（脚本第 445-481 行）本身已用单副本密度
  `q=Σ|Φ̃|²+εΣ|Ψ̃|²` 与 `1/(M·q)` 权重，**度量正确，不需要改**。

### 修正方式

在 `NES_VMC_deflation_mf.py: estimate_grams` 内新增（`aux_g["lam_uniform"]`）：

```text
χ     = Ψ̃ − Φ̃ c
Hχ    = HΨ̃ − HΦ̃ c
S_ij  = Σ_σ w(σ) χ_i(σ)* χ_j(σ)
M_ij  = Σ_σ w(σ) χ_i(σ)* (Hχ_j)(σ)
w(σ)  = 1/(M·q(σ))                      # 自归一化后还原单副本计数测度
S     = U s U†                          # Hermitian 分解
keep  = s > rcond·s_max                 # 截断近零奇异方向（默认 rcond=1e-8）
λ     = eig(S⁺^{-1/2} M S⁺^{-1/2})       # 仅在保留子空间；丢弃方向填 NaN
```

### 为什么还要截断（伪逆）

Cholesky+jitter 的问题不在“要不要正则”，而在于 jitter 固定为 `1e-12·tr(S)/K`：
当 `S` 的近零本征值完全由 1024 个样本的采样噪声决定时，`1e-12` 的脊远小于噪声，
`S⁻¹` 会把噪声方向放大到 `1e8~1e10`，于是首步出现
`λ̂=[-2.56e10, -1.42e10, 3.85e8, 2.82e10]` 这类假能级（step 2 起自愈）。
改为伪逆截断后，这些方向被直接丢弃；日志同时打印 `pinv keep=k/K` 与 `cond(S)`。
若某步 `keep < K`（active 列整体秩亏），该步 λ̂ 整步置 NaN、图上留空档，
而不是把秩亏子空间的噪声比值当成能级。

与收尾提取完全同构，额外开销仅为每步一次 `K×K` 组装 + `K×K` 伪逆广义本征。
四个脚本的 `lam_hat` 改为读取 `aux_g["lam_uniform"]`；日志/图/注释同步改口径。
旧监控量 `aux["lam_gram"]`（`_gram_eig`，扩展空间 `|Ψ_F|²` 测度）**已彻底删除**：
`_gram_eig` 函数、`aux["lam_gram"]` 字段、各脚本的 `lam_gram_history`/pkl 键/
“监控量 2”“两种监控量对照”两张图与末步 legacy 误差日志全部移除，避免误用。
