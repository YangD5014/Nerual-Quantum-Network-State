# 第 03 章 · 数学骨架：严格归一化的波函数

> 本章是全套教材的"公式心脏"。读完你要能回答三个问题：
> ① 网络每个位置输出的 ℓᵢ 怎么变成一个概率；② 粒子数约束怎么融进概率里；
> ③ 为什么整个模型自动满足 Σ|ψ|² = 1，而且相位怎么拼回去。

## 3.1 设计目标

我们要造一个复值函数 logψ(x)（x 是 8 位 0/1 串），满足：

1. **归一化**：在 16 个合法组态上 Σ|ψ(x)|² = 1（不需要事后除以 Z）；
2. **可精确采样**：能从 |ψ|² 逐位掷骰子抽样；
3. **尊重约束**：非法组态（如上旋段 0 个或 2 个电子）概率恒为 0；
4. **实参数**：网络权重全是实数（沿用典藏 notebook 的实参数 SR 体系），
   复数性由"振幅 + 相位"拼装产生。

做法：把 |ψ|² 写成条件分布的乘积（链式法则），把相位写成逐位贡献的和。

## 3.2 逐位条件分布 π̃：一个带约束的 softmax

网络在位置 i 输出一个实数 ℓᵢ（只看前缀 x₍<i₎，第 04 章保证这一点）。
定义**约束 softmax**：

```
π̃ᵢ(b | x₍<i₎) = exp[(2b−1)·ℓᵢ] / Σ_{b' ∈ feasible(i)} exp[(2b'−1)·ℓᵢ],   b ∈ {0,1}
```

其中 (2b−1) 把 b=1 映射成 +1、b=0 映射成 −1，所以分子就是"占据用 e^{+ℓ}、
空置用 e^{−ℓ}"——这是把二元变量当 Ising 自旋的标准写法。
分母只对**可行取值** feasible(i) 求和。

**feasible(i) 是什么？** 给定前缀，位置 i 放 0 或放 1 之后，
粒子数约束还能不能完成。代码里就三行
（[ar_nqs.py](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/自回归采样器/ar_nqs.py) 的
[feasible](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/自回归采样器/ar_nqs.py#L57-L64)）：

```
rem   = target − placed_before      # 本段还差几个电子（含位置 i）
slots = end − i                     # 本段还剩几个槽位（含位置 i）
放 1 可行 ⟺ rem ≥ 1                 # 还缺电子，放 1 有意义
放 0 可行 ⟺ rem ≤ slots − 1         # 放 0 之后，剩余 rem 个电子塞得进 slots−1 个槽
```

以 H2/6-31G 为例（`specs = [(0,4,1), (4,8,1)]`，上/下旋段各恰 1 电子）：

- 前缀 x₀=1（上旋段已放 1 个）：位置 1 处 rem=0 → 放 1 不可行，π̃₁ 退化为 δ₀；
- 前缀 x₀..x₂=000 且到位置 3：rem=1, slots=1 → 放 0 不可行，π̃₃ 退化为 δ₁。

**关键点：feasible 永远非空。** 只要前缀本身可完成（rem ≤ slots），
放 0 和放 1 至少有一个可行（rem≥1 则放 1 可行；否则 rem=0≤slots−1 则放 0 可行）。
所以分母至少有一项，softmax 良定义，且被强制的位置 π̃(b)=1 ——
约束不是"惩罚"非法串，而是**让非法串根本生成不出来**。

## 3.3 归一化证明：为什么 Σ|ψ|² = 1 是免费的

定义

```
|ψ(x)|² ≡ Π_{i=0}^{7} π̃ᵢ(xᵢ | x₍<i₎)
```

对全部 2⁸ 个串求和（非法串自动为 0，等价于对 16 个合法串求和）。
用**塔性质（逐层求和）**：

```
Σ_{x₀} π̃₀(x₀) = 1                       （softmax）
Σ_{x₁} π̃₁(x₁|x₀) = 1  对每个固定 x₀    （softmax）
...
```

先对最内层 x₇ 求和：对任何固定前缀，Σ_{x₇ 可行} π̃₇ = 1，x₇ 消失；
再对 x₆ 求和，又消失……逐层剥掉 8 层，最后剩常数 1。
这就是"按构造归一化"：**每个局部 softmax 的归一，逐层相乘成全局的归一**。
不存在配分函数，不存在 2^N 求和——这是自回归对 VMC 最根本的贡献。

数值自检（第 06 章表格）：把 16 个合法组态的 |ψ|² 全算出来求和，
与 1 的偏差 < 1e-16（float64 机器精度）。

> 注意一个容易忽略的细节：上面的求和是对**所有** 2⁸ 串做的，非法串贡献为 0，
> 因为它们的前缀在某层遇到"被强制"的位置时，实际取值与强制值矛盾，
> 该层 π̃ = 0。所以模型对非法组态给出 |ψ|² = 0、logψ = −∞，
> 与物理扇区完全一致。

## 3.4 相位拼装：复波函数的虚部从哪来

|ψ|² 只给了振幅。波函数还需要相位 φ(x)。
网络每个位置额外输出两个实数 φmᵢ、φdᵢ（同样只看前缀），定义

```
logψ(x) = Σᵢ [ ½·log π̃ᵢ(xᵢ|x₍<i₎)  +  i·( φmᵢ(x₍<i₎) + xᵢ·φdᵢ(x₍<i₎) ) ]
```

逐项解释（对应代码
[logpsi_from_out](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/自回归采样器/ar_nqs.py#L112-L128)）：

- **½·log π̃**：log|ψ| = ½ log|ψ|² = ½ Σ logπ̃ᵢ。取实部即对数振幅。
- **φmᵢ + xᵢ·φdᵢ**：位置 i 对总相位的贡献，是占据数 xᵢ 的线性函数。
  φmᵢ 是"背景相位"（该位置无论占不占都贡献），xᵢ·φdᵢ 是"占据修正"。
  总相位 φ(x) = Σᵢ φmᵢ(x₍<i₎) + Σᵢ xᵢ φdᵢ(x₍<i₎)，仍是逐位局域的和，
  与典藏 notebook"振幅-相位分离"的 ansatz 哲学一致，只是把全局函数
  logA(x)、φ(x) 换成了逐位可归一化的版本。
- **为什么相位不参与归一化**：|e^{iφ}| = 1，虚部随便怎么写都不破坏 Σ|ψ|² = 1。
  这是自回归 NQS 的一个特权：振幅部分被 softmax 锁死（表达力受限），
  相位部分完全自由——而物理上重要的干涉、动量分布、几何相位全在相位里。

实参数 + 复输出意味着梯度要拆 Re/Im 两条路（Wirtinger 手写），
这套推导与典藏 notebook 完全相同，见第 05 章 5.4 节。

## 3.5 对数几率的比值性质（采样器会用到）

由 3.2 的定义，当 0 和 1 都可行时：

```
π̃ᵢ(1) / π̃ᵢ(0) = e^{+ℓᵢ} / e^{−ℓᵢ} = e^{2ℓᵢ}
```

即 **ℓᵢ 恰好是"占据 vs 空置"的对数几率的一半**：
`p₁ = sigmoid(2ℓᵢ)`。这给 ℓᵢ 一个非常直观的读法：
ℓᵢ = 0 → 五五开；ℓᵢ → +∞ → 必占据；ℓᵢ → −∞ → 必空置。
第 05 章手算采样例子直接用 p₁ = sigmoid(2ℓ) 掷骰子。

## 3.6 本章小结

1. 网络逐位输出 (ℓᵢ, φmᵢ, φdᵢ)，ℓᵢ 经**约束 softmax** 变成分布 π̃ᵢ，
   约束通过可行域 rem/slots 判断实现——非法组态不是被惩罚，而是无法生成。
2. |ψ|² ≡ Ππ̃ᵢ 由塔性质**按构造严格归一**（数值偏差 < 1e-16），
   没有配分函数，这是精确采样的数学前提。
3. 相位是逐位前缀函数的和，模为 1、不影响归一化，承载全部复数物理。
4. ℓᵢ 的直观含义：p(占据) = sigmoid(2ℓᵢ)。
