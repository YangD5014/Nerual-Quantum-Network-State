# 自回归采样器教材 —— 写给不懂自回归模型的 VMC 研究者

这套教材解释 `../ar_nqs.py` 里实现的**自回归（autoregressive）神经网络波函数与采样器**，
以及它为什么能替代典藏 notebook 里的 Metropolis MCMC 采样器。

目标读者：会 VMC、会用 netket、了解 H2/6-31G 体系，但**从未接触过自回归模型**。
所有公式和数字都来自本目录真实运行过的代码，可逐条复现。

## 核心结论（先给剧透）

1. 自回归模型把 8 个自旋轨道的占据数 x₁…x₈ 拆成
   `p(x) = p(x₁)·p(x₂|x₁)·…·p(x₈|x₁…x₇)`，
   采样 = 按顺序逐位掷骰子，得到的样本**严格 i.i.d. 服从 |ψ|²**，没有 MCMC 的
   自相关、burn-in、reset 等一切问题。
2. 因为每个条件分布都在"粒子数约束允许的取值"上归一化，整个模型在 16 维物理
   扇区上**自动严格归一化**（数值验证偏差 < 1e-16）。
3. 但 AR 采样**不能**替代典藏 notebook 的 `machine_pow=1` 重要性加权修复：
   消融实验显示按 |ψ|² 精确采样同样会塌缩冻结在 HF 组态（详见第 02、05 章）。
4. 最终训练成果：1200 步（lr=0.05）+ 800 步精修（lr=0.02）→
   能量误差 **0.194 mHa**、与 FCI 基态重叠 **0.9997**、方差 2.7e-4，
   主算法全程 Matrix-Free（不做任何 2^N 全空间枚举）。
