# 第 05 章 · 采样与训练全流程

> 前三章把零件造齐了。本章把整台机器转起来：先手算一遍采样，
> 再讲 machine_pow=1 的重要性加权怎么嵌进顺序采样，最后过一遍
> 一步 SR 更新里每个公式和每个数字。

## 5.1 手算一遍采样（pow=2，精确 |ψ|²）

假设网络对某个前缀给出了这些 ℓ 值（每步掷骰子前现算）：

```
ℓ₀ = 0.5   ℓ₁..ℓ₃ 待定   ℓ₄ = 0.8   ℓ₅ = 0.2   ℓ₆..ℓ₇ 待定
```

**第 0 位**（上旋段起点，rem=1，slots=4，0/1 都可行）：

```
p₁ = sigmoid(2ℓ₀) = sigmoid(1.0) = 0.731
掷骰子 u = 0.42 < 0.731  →  x₀ = 1
```

**第 1 位**：x₀=1 已放完上旋段的 1 个电子，rem=0 → 放 1 不可行，
π̃₁ 退化为 δ₀ → **x₁ = 0（强制）**。同理 x₂ = x₃ = 0。
注意这三步掷都没必要掷——代码里仍然掷了（p₁ 被 `f1 & ~f0 → 1.0`
之类的强制分支处理），但概率上是确定的。

**第 4 位**（下旋段起点，rem=1，slots=4）：

```
p₁ = sigmoid(2×0.8) = sigmoid(1.6) = 0.832
掷 u = 0.91 > 0.832  →  x₄ = 0
```

**第 5 位**：rem=1，slots=3，仍都可行：

```
p₁ = sigmoid(0.4) = 0.600
掷 u = 0.35 < 0.600  →  x₅ = 1
```

**第 6、7 位**：rem=0 → 强制 0。

最终样本 `x = [1,0,0,0,0,1,0,0]`。它被抽中的概率是

```
|ψ(x)|² = π̃₀(1)·π̃₁(0)·π̃₂(0)·π̃₃(0)·π̃₄(0)·π̃₅(1)·π̃₆(0)·π̃₇(0)
        = 0.731 × 1 × 1 × 1 × 0.168 × 0.600 × 1 × 1 ≈ 0.0736
```

对 16 个合法串都这样算一遍，概率和恰为 1（第 03 章塔性质）。
每个样本消耗 8 次前向（批量并行）。

## 5.2 pow=1：从 |ψ| 采样 + 重要性权重

第 02 章说过，pow=2 会冻结。采样器 [make_ar_sampler](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/自回归采样器/ar_nqs.py#L153-L188)
的通用形式是：第 i 步从

```
qᵢ(b) ∝ exp[ (pow/2)·(2b−1)·ℓᵢ ]
```

抽样。pow=2 时 q = π̃（即 5.1）；pow=1 时 qᵢ(1)/qᵢ(0) = e^{ℓᵢ}，
即从 q ∝ |ψ| 抽样——**稀有组态的抽中概率从 ψ² 提升到 ψ**。

代价：样本不再服从 |ψ|²，而是服从 q。所有估计器要乘重要性权重

```
w(x) = |ψ(x)|² / q(x) = Πᵢ π̃ᵢ(xᵢ) / qᵢ(xᵢ)
```

代码里逐位累加 `logw += logpi − logq`（注意系数：logq 前面的 pow 只进 q 的
定义，**不进 logw 的修正项**——这里曾出过一个把 logq 乘上 machine_pow 的 bug，
pow=1 时恰好看不出来，pow=2 自检时 maxdev 飙到 4.19 才暴露，见第 06 章踩坑表）。

自检数字（4×10⁵ 样本 vs 全空间真分布，最大偏差）：
pow=2 精确采样 **0.00096**；pow=1 加权采样 **0.00062**。两者都在蒙特卡洛
噪声量级（最小格 p≈0.0152 处噪声 ≈0.0006），说明两条采样路线都正确。

## 5.3 一步训练的全景图

主循环在 [H2_631G_AR_VMC.py](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/自回归采样器/H2_631G_AR_VMC.py) 的
[main](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/自回归采样器/H2_631G_AR_VMC.py#L184-L197)，每步五件事：

```
① 采样     sigma, logw = sample(params, rng, 3000, pow=1)     # 8 次批量前向
② 局部能量 E_loc(σ) = Σ_η H(σ,η)·ψ(η)/ψ(σ)                    # ha.get_conn_padded，Matrix-Free
③ 力梯度   ∇E = 2·Re⟨(E_loc−Ē)*·∇logψ⟩_w                     # 加权，w=exp(logw)
④ QGT      S = Re⟨(∇logψ−⟨∇logψ⟩_w)(∇logψ−…)*ᵀ⟩_w + 0.01·I   # 实参数度量取实部
⑤ SR 更新  Δθ = −lr · S⁻¹∇E，lr=0.05（optax.sgd）
```

逐个说明"为什么长这样"：

**② 局部能量**：与典藏完全相同的
[compute_local_energies](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/自回归采样器/H2_631G_AR_VMC.py#L59-L65)。
`get_conn_padded` 返回每个 σ 的连接 η 和矩阵元；padding 行 η=σ、H=0，
自动不贡献。注意 η 是**同扇区的合法组态**（H 保持粒子数），
所以 logψ(η) 也在约束模型内评估，没有越界问题。

**③ 力梯度带因子 2**：E = ⟨ψ|H|ψ⟩ 对实参数求导，
∂E/∂θ = 2Re⟨(E_loc−Ē)(∂logψ)*⟩。典藏 notebook 的代码漏乘了这个 2
（它的 docstring 说"已含因子 2"，实际实现没有）。本实现修正为显式
`2.0 *`（[forces_expect_hermitian](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/自回归采样器/H2_631G_AR_VMC.py#L82-L96)），
代价是**有效步长翻倍**，所以 lr 从典藏的 0.1 减半到 **0.05** 对齐。
这不是可调口味，是同一数学对象的两种记账方式——
首轮用 lr=0.1 + 因子 2 时训练平台在 52 mHa，减半后 400 步到 9.5 mHa。

**③ 的梯度怎么来**：实参数、复输出，`jax.grad` 不能直接微复值函数，
拆成 ∇Re + i·∇Im（[_grad_logpsi_real_params](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/自回归采样器/H2_631G_AR_VMC.py#L69-L72)），
与典藏同一套 Wirtinger 手写推导。

**④ 度量取 Re(S)**：实参数位移 dθ 是实向量，⟨|dlogψ|²⟩ = dθᵀRe(S)dθ，
S 的虚部是反对称部分、对实二次型无贡献。
diag_shift = 0.01 正则化后直接 `jnp.linalg.solve`（2136×2136，每步可解）。

**梯度正确性验证**（[diag_gradient.py](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/自回归采样器/diag_gradient.py)）：
MC 加权梯度 vs 全空间 autodiff 精确梯度，cosine = **0.9995**，
而两次独立 MC 之间的噪声底 cosine = 0.9983——MC 梯度与精确梯度的偏差
小于 MC 自身的统计噪声，即估计器**无系统偏差**。

## 5.4 收敛阶梯（真实数字）

| 配置 | 步数 | 能量误差 | 方差 | 与 FCI 基态重叠 |
|---|---|---|---|---|
| pow=2, lr=0.1（消融，冻结） | 400 | 56.9 mHa | 4.2e-2 | 0.902 |
| pow=1, lr=0.1（因子2步长过大） | 400 | 52.3 mHa | 4.0e-2 | 0.911 |
| pow=1, lr=0.05 | 400 | 9.47 mHa | 7.2e-3 | 0.971 |
| pow=1, lr=0.05 | 1200 | 3.79 mHa | 3.4e-3 | 0.991 |
| pow=1, lr=0.02 续训（refine） | +800 | **0.194 mHa** | **2.7e-4** | **0.9997** |

读法：前两行说明"采样精确"救不了错误的采样分布/步长；
第三到五行是标准的"降学习率精修"路线——误差随步数持续下降，
|∇E| 从 0.098 降到 5.4e-4，方差同步塌缩，是真正的收敛而非平台。
计时约 0.85 s/步（3000 walkers × 8 前向 + 梯度 + 2136² 线性求解）。

作为参照：典藏 FFNN + Metropolis 路线 400 步到 3.5 mHa。
AR 路线用更多步数达到 0.194 mHa，换来的是 i.i.d. 精确样本
（能量误差条只含 √(Var/N) 的纯统计项，没有 MCMC 自相关修正的暗账）。

## 5.5 本章小结

1. 采样 = 逐位"约束 softmax 掷骰子"；被约束强制的位不掷（p 退化为 δ）。
2. pow=1 从 q∝|ψ| 采样，`logw += logπ̃ − logq` 累加重要性权重；
   logq 的系数是 1 不是 pow——这是踩过的坑。
3. 力梯度显式带因子 2，lr 相应减半（0.05）与典藏有效步长对齐；
   梯度经全空间对照验证无系统偏差（cosine 0.9995 ≥ 噪声底 0.9983）。
4. 收敛阶梯：0.05→0.02 两段共 2000 步，最终 0.194 mHa / 重叠 0.9997。
