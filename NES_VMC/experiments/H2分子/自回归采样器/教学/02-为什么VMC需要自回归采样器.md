# 第 02 章 · 为什么 VMC 需要自回归采样器

> 本章回答两个问题：Metropolis MCMC 在 VMC 里到底难受在哪；
> 以及一个反直觉的实验结论——自回归消灭了马尔可夫链，但**消灭不了零方差冻结**。

## 2.1 回顾：典藏 notebook 是怎么采样的

典藏版（`../量子-经典混合式 Ansatz/FFNN振幅相位分离实数版-典藏.ipynb`）用
netket 的 Metropolis 采样器：

```python
sampler = nk.sampler.MetropolisSampler(
    hi, rule=single_rule, n_chains=150, sweep_size=32, machine_pow=1)
```

工作原理：150 条独立链，每条链从一个组态出发，每次按 `FermionHopRule`
提议"段内两个轨道间跳一个电子"（保证粒子数约束），以 Metropolis 接受率
接受或拒绝；一条链走几十步才交出一个"近似服从 |ψ|^(2·pow) 的样本"。

注意：这套流程**没有任何一步用到 2^N 枚举**，它是 Matrix-Free 的，
这是它必须存在的理由——我们不允许主算法做全空间求和（项目硬约束）。
但 Matrix-Free 的代价是：样本只是**渐近**服从目标分布。

## 2.2 MCMC 的四座大山

| 痛点 | 表现 | 在本体系里的具体形态 |
|---|---|---|
| 自相关 | 相邻样本不独立，有效样本数 ≈ N/(2τ) | 一条链 sweep 之间互相"记得"前一步 |
| burn-in | 初始链未收敛到平稳分布，前段样本有毒 | 每轮参数更新后链要重新"忘记"旧分布 |
| 模式隧穿慢 | 分布有两个分离峰时，链几乎不跨峰 | 概率质量堆在 HF 峰、FCI 峰势垒高时，稀有组态长期采不到 |
| 调参负担 | 步长/提议规则/接受率要人伺候 | 约束希尔伯特空间里提议规则必须手工设计（FermionHopRule + graph） |

这些问题的共同根源：**MCMC 用"局部随机游走"来近似全局分布**，
而全局性质（归一化、跨模式转移）恰恰是随机游走最难覆盖的。

## 2.3 自回归一次干掉前三座山

换成 [ar_nqs.py](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/自回归采样器/ar_nqs.py) 的顺序采样器后：

1. **没有链**：每个样本独立地从第 0 位掷骰子到第 7 位，样本之间零相关，
   有效样本数 = 名义样本数，不需要除以 2τ。
2. **没有 burn-in**：不存在"平稳化"过程，第 1 个样本就是精确样本。
3. **没有隧穿问题**：稀有组态 σ 的采样概率就是它的模型概率 π̃(σ)，
   不需要"游走"到它——每位条件分布都直接给出它。
4. **没有提议规则调参**：约束由可行域逻辑（第 03 章）在模型内部强制，
   采样器不需要图、不需要接受率。

数值验证（自检，见第 06 章表格）：对 4×10⁵ 个 pow=2 精确样本统计经验频率，
与全空间 16 维真分布的最大偏差 0.00096——与纯蒙特卡洛噪声（√(p(1−p)/N)，
p_min≈0.0152 处约 0.0006）同量级，说明采样**确实精确**。

## 2.4 但是：精确采样 ≠ 有效梯度（消融实验）

这是本教材最重要的一节。直觉上有人会想：

> "MCMC 采不准才是问题根源，现在我能 100% 精确地从 |ψ|² 采样了，
> 是不是可以直接用 machine_pow=2、丢掉重要性加权，训练就天下太平了？"

我们真的跑了这个实验（`AR_VMC_pow2.log`，lr=0.1，400 步，pow=2 精确 |ψ|² 采样）：

```
MC 能量：-0.99746898 Ha          ← 停在 HF 能量（-0.9975）
全空间 E：-0.99748975  Var：4.2e-02  Ovl：0.902
精确梯度范数 |∇E|：3.866e-04     ← 梯度被压灭
误差：56.9 mHa（训练完全停滞）
```

对照组是 pow=1 + 重要性加权（同样的 AR 采样器）：400 步误差 9.5 mHa，
继续训练到 2000 步收敛至 **0.194 mHa**（第 05 章）。

**为什么精确采样救不了 pow=2？** 因为零方差冻结的根源不在采样器，
而在**估计器里梯度信号的权重**。VMC 力项是

```
∇E = 2 Re ⟨ (E_loc − ⟨E⟩) · (∇logψ)* ⟩_{|ψ|²}
```

期望是在 |ψ|² 之下取的。当网络（哪怕只收敛了一半）把概率质量堆到 HF 组态附近时，
激发组态 η 的 |ψ_η|² 极小；它对梯度的贡献 ∝ |ψ_η|²·(∇logψ)_η，
其中 (∇logψ)_η ~ ψ_η 量级，所以总贡献 ~ **ψ_η²**，指数级消失。
即使你能精确采样，稀有组态被抽中的**次数**本身也 ~ ψ_η²，梯度信噪比同样塌掉。
这不是采样算法的缺陷，是 |ψ|² 这个采样分布的**几何缺陷**。

改成按 q ∝ |ψ| 采样（machine_pow=1），稀有组态出现概率 ∝ ψ_η，
再用重要性权重 w = |ψ|²/q ∝ |ψ| 乘回去，其梯度贡献变成 ~ **ψ_η**——
平方变一次方，信号恢复。这就是典藏 notebook 当年修复冻结问题的方案，
也是为什么 AR 采样器必须保留 `machine_pow` 参数和 `logw` 输出。

> 一句话：**自回归解决"怎么采"，重要性加权解决"采到之后怎么算才不丢信号"。
> 两者正交，缺一不可。**

## 2.5 自回归没有带来的东西（诚实清单）

- **没有降低评估成本**：算一个样本的 logψ 要 8 次前向（掩码合并后仍是每位一次），
  比全局 FFNN 的 1 次贵 N 倍。小体系无所谓，大体系要算账。
- **没有解决优化景观问题**：pow=2 冻结点附近，我们用全空间精确 SR 做逃逸测试
  （[diag_exact_sr.py](file:///Users/yangjianfei/mac_vscode/神经网络量子态/NES_VMC/experiments/H2分子/自回归采样器/diag_exact_sr.py)），
  精确梯度也推不动——那是景观平台，不是采样器的锅。
- **没有放松 Matrix-Free 约束**：主算法依然只用 `ha.get_conn_padded`，
  全空间 16 维只出现在自检与诊断（项目硬约束，第 06 章有代码对照）。

## 2.6 本章小结

1. MCMC 的四大痛点（自相关、burn-in、隧穿、调参）全部来自"用局部游走近似全局分布"。
2. 自回归顺序采样把样本质量变成"按构造精确 i.i.d."，四个痛点一次性消失，
   数值自检偏差 0.00096 ≈ 蒙特卡洛噪声底。
3. 消融实验证明：pow=2 精确采样照样冻结在 HF（56.9 mHa，|∇E|≈4e-4），
   因为冻结源于 |ψ|² 测度下梯度信号 ~ψ_η² 的几何塌缩，与采样算法无关。
4. 所以本项目的最终形态是：**AR 顺序采样 + machine_pow=1 + 重要性加权**，
   各管一段、互不越位。
