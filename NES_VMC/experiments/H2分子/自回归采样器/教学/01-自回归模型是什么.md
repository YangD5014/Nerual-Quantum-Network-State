# 第 01 章 · 自回归模型是什么

> 本章不需要任何量子力学。只需要你会问："这 8 个开关的状态，整体出现的概率是多少？"

## 1.1 一个具体的场景

我们的体系是 H2/6-31G，共 8 个自旋轨道。一个电子组态就是一个长度 8 的 0/1 串：

```
x = [1, 0, 0, 0, 1, 0, 0, 0]     ← Hartree-Fock 组态
```

- `x_i = 1` 表示第 i 个自旋轨道被占据，`0` 表示空着。
- 物理上不是任意 0/1 串都允许：上旋段（site 0–3）必须**恰好** 1 个电子，
  下旋段（site 4–7）也必须**恰好** 1 个电子。所以合法组态只有 4×4 = 16 个。

现在问一个概率问题：波函数模方 `p(x) = |ψ(x)|²` 是这 16 个串上的一个概率分布。
**如果我想让神经网络"生成"一个按 p(x) 分布随机抽取的组态，最笨但最直接的办法是什么？**

答案就是自回归模型的全部核心：

> **一位一位地决定。每决定一位，都问一次网络："在已经决定的这些位的条件下，
> 下一位是 1 的概率是多少？"然后掷骰子。**

```
第 1 位：网络说 P(x₀=1) = 0.73   → 掷骰子，得 1
第 2 位：网络说 P(x₁=1 | x₀=1) = 0.02 → 掷骰子，得 0
第 3 位：网络说 P(x₂=1 | x₀x₁=10) = 0.10 → 得 0
...
第 8 位：网络说 P(x₇=1 | 前7位) = ...   → 得 0
最终输出 x = [1,0,0,0,0,1,0,0]，它**严格**服从 p(x)。
```

"根据已经生成的部分（self-regression，自己回归到自己身上），预测下一位" ——
这就是"自回归"（autoregressive）这个名字的来历。你在 ChatGPT 里看到的逐字生成，
就是同一件事，只不过词表有几万大、序列有几百长。

## 1.2 数学上它只是一个恒等式

自回归没有任何近似。对**任意**联合分布 p(x₁…x_N)，链式法则（条件概率的定义反复使用）给出：

```
p(x₁,…,x_N) = p(x₁) · p(x₂|x₁) · p(x₃|x₁,x₂) · … · p(x_N|x₁,…,x_{N-1})
```

右边每一项都是概率良定义的（只要左边对应的前缀概率不为零）。
所以"把联合分布拆成一串条件分布的乘积"**不是建模假设，而是恒等变形**——
任何分布都能这样写。

自回归的**建模选择**是：不直接给网络喂整个 x 让它输出一个标量 p(x)，
而是让网络输出 N 个条件分布的参数，每个条件分布只允许看前缀。

两种做法对比：

| | 全局 ansatz（典藏 notebook 的 FFNN） | 自回归 ansatz（本目录） |
|---|---|---|
| 网络看到 | 完整串 x = (x₁…x₈) | 生成第 i 位时只看前缀 x₍<i₎ |
| 网络输出 | 一个复数 logψ(x) | 每个位置一个条件分布 π̃ᵢ(xᵢ\|x₍<i₎) |
| 归一化 | 需要 Z = Σₓ \|ψ(x)\|²（2^N 项） | **不需要**，每位 softmax 自动归一 |
| 采样 | 只能近似（MCMC） | **精确** i.i.d.（逐位掷骰子） |
| 评估单个 x 的 logψ | 1 次前向 | N 次前向（或 1 次掩码前向，见第 04 章） |

最后一行先记住结论：我们实际只花 **1 次**前向就算出全部 8 个条件分布，
靠的是"因果掩码"技巧，这是第 04 章的主题。

## 1.3 为什么"逐位掷骰子"得到的是精确样本

这是初学者最容易怀疑的一点。直觉上："我每一步只保证下一位服从条件分布，
整体真的服从联合分布吗？"

真的。用两个小例子建立直觉，严格证明在第 03 章。

**例 A（抛两枚硬币）。** 设 p(x₁,x₂) 任意。自回归做法：
先按 p(x₁) 抽 x₁，再按 p(x₂|x₁) 抽 x₂。得到 (x₁,x₂) 的概率是
`p(x₁)·p(x₂|x₁) = p(x₁,x₂)`，分毫不差。

**例 B（掷骰子 vs 抽签）。** Metropolis MCMC 像"反复洗牌直到均匀"——
你必须信任洗牌的次数够多，而且前后两次抽到的牌是相关的。
自回归采样像"按顺序从袋子里抽签"——每一签都是从当前真实条件分布里独立抽的，
**没有"预热"、没有"相关"、没有"洗不够"的问题**，因为根本不存在马尔可夫链。

代价是：想抽第 i 位，必须先抽完前 i−1 位。样本之间确实独立了，
但单个样本的生成被强制串行化，采样开销从"随机改一位"变成"N 次网络前向"。
这笔账划不划算，取决于网络前向有多便宜——在我们的体系里，8 次批量前向
约 0.85 秒/步（3000 个样本并行），完全可接受。

## 1.4 自回归在 NQS 文献中的位置

神经网络量子态（NQS）从 Carleo & Troyer 2017 的受限玻尔兹曼机开始，
长期以 MCMC 为采样 backbone。自回归 NQS 的卖点是**精确采样**：
模型按构造归一化，`|ψ|²` 的每个样本严格 i.i.d.。
这与 Born machine（Gao & Duan, 2018）一脉相承——Born machine 也想要
"直接输出归一化概率"，但一般网络做到全局归一化很困难；
自回归分解把"全局归一"化归为"N 个局部 softmax 归一"，后者是免费的。

在矩阵乘积态（MPS）语言里，一个正交化的 MPS 同样可以逐位精确采样——
自回归 NQS 可以看作"用任意神经网络代替 MPS 的转移张量"，
表达力不受键维限制，代价是失去 MPS 的多项式算法族（如变分压缩）。
对本项目这种 8 比特小体系，表达力和采样精度的权衡完全站在自回归一边。

## 1.5 本章小结

1. 自回归 = 用链式法则把联合分布拆成条件分布的乘积，逐位生成。这是恒等式，不是近似。
2. 每个条件分布做一次 softmax → 模型**按构造归一化** → 不需要配分函数 → 可以**精确采样**。
3. 采样得到的样本严格 i.i.d.，彻底告别 burn-in、自相关时间、拒绝率这些 MCMC 概念。
4. 代价：生成一位必须前向一次（本实现用因果掩码合并为一次前向出全部条件），
   且串行生成不能"跳改"。
5. 它**不能**自动解决 VMC 的所有采样病理——第 02 章会展示一个反直觉的实验：
   即使采样 100% 精确、100% 服从 |ψ|²，训练照样会冻结。
