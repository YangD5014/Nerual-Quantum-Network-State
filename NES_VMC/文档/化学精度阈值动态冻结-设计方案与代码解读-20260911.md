## 0. 一句话方案

训练过程中，实时读取每个能级 $E_i$（平均局部能量矩阵 $\langle P^{-1}HP\rangle$ 的第 $i$ 个本征值）。
当某能级**连续 $N_\text{stable}$ 轮**低于化学精度阈值（相对精确解 $E_\text{FCI,i}$），就通过
$Mv=\lambda Sv$ 确定它对应的"主动列"，把该列**永久冻结**（单向、只增不减）。冻结列参数不再
被优化，其余列继续用自然梯度更新，从而大幅缩小 QGT 求解规模（$P^3\to P_a^3$）。

三份决策对象的尺寸全部是 **K×K**：$M$、$S$、$v$，不触碰完整的 $16\times16$ 的 H，也不做精确对角化。

---

## 1. 动态冻结机制：`OneWayFreezer` 怎么控制

`OneWayFreezer` 是一个**单向、单调递增**的冻结集合控制器：

| 接口 | 作用 |
|------|------|
| `freeze_cols(*cols)` | 把尚未冻结的列加入冻结集（已冻结自动跳过，**永不恢复**） |
| `frozen_mask` | 长度 K 的布尔元组，传给冻结版工厂（静态 trace 期常量） |
| `consume_changed()` | 读取并复位"本轮是否有新增冻结"标志，用于触发机器/QGT 重建 |

控制流程（每轮）：

$$
\text{冻结集合}=F\ ,\qquad F\leftarrow F\cup\{\text{col}\}\quad(\text{只增不减})
$$

```python
# 判据命中某能级 -> v 行峰值列
freeze_ctrl.freeze_cols(col)          # 更新 F
if freeze_ctrl.consume_changed():     # 若本轮确实新增了冻结
    grad_fn, qgt_fn = build_grad_machines(freeze_ctrl.frozen_mask)  # 含 stop_gradient 的新计算图
    idx_active  = build_active_index(total_params, freeze_ctrl.frozen_set)  # 活跃参数索引
```

要点：

- 冻结集合**只增不减**：一旦某列被冻结，其变分参数在该轮及以后**恒定不动**；
- 新增冻结必须触发**重建**（`build_grad_machines` 用新的 `frozen_mask` 重编译）与**索引更新**
  （`build_active_index` 重算活跃参数集合）；
- 控制器不保存 step，由判据层在任意时刻调用，真正做到**在循环中动态指定**。

## 2. 冻结判据

### 2.1 基准选项：化学精度（需 FCI 精确解）

$$
\underbrace{|E_i-E_{\text{FCI},i}|<\epsilon_\text{chem}}_{连续\, N_\text{stable}\, 轮}\;\Longrightarrow\;\text{冻结能级 }i\text{ 对应的主动列}
$$

- $\epsilon_\text{chem}=1.6\times10^{-3}\ \mathrm{Ha}$（$1\,\text{kcal/mol}$），脚本中 `CHEM_ACC`；
- $N_\text{stable}=5$，脚本中 `NEED_STABLE`。用**连续达标轮数**而非单轮，是为了避免个别采样
  方差波动触发误冻结（用计数器 `stable_rounds[i]`，未达标即清零）。

### 2.2 为什么"化学精度"是额外信息

化学精度阈值需要**精确解 $E_\text{FCI,i}$** 作为参考，而它的目标通常是**在不知道精确解时**估算能级。
因此把它当冻结判据意味着：你已有一条"金标准"能级，用它来识别"哪些能级已经算准、可以收工"。
`CRITERION="chemacc"` 正是这个默认选项。

### 2.3 其他不依赖精确解的合理判据（探索方向）

| 判据 | 触发条件 | 是否需 $E_\text{FCI}$ | 脚本开关 |
|------|---------|:---:|------|
| 能量平台 | 最近 $W$ 轮能量极差 $<\varepsilon$ | 否 | `energy_plateau` |
| 精度+梯度收敛 | 化学精度，且该列梯度范数 $<g_{\text{tol}}$ | 是 | `chemacc_grad` |
| QGT/条件数稳定 | $\mathrm{cond}(\Psi)$ 趋于平台 | 否 | （可封装为独立判据） |

纯自监督方向（无需任何外部能量）最值得探索的是**能量平台**与**梯度范数下降**：它们用训练自身
产生的量刻画"该能级已收敛"，与化学精度解耦，可直接用于没有参考解的体系。脚本已内置
`energy_plateau_reached()`；要用时把 `CRITERION="energy_plateau"` 并配 `PLATEAU_W/PLATEAU_EPS` 即可。

## 3. 能级 → 主动列 的映射（M，S，v 全 K×K）

列只是 K 维本征子空间的任意基，**能级 i 与列 i 不一定一一对应**。要确定"能级 i 对应哪一列"，
解 K×K 广义本征问题：

$$
M\,v=\lambda\,S\,v,\qquad M_{ij}=\langle\psi_i\vert H\vert\psi_j\rangle,\quad S_{ij}=\langle\psi_i\vert\psi_j\rangle
$$

- $v$ 的第 i 行即"能级 i 在 K 个原始列上的投影系数 $v_{ij}$"，取 `argmax_j |v_{ij}|` 为主动列；
- $M$、$S$ 由 **MCMC 样本**重建（见 `compute_level_to_col`），全程 K×K；
- 仅当判据首次触发时才计算，避免每轮开销。

---

## 4. 冻结后其余列如何继续更新

冻结页做两件事，保证其余列正常推进且不与取向自由冲突：

1. **列级 `stop_gradient`**：在冻结列的 $L$ 矩阵列输出处加 `jax.lax.stop_gradient`，
   前向值不变（物理上 $K$ 列仍完整），反向图中该子网络 VJP 被真正剪掉 ⇒ 冻结列梯度为 $0$，
   参数逐位不动；
2. **QGT 活跃索引切片**：`build_active_index` 把冻结列的参数从总 $P$ 中剔除，得到
   活跃集 $P_a=P-\lvert F\rvert\cdot P_{\text{col}}$；QGT 的 $O$ 矩阵按 `idx_active` 切片，
   线性求解规模 $P^3\to P_a^3$，其余列的自然梯度在 $P_a\times P_a$ 上照常更新。

$$
\text{其余列梯度}\ \delta = \big(O^\dagger_{P_a} O_{P_a}+I\,\text{diag\_shift}\big)^{-1}\,g_{P_a}
$$

**关于正交性**：冻结某列等价于把该能级的子空间方向固定；其余列通过跨列的 $S$（重叠）与耦合项
继续被 $H$ 驱动，仍能对剩余能级正交化——因为它们之间的纠缠仍在损失与 QGT 中，只是不再涉及
冻结列参数。这正是"分层冻结"的核心收益：已算准的能级被固定，算力转向尚未收敛的能级。

## 5. 代码解读（逐函数）

### `OneWayFreezer(K, frozen_set=None)`
单例冻结控制器。核心是 `frozen_set`（只增不减集合）+ `_changed` 标志：
`freeze_cols` 用差集 `new = cols - frozen_set` 去重，把新列加入并置 `_changed=True`；
`consume_changed()` 取走标志并复位，驱动训练主循环重建计算图。

### `compute_level_to_col(single_machine_list, total_params, x_batch)`
基于 MCMC 样本重建 M（K×K）、S（K×K）并解广义本征问题得 v（K×K）：
1. 逐列拟设算到每个 walker 的 K 个副本构型，拼成 $P_{n\alpha\beta}=\psi_\beta(x_{n\alpha})$；
2. 用 `Ham_Psi_scaled`（局部能量算子，作用到被采样构型）得 $HP$；
3. 逐 walker 按 Frobenius 范数归一化，估计 $\hat S=\mathrm{mean}(P^\dagger P)$、
   $\hat M=\mathrm{mean}(P^\dagger HP)$；
4. `scipy.linalg.eigh(Mhat, Shat)` → λ、v，v 按能量升序重排。返回 v 与有效样本数。

### `level_to_active_col(v, level)`
对旋转矩阵第 `level` 行取绝对值最大列，返回主动列下标：`argmax_j |v[level,j]|`。

### `col_grad_norms(grad_raw)`
对每列变分梯度子树 `grad_raw['single_ansatz_list'][j]` 做 `ravel_pytree` 并取范数，
供 `chemacc_grad` 判据判断"该列是否还在剧烈变化"。

### `energy_plateau_reached(series, window, eps)`
取最近 `window` 轮能量做极差 `max−min`，小于 `eps` 则认为达到平台——纯自监督、无需精确解。

### 主循环中的判据与冻结段
```
for i in range(K):
    if i in frozen_levels: continue
    met = 判据(errors_i[i], col_norms[i], 能量序列)
    stable_rounds[i] = stable_rounds[i]+1 if met else 0
    if stable_rounds[i] >= NEED_STABLE:
        v = compute_level_to_col(...)          # 仅在此刻调用
        col = level_to_active_col(v, i)
        freeze_ctrl.freeze_cols(col); frozen_levels.add(i)
if freeze_ctrl.consume_changed():
    重建 grad_fn/qgt_fn + idx_active
```

## 6. 运行与预期

```bash
cd experiments/H2分子
/opt/miniconda3/envs/Netket/bin/python NES_VMC_chemacc_freezing.py
```

预期行为：

- 基态（能量最低、收敛最快）最可能先满足化学精度并先被冻结；
- 冻结后 `P_a/P` 下降、QGT 开销下降（$P^3\to P_a^3$）；
- 其余能级继续收敛，直至逐个冻结；
- 结果与每轮能级、误差、冻结集合、`level_to_col` 映射一并存入
  `./data/{时间戳}_history_chemacc_freeze_H2_K4.pkl`。

切换判据：改主循环顶部 `CRITERION = "chemacc"` 为 `"chemacc_grad"` 或 `"energy_plateau"`，
并相应配置 `GRAD_TOL` / `PLATEAU_W` / `PLATEAU_EPS`。
