### 一、核心原理：投影哈密顿量的简化形式

首先明确目标：构造冻结子空间正交补中的投影哈密顿量 ( H_\perp = P_\perp H P_\perp )，其中

- 投影算符 ( P_\perp = I - P_F )
- 冻结子空间投影 ( P_F = \sum_{m\in F} |\phi_m\rangle\langle\phi_m| )
- ( {\phi_m} ) 是已收敛的冻结本征态（满足正交归一）

由于 ( \phi_m ) 本身就是哈密顿量的本征态（( H|\phi_m\rangle = E_m |\phi_m\rangle )），可以利用本征态的正交性大幅简化投影哈密顿量，最终得到非常实用的形式：
$$
\boxed{H_\perp = H - \sum_{m\in F} E_m \cdot |\phi_m\rangle\langle\phi_m|}
$$
这个简化是NetKet下实现的核心基础——不需要显式计算 ( H ) 作用在波函数上的结果，只需要原始哈密顿量、冻结态的能量和波函数即可构造。

NetKet 本身**没有内置子空间投影哈密顿量的原生API**，但它的算子和VMC框架完全可扩展。下面分两种场景给出可直接落地的实现方案和伪代码。

### 二、方案1：小系统（精确矩阵形式，完全兼容NetKet API）

如果系统希尔伯特空间维度不高（如自旋数 ( N\le12 )，维度4096以内），可以显式构造投影哈密顿量的稀疏矩阵，再包装成标准的NetKet算子，后续VMC、SR、QGT都无需修改，直接替换原始哈密顿量即可。

#### 伪代码（NetKet 3.x 风格）

```
import netket as nk
import numpy as np
from scipy.sparse import csr_matrix

# ========== 1. 定义原始系统与哈密顿量 ==========
hi = nk.hilbert.Spin(s=1/2, N=N_sites)  # 你的希尔伯特空间
graph = nk.graph.Chain(length=N_sites)
H = nk.operator.Ising(hi, h=transverse_field, graph=graph)  # 原始哈密顿量
H_sparse = H.to_sparse()  # 转为稀疏矩阵

# ========== 2. 准备冻结本征态 ==========
# 输入：已收敛的冻结本征态矢量 phi_m（shape: [hilbert_dim, 1]，已归一化）
#       对应本征能量 frozen_energies
frozen_states = [phi_0, phi_1, ...]    # 每个元素是numpy列向量
frozen_energies = [E_0, E_1, ...]      # 对应本征态的精确能量

# ========== 3. 构造投影哈密顿量 ==========
H_perp = H_sparse.copy()
for E_m, phi_m in zip(frozen_energies, frozen_states):
    # 构造外积 |phi_m><phi_m|（稀疏矩阵形式）
    proj_m = csr_matrix(phi_m @ phi_m.conj().T)
    # 按简化公式减去冻结态的贡献
    H_perp -= E_m * proj_m

# ========== 4. 包装为NetKet标准算子 ==========
# 直接用矩阵初始化LocalOperator，完全兼容NetKet所有API
H_projected = nk.operator.LocalOperator(hi, matrix=H_perp)
```

✅ 优点：零侵入、完全兼容原生API，后续训练逻辑一行都不用改。
❌ 缺点：仅适用于小系统，大系统无法存储全空间矩阵和态矢量。

### 三、方案2：大系统VMC场景（NetKet原生蒙特卡洛，推荐NES-VMC使用）

对于NES-VMC这类大系统变分蒙特卡洛方法，不可能显式构造全空间投影矩阵。工程上有两种成熟实现，都不需要修改NetKet内核：

#### 方式A：正交惩罚法（最简单，优先验证）

**原理**：在损失函数中加入正交惩罚项，强制自由态与所有冻结态正交，等效于在正交补空间中优化。当惩罚系数足够大时，优化结果与显式投影哈密顿量严格等价。
损失函数形式：
$$
\mathcal{L} = E_\psi + \beta \cdot \sum_{m\in F} \big|\langle \phi_m | \psi \rangle\big|^2
$$

#### 伪代码（基于NetKet自定义损失函数）

```
import netket as nk
import jax
import jax.numpy as jnp

# ==================== 1. 初始化冻结态 ====================
# 保存已训练好的冻结本征态（MCState类型）和对应能量
frozen_vstates = [phi0_state, phi1_state, ...]  # 每个都是nk.vqs.MCState
frozen_energies = [E0, E1, ...]
beta = 15.0  # 正交惩罚系数，调至足够大即可（一般5~20）

# ==================== 2. 自定义损失函数 ====================
def projected_loss(vstate):
    # 原始能量期望值
    E = vstate.expect(H).mean.real
    
    # 计算与所有冻结态的重叠平方和（采样估计）
    overlap_penalty = 0.0
    samples = vstate.samples.reshape(-1, vstate.hilbert.size)
    
    for phi_state in frozen_vstates:
        # 共享采样点，同时评估两个态的波函数对数振幅
        log_psi = vstate.log_prob(samples)
        log_phi = phi_state.log_prob(samples)
        
        # 估计重叠 <phi|psi> ≈ mean[ phi*(x) psi(x) / |psi(x)|² ]
        overlap = jnp.mean(jnp.exp((log_phi.conj() + log_psi) / 2))
        overlap_penalty += jnp.abs(overlap) ** 2
    
    return E + beta * overlap_penalty

# ==================== 3. 自定义训练循环 ====================
# 初始化自由态、优化器和SR
sampler = nk.sampler.MetropolisLocal(hi, n_chains=32)
vstate = nk.vqs.MCState(sampler, model=ansatz, n_samples=1024)
optimizer = nk.optimizer.Adam(learning_rate=0.005)
sr = nk.optimizer.SR(diag_shift=0.01)

# 训练循环
for step in range(max_iter):
    vstate.sample()  # 重新采样
    
    # 计算损失和梯度
    loss, grad = jax.value_and_grad(projected_loss)(vstate.parameters)
    
    # SR预条件 + 参数更新
    grad = sr(vstate, grad)
    vstate.parameters = optimizer.update(grad, vstate.parameters)
    
    if step % 50 == 0:
        print(f"Step {step}: Loss = {loss:.6f} Ha")
```

👉 说明：

- 这是VMC领域求解激发态/子空间问题的标准工程方案，实现成本最低，数值稳定性最好。
- 可以无缝嵌入NES-VMC的训练流程，QGT、自然梯度等都可以沿用原生实现。
- 惩罚系数β不需要无限大，一般只要重叠被压制到1e-4以下，结果就与严格投影无显著差异。

#### 方式B：显式投影波函数法（严格对应投影哈密顿量）

如果需要严格的数学等价性，可以在局域能量计算层面显式做波函数投影，严格对应 ( P_\perp H P_\perp )。核心是在每个采样构型上，先将波函数投影到正交补空间，再计算局域能量。

#### 核心伪代码（局域能量计算部分）

```
def project_psi(x, psi_params, frozen_params, overlaps):
    """单个构型x上的波函数投影"""
    psi_x = ansatz.apply(psi_params, x)
    psi_perp = psi_x
    for phi_params, c_m in zip(frozen_params, overlaps):
        phi_x = ansatz.apply(phi_params, x)
        psi_perp -= c_m * phi_x
    return psi_perp

def projected_local_energy(x, psi_params, frozen_params, overlaps, H):
    """计算投影后的局域能量 E_L^perp(x) = (H ψ^⊥)(x) / ψ^⊥(x)"""
    # 投影后的当前点波函数值
    psi_perp_x = project_psi(x, psi_params, frozen_params, overlaps)
    
    # 遍历哈密顿量的所有非零连接构型，计算 Hψ^⊥
    H_psi_perp = 0.0 + 0.0j
    for x_prime, matrix_elem in H.get_conn(x):
        psi_perp_xp = project_psi(x_prime, psi_params, frozen_params, overlaps)
        H_psi_perp += matrix_elem * psi_perp_xp
    
    return (H_psi_perp / psi_perp_x).real
```

👉 说明：

- 严格对应投影哈密顿量的数学定义，但实现侵入性强，需要重写局域能量和梯度计算逻辑。
- 适合对精度要求极高的最终验证阶段，不建议初期使用。

### 四、与NES-VMC适配的补充说明

1. **为什么NetKet没有原生API？** 子空间投影属于定制化的变分训练策略，不是通用量子算子，因此不会内置。但NetKet的可扩展性完全支持以上两种实现，无需修改内核。
2. **规范漂移规避**：两种方案都建议每10~20步重新计算一次冻结态与自由态的重叠，更新投影系数/惩罚项，避免数值积累导致正交性失效。
3. **推荐落地路径**：先用正交惩罚法快速验证物理效果，确认冻结策略正确后，再按需迁移到严格投影版本。

这个问题涉及NetKet底层定制和数值方法细节，实现起来步骤比较多，工作任务模式可以帮你把完整的可运行代码、参数调优建议和验证流程整理成可直接复用的版本，要不要用它处理？
