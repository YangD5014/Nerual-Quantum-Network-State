## 1. 三个函数的分工

```text
make_MS_estimator_fn(ha, single_machine_list)
        │  返回 jitted 统计器 estimator(params, x_batch)
        │  内部：P、HP、掩码、归一化、样本平均 → (M̂, Ŝ, finite)
        ▼
compute_lam_v_from_samples(ha, single_machine_list, total_params, x_batch)
        │  调用 estimator 得 M̂、Ŝ → scipy eigh 解 K×K 广义本征问题 → 排序
        ▼
返回 (lam (K,), v (K,K), n_valid [, M̂, Ŝ])
        │
        ▼
level_to_active_col(v, i) = argmax_j |v[i, j]|   → 分层冻结的目标列
```

- **统计器与求解分离**：重活（逐 walker 的 P/HP 构造与样本平均）在 jit 内；轻活（4×4 的 `eigh`）在 Python 侧用 scipy 完成，与 notebook 完全同路径；
- `compute_lam_v_from_samples` 支持 `estimator=` 传入预构建的统计器，训练循环中反复调用时避免每次重建闭包导致重编译。

## 2. 数学背景（一句话回顾）

NES-VMC 的 K 个列 $\{\psi_1,\dots,\psi_K\}$ 只是 K 维本征子空间的任意基（GL(K) 规范自由），
要得到"能级 i 对应哪一列"，在列子空间上解广义本征问题：

$$
M\,v=\lambda\,S\,v,\qquad
M_{ij}=\langle\psi_i \vert H \vert \psi_j\rangle,\quad
S_{ij}=\langle\psi_i \vert \psi_j\rangle
$$

旋转后第 k 列（能量升序）即第 k 个本征态：

$$
\varphi_k=\sum_{j=1}^{K}\psi_j\,v_{kj},\qquad
\langle\varphi_k \vert H \vert \varphi_k\rangle=\lambda_k
$$

**每个 walker 的关键恒等式**（实现正确性的根基）：

$$
(P^{\dagger}P)^{-1}\big(P^{\dagger}HP\big)=P^{-1}HP
$$

其中 $P_{\alpha\beta}=\psi_\beta(x_\alpha)$ 是单 walker 的 K×K 振幅矩阵。
右端 $P^{-1}HP$ 正是训练里的局部能量矩阵，因此本函数算出的 λ 与训练能级天然一致。

## 3. 实现过程逐步拆解

### 3.1 `make_MS_estimator_fn`：jitted 统计器（4 个阶段）

**阶段 1 —— 单 walker 的 K×K 振幅阵 $P$**

```python
logP_cols = [single_machine_list[j](total_params["single_ansatz_list"][j], x_batch)
             for j in range(K_)]
logP    = jnp.stack(logP_cols, axis=-1)                   # (N, α, β)
shift_n = jnp.max(logP.real, axis=(1, 2)).reshape(-1)     # 每 walker 公共安全标度
P       = jnp.exp(logP - shift_n.reshape(-1, 1, 1))       # (N, K, K)
```

- 第 j 个 gauge-fixed 单列 machine 对 **(N, K, n_spin) 的副本构型**求值 → (N, K)，
  即 $\psi_j$ 在每个 walker 的 K 个副本构型 $x_{n1},\dots,x_{nK}$ 上的对数振幅；
- 堆叠后 `logP[n, α, β]` = 第 β 列在 walker n 的第 α 个副本构型上的对数振幅；
- `shift_n` 是逐 walker 的行/列最大实部，`exp` 前减掉防溢出。它是**每 walker 的公共标度**，
  后续会被归一化抵消，不影响广义本征值。

**阶段 2 —— $H\psi$：局部能量算子作用在被采样构型上**

```python
HP = Ham_Psi_scaled(ha=ha, single_machine_list=single_machine_list,
                    total_params=total_params, x=x_batch, shift=shift_n)   # (N, K, K)
```

- `Ham_Psi_scaled` 计算 $HPsi_{n,\alpha\beta}=\big(H\psi_\beta\big)(x_{n\alpha})
  \cdot e^{-\mathrm{shift}_n}$；
- $H$ 的作用通过**逐边 hop 求和路径**实现，只碰被采到的构型——**从不构造完整
  n_states×n_states 的 H 矩阵，不做精确对角化**。

**阶段 3 —— 有效性掩码 + 逐 walker Frobenius 归一化**

```python
finite = jnp.all(jnp.isfinite(P), axis=(-2, -1)) & jnp.all(jnp.isfinite(HP), axis=(-2, -1))
Pn  = jnp.where(finite.reshape(-1, 1, 1), P,  0.0)
HPn = jnp.where(finite.reshape(-1, 1, 1), HP, 0.0)
norm = jnp.sqrt(jnp.sum(jnp.abs(Pn)**2, axis=(1, 2)) + 1e-30).reshape(-1, 1, 1)
Pn, HPn = Pn / norm, HPn / norm
```

- 溢出/NaN 的 walker 整体剔除（`finite` 是 (N,) 布尔掩码）；
- 每个 walker 按 $\lVert P_n\rVert_F$ 归一化（P、HP **同乘**公共标度）。这一步保证所有 walker
  权重相当，且不改变广义本征值——因为对 $(M, S)$ 同乘常数 $\Rightarrow Mv=\lambda Sv$ 不变。

**阶段 4 —— 样本平均得到 K×K 的 M̂、Ŝ**

```python
N_eff = jnp.maximum(jnp.sum(finite.astype(jnp.float32)), 1.0)
Shat  = jnp.einsum("nai,naj->ij", jnp.conj(Pn), Pn).astype(jnp.complex128) / N_eff
Mhat  = jnp.einsum("nai,naj->ij", jnp.conj(Pn), HPn).astype(jnp.complex128) / N_eff
Shat  = 0.5 * (Shat + jnp.conj(Shat.T))     # 强制 Hermitian，去浮点误差
Mhat  = 0.5 * (Mhat + jnp.conj(Mhat.T))
```

即

$$
\hat S_{ij}=\frac1{N_\text{eff}}\sum_n\sum_{\alpha}\big(P_{n\alpha i}\big)^{*}P_{n\alpha j},
\qquad
\hat M_{ij}=\frac1{N_\text{eff}}\sum_n\sum_{\alpha}\big(P_{n\alpha i}\big)^{*}\big(HP\big)_{n\alpha j}
$$

`N_eff` 用 `jnp.maximum(..., 1.0)` 保护全 walker 失效时不除零（此时结果无效但不会崩溃，
由调用方检查 `n_valid` 决定是否采用）。

### 3.2 `compute_lam_v_from_samples`：解 K×K 广义本征问题

```python
lam, v = scipy_eigh(np.asarray(Mhat), np.asarray(Shat))   # 复 Hermitian 广义本征
order   = np.argsort(lam.real)                            # 能量升序
lam, v  = lam[order], v[:, order]
n_valid = int(np.asarray(finite).sum())
```

- `scipy.linalg.eigh(M, S)` 一次给出 λ 与 S-正交归一的 v；
- `order` 把列按能量升序排——**v 的行下标从此与 FCI 能级下标一一对应**；
- eigh 放在 Python/scipy 侧（K×K=4×4 极小，开销可忽略），保持与 notebook 验证过的路径一致。

### 3.3 `level_to_active_col`：能级 → 主动列

```python
def level_to_active_col(v, level):
    return int(np.argmax(np.abs(np.asarray(v)[level])))
```

$v$ 的第 i 行是"能级 i 在 K 个原始列上的投影系数"，绝对值最大的列即该能级最"对齐"的
原始列——分层冻结时 `stop_gradient` 的目标列。

## 4. 张量尺寸流水表（全程与 Hilbert 空间维度无关）

| 阶段 | 对象 | 形状 |
|------|------|------|
| 输入 | `x_batch`（walker 构型） | (N, K, n_spin) |
| 阶段1 | `logP`、`P` | (N, K, K) |
| 阶段2 | `HP` | (N, K, K) |
| 阶段3 | `finite`、`norm` | (N,)、(N,1,1) |
| 阶段4 | `M̂`、`Ŝ` | **(K, K)** |
| 求解 | `lam`、`v` | (K,)、**(K, K)** |

> K=4 的 H2：M、S、v 全部 **4×4**。

---

## 5. 数值稳定性设计（5 点）

1. **逐 walker shift**：`exp(logP − shift_n)` 防止对数振幅大差异导致上溢/下溢；
2. **Frobenius 归一化**：消除 walker 间振幅尺度差异，且不改变广义本征值；
3. **finite 掩码**：任何 walker 出现非有限值即整体剔除，并随返回值给出 `n_valid` 供调用方把关；
4. **Hermitian 化**：`0.5(M+M†)` 消除浮点不对称，保证 `eigh` 输入合法；
5. **complex128 提升精度**：einsum 结果 cast 到 complex128 再送 scipy。

## 6. 使用示例

**场景 A —— 一次性调用（从训练 history 复现）**

```python
import pickle, numpy as np
import flax.nnx as nnx
from NES_VMC_V1 import NESTotalAnsatz_stable, create_single_machine_gauge_fixed
from NES_VMC_tool import compute_lam_v_from_samples, level_to_active_col
from H2_631G import SINGLE_SIZE, ha, K, Hatree_Fock, E_fcis

with open(HISTORY_FILE, 'rb') as f:
    history = pickle.load(f)
params  = history['params'][-1]
samples = np.asarray(history['samples'][-1])          # (N, K*SINGLE)
x_batch = samples.reshape(-1, K, SINGLE_SIZE)         # (N, K, n_spin) 整数构型

total_ansatz = NESTotalAnsatz_stable(
    n_spin_orbitals=SINGLE_SIZE, n_states=K, hidden_dim=SINGLE_SIZE + K, rngs=nnx.Rngs(11))
sml = [create_single_machine_gauge_fixed(a, Hatree_Fock)[0]
       for a in total_ansatz.single_ansatz_list]

lam, v, n_valid = compute_lam_v_from_samples(ha, sml, params, x_batch)
cols = [level_to_active_col(v, i) for i in range(K)]
print('λ =', np.round(lam, 6), '能级→列 =', cols)
```

**场景 B —— 训练循环中反复调用（复用 estimator 免重编译）**


## 7. 成本分析

| 环节 | 成本 | 说明 |
|------|------|------|
| P 构造 | O(N·K) 次 machine 前向 | 已 jit |
| HP 构造 | O(N·K·edges) 局部能量路径 | 不构造完整 H |
| 样本平均 | O(N·K²) | einsum |
| eigh | O(K³) | 4×4，可忽略 |

**结论**：计算 λ、v 的成本由采样规模 N 与 K 决定，与 Hilbert 空间维度
$n_\text{states}$ **完全解耦**——不会退化为精确对角化。

## 9. 注意事项与边界

1. **列规范不变性**：单列 machine 与训练 total machine 相差逐列常数（ref 居中 / gauge g），
   等价于 $M,S$ 做对角合同变换 $D^\dagger M D,\ D^\dagger S D$——λ 不变、v 随之旋转，
   因此用 gauge-fixed 单列 machine 与训练口径一致且结果物理等价。
2. **能级→列可能多对一**：参数未充分收敛时，多个能级的 $|v[i,:]|$ 可能峰值落在同一列
   （实测出现过 [3, 1, 3, 1]）。此时冻结策略需注意：同一列只冻结一次；若两能级映射到
   同一列，应等子空间更收敛后再判，或在**未冻结列**中取次优列。
3. **判据时机**：建议在训练中后期、子空间基本张成后再调用（早期 λ、v 抖动大，
   冻结判据容易误触发）。
4. **JAX x64**：complex128 提升精度依赖 `JAX_ENABLE_X64=1`（本环境已开启）；
   若关闭，精度退化为 float32，但流程不报错。
5. **重编译**：`compute_lam_v_from_samples` 每次新建 estimator 会重编译；
   循环内反复调用务必传 `estimator=`。
6. **n_valid 把关**：调用方应检查 `n_valid` 占比，过低说明采样或数值有问题，
   此时 λ、v 不可信。
