# 冻结 K=4 + 剩余子空间训练 K=2（达到 K=6 效果）实施方案

## Context

NES-VMC 在 H2/6-31G（物理空间仅 16 维）上 K=4 训练 300 步已得到哈密顿量的四个近似本征态 φ\_0..φ\_3（Rayleigh 偏差 \~1e-3–5e-4 Ha、与 FCI 重叠 0.998+），并已保存为全空间振幅向量 `冻结K4/近似本征态_K4_26-10-07-19-57.npz`（键 `phi_vecs (16,4)`、`all_states`）。

目标：按文档 `[GPT1014]NES_VMC_Matrix_Free_Subspace_Extension.md` 方案 A，**冻结 φ\_0..φ\_3 作投影基**，新建 2 个可训练单态拟设 χ\_0,χ\_1，在其正交补 Q₄=I−ΦΦ† 的 12 维剩余子空间中运行 NES-VMC（2×2 行列式联合采样），收敛后提取 φ\_4,φ\_5，与 FCI 的 E₄,E₅ 对照，等效达到 K=6 效果。

已确认的可复用组件（均在同目录）：

* `NES_VMC_deflation.py`：`amplitudes_full`（(16,K) 全空间振幅）、`orthonormalize_frozen`（Gram-Schmidt）、`make_deflation_bundle`（χ=A−F(F†A)、z=QHQχ、logΨ\_F=log det χ\[idx]、E\_L^F=solve(χ\_idx,z\_idx)）、`extract_physical_states`（M=χ†Hχ, S=χ†χ 广义本征，升序物理态）

* `NES_VMC_V1.py`：`create_single_machine_gauge_fixed`、`NESFermionHopRule`、`flatten_batched_pytree`

* `H2_6_31G_8Qbit_K2.py`：K=2 的 `hi_ext/ext_edges/SINGLE_SIZE/ha/hi/Hatree_Fock/E_fcis`（hi 与 K4 模块相同，基矢序一致）

* `H2_631G_8Qbit_K4_Ansatz_A_RealFFNN.py`：实参数+复输出（RealFFNN）的 Wirtinger 梯度、重要性加权（machine\_pow=1 按 |Ψ| 采样、w∝|Ψ|）、QGT、训练循环模板

仓库中**不存在**实参数版 deflated grad/QGT（现有 `make_deflated_grad_fn` 用 holomorphic=True 仅适用复参数），这是本方案唯一需要新写的算法代码。

## 数学要点（已评审确认）

* F 为 stop\_gradient 常量 → autodiff 对 χ=A−F(F†A) 自动得 ∂χ=Q∂A，即文档的投影切空间，∇c 项无需手工处理。

* loss = Re tr(E\_L^F) 在列基变换下不变，期望值 = tr(S⁻¹M) ≥ ν₀+ν₁（Fan 极大极小），收敛目标即投影子空间最低两本征值之和；E₄/E₅ 间隔 0.0135 Ha 不简并，tr 形式足够，不用样本版小本征分解。

* **冻结态只是近似本征态 → QHQ 的 ν₀,ν₁ 与 E₄,E₅ 存在"冻结空间偏差下限"（预期 ≤1e-3 Ha），训练不可能突破**。必须先算 oracle 区分方法偏差 vs 训练误差。

* 投影子只依赖 span{φ}，升序 GS 正交化不损失物理（GS 与斜投影差 5e-16），且保留 φ₀ 不被污染。

* 新风险：ψ\_j→ψ\_j+Σα\_m φ\_m 方向对 Ψ\_F 不可见（梯度恒零）→ 原始 A 冻结分量可无界漂移，靠 diag\_shift 正则化 + 监控 `max|A|`、`‖F†A‖` 防线（>1e3 告警）。不需要 gauge reset（gauge-fixed 列 + slogdet 已钉死尺度）。

## 文件组织（均在 `NES_VMC/experiments/H2分子/` 下）

1. **新建** **`NES_VMC_deflation_real.py`**（实参数 deflated 梯度/QGT 模块，不动已验证的 `NES_VMC_deflation.py`）：

   * `load_and_orthonormalize_frozen(npz_path, hi)` → F (16,4)：assert npz `all_states` 与 `hi.all_states()` 逐行相等；GS 残差全部 >0.1 才通过（防 `orthonormalize_frozen` 近零向量 bug）

   * `deflation_oracle(F, H_dense)` → ν (2,), u\_vecs：对角化 QHQ，给出冻结偏差下限 oracle

   * `grad_logpsi_real_single(machine, params, x_single)`、`importance_weights_real(machine, params, x_batch, valid)`：从 K4 脚本移植（去掉 g 参数；不能 import K4 脚本——它 import 即训练）

   * `make_deflated_grad_fn_real(forward, min_valid_ratio=0.25)` → `grad_fn(params, sigma_flat)` 返回 (float grad pytree, loss\_mean, E\_L\_mean, aux)，aux 含 valid\_ratio、ess、cond\_chi\_p95；梯度 dtype 为 float，不做 complex64 转换

   * `make_deflated_qgt_fn_real(machine_single)`：O=Wirtinger 拆分，w 加权中心化，S\_real=Re(O†WO)+diag\_shift·I
2. **新建训练脚本** **`H2_631G_8Qbit_K2_frozen4_deflation_RealFFNN.py`**：结构照抄 K4 RealFFNN 脚本（logging→`日志/`、pkl→`data/`、per\_param\_clip 后自然梯度 solve、optax chain(clip20, sgd lr=0.1)），差异：

   * K=2 新拟设 `NESTotalAnsatz_stable(n_states=2)` fresh 随机初始化（工程惯例：Stage1 必须新 init），gauge-fixed 单列 machine 列表

   * `make_deflation_bundle(sms, all_states, H_dense, F)` 提供 machine/forward；采样 `NESFermionHopRule(K=2)` + `MetropolisSampler(machine_pow=1, n_chains=16, sweep_size=20, chain_length=200)`

   * 监控用**全空间精确** M/S（每步 `amplitudes_full`→χ→`extract_physical_states` 级别的对角化，16 维下开销可忽略），对照 ν₀,ν₁ 与 E\_fcis\[4:6]；日志"理论 Loss 目标"= ν₀+ν₁（≈−0.0425 Ha，尺度与 K4 的 −2.0 完全不同）

   * 每步记录：loss、λ\_k、valid\_ratio、ESS、cond(χ\_idx) p95、max|A|、‖F†A‖\_max、accept rate

   * N\_ITER=300，每 20 步存 pkl
3. **输出**：训练后 `φ̂₄,φ̂₅ = extract_physical_states(χ_full, H_dense)`，保存 npz 至 `冻结K4/`（含 phi\_vecs、λ、oracle ν、诊断指标），打印与 `测试各能级的近似本征态.py` 同款验收表。

## 实施步骤

* **步骤 0（纯 numpy 预检，先于一切训练）**：加载 npz → GS 得 F → 对角化 QHQ 得 ν₀,ν₁ 及 u₀,u₁，报告 u 与 FCI φ₄,φ₅ 重叠。验证 ν ≈ E\_fcis\[4:6]（偏差 = 冻结下限）。若 ν₀ 明显低于 E₄ 则停下修 K=4 来源。

* **步骤 1（模块单测，无训练）**：fresh K=2 ansatz + bundle + 实参数 grad/QGT 跑 1 batch：logΨ\_F 形状 (N,)、E\_L (N,2,2) 有限率、grad float 且 finite、cond(χ\_full) 初值 <1e6（否则换 seed）。

* **步骤 2（5 步 smoke）**：loss 向 ν₀+ν₁ 下行、valid\_ratio>0.9、ESS>N/3、max|A| 不爆、单步耗时可接受。

* **步骤 3（300 步正式训练）**：全超参沿用 K4 模板；每步诊断入日志与 pkl。

* **步骤 4（提取与验收）**：指标见下表；与步骤 0 oracle、已有 K=6 基线（`26-10-09-15-11` K6 运行）三方对比。

* **可选对照（成本极低，建议做）**：同一 loss 去掉采样、16 构型确定性 tr(S⁻¹M) 直接 autodiff——解耦"拟设容量"与"MC 噪声"，失败归因干净。

## 验收标准

| 指标           | 定义                                            | 通过线                                    |
| ------------ | --------------------------------------------- | -------------------------------------- |
| Rayleigh 偏差  | R(φ̂ₖ) − E\_fcis\[4+k]                        | < 2e-3 Ha，且 R−ν 偏差 < 1e-4（区分训练误差/冻结下限） |
| Var\[E\_loc] | ⟨H²⟩−⟨H⟩² 全空间精确                               | < 1e-4                                 |
| FCI 重叠       | \|⟨U\[:,4+k]\|φ̂ₖ⟩\|²（U=eigh(H\_dense)）       | > 0.99                                 |
| 冻结剩余重叠       | max\_m \|⟨φ\_m^raw\|φ̂ₖ⟩\|²（用原始非正交 phi\_vecs） | < 1e-6                                 |
| 子空间条件数       | cond(χ†χ)                                     | < 1e4                                  |

## 风险与对策

* **χ\_idx 近奇异**（两列局部成比例）→ E\_L solve 爆：valid mask + min\_valid\_ratio=0.25 + fresh init 检查 cond；per\_param\_clip=0.5 + global clip 20 保留。

* **冻结分量漂移**（梯度零方向）：监控 max|A|、‖F†A‖，>1e3 告警、>1e5 重启/加大 diag\_shift；不加 |⟨φ|ψ⟩|² 惩罚（gauge-fixed 列不可能严格在 Q 空间，惩罚有偏）。

* **φ̂₄ 好 φ̂₅ 差**：优先查 cond(χ\_full)（E4/E5 小间隔列混合），其次延长迭代/降 lr。
